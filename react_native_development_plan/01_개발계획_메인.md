# 기사앱 React Native 포팅 세부 개발계획

## 📋 프로젝트 개요

### 프로젝트명

현재 Android 전용으로 개발된 기사앱을 React Native로 포팅하여 iOS와 Android를 동시에 지원하는 크로스 플랫폼 앱으로 전환

### 예상 비용

## 🎯 핵심 목표

1. **크로스 플랫폼 지원**: 단일 코드베이스로 iOS/Android 동시 지원
2. **기능 완전성**: 현재 Android 앱의 모든 기능 100% 포팅
3. **성능 최적화**: 네이티브 앱과 동등한 수준의 성능 구현
4. **유지보수성**: 향후 기능 추가 및 수정이 용이한 구조 설계

## 📊 현재 Android 앱 분석 결과

### 기술 스택
- **언어**: Kotlin
- **UI**: Jetpack Compose
- **아키텍처**: MVVM + Repository Pattern
- **DI**: Hilt
- **상태관리**: StateFlow
- **백엔드**: Firebase (Auth, Firestore, FCM)

### 주요 기능
1. **인증 시스템**
   - Firebase Auth 기반 로그인/회원가입
   - 기사 승인 프로세스
   - 자동 로그인

2. **실시간 콜 관리**
   - Firestore 실시간 리스너
   - 콜 상태 관리 (WAITING → ASSIGNED → ACCEPTED → IN_PROGRESS → COMPLETED)
   - 새로운 콜 알림 팝업

3. **기사 상태 관리**
   - OFFLINE/ONLINE/WAITING/ASSIGNED/ACCEPTED/ON_TRIP
   - 상태별 화면 전환

4. **백그라운드 서비스**
   - Foreground Service로 앱 종료 후에도 콜 감지
   - FCM 푸시 알림

5. **위치 서비스**
   - GPS 기반 현재 위치 획득
   - 지오코딩을 통한 주소 변환

6. **정산 시스템**
   - 운행 완료 후 정산 처리
   - 현금/카드 결제 관리

## 🏗️ React Native 아키텍처 설계

### 기술 스택 선정
- **Core**: React Native 0.73.x + TypeScript 5.x
- **상태관리**: Redux Toolkit + RTK Query
- **네비게이션**: React Navigation 6.x
- **UI 라이브러리**: React Native Paper 5.x
- **Firebase**: @react-native-firebase/*
- **푸시알림**: @notifee/react-native
- **위치서비스**: @react-native-community/geolocation

### 아키텍처 패턴
- **Presentation Layer**: React Components + Hooks
- **State Layer**: Redux Toolkit Slices
- **Service Layer**: Firebase Services + API Services
- **Utility Layer**: Helper Functions + Constants
