## 🏗️ 아키텍처 레이어

### 1. Presentation Layer (View)
- **Screens**: 전체 화면 컴포넌트
- **Components**: 재사용 가능한 UI 컴포넌트
- **Navigation**: 화면 간 전환 로직

### 2. State Management Layer
- **Redux Store**: 전역 상태 관리
- **Slices**: 기능별 상태 분리
- **Thunks**: 비동기 액션 처리
- **Selectors**: 상태 선택 및 메모이제이션

### 3. Service Layer
- **Firebase Services**: Firebase와의 통신
- **API Services**: REST API 통신
- **Location Services**: 위치 관련 서비스

### 4. Utility Layer
- **Hooks**: 커스텀 React Hooks
- **Utils**: 공통 유틸리티 함수
- **Constants**: 앱 전역 상수

### Redux Slice 구조
```typescript
// store/slices/driverSlice.ts
import { createSlice, PayloadAction } from '@reduxjs/toolkit';

interface DriverState {
  status: DriverStatus;
  currentCall: CallInfo | null;
  isLoading: boolean;
}

const initialState: DriverState = {
  status: DriverStatus.OFFLINE,
  currentCall: null,
  isLoading: false,
};

const driverSlice = createSlice({
  name: 'driver',
  initialState,
  reducers: {
    setStatus: (state, action: PayloadAction<DriverStatus>) => {
      state.status = action.payload;
    },
    setCurrentCall: (state, action: PayloadAction<CallInfo | null>) => {
      state.currentCall = action.payload;
    },
  },
});

export const { setStatus, setCurrentCall } = driverSlice.actions;
export default driverSlice.reducer;
```

## 🔧 네이밍 컨벤션

### 파일 네이밍
- **컴포넌트**: PascalCase (예: `HomeScreen.tsx`)
- **유틸리티**: camelCase (예: `formatters.ts`)
- **상수**: camelCase (예: `constants.ts`)
- **타입**: PascalCase (예: `User.ts`)

### 코드 네이밍
- **컴포넌트**: PascalCase
- **함수**: camelCase
- **변수**: camelCase
- **상수**: UPPER_SNAKE_CASE
- **타입/인터페이스**: PascalCase
