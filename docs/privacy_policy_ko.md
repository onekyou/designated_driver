# 개인정보처리방침

**최종 수정일:** 2026년 1월 17일
**시행일:** 2026년 1월 17일

---

## 1. 개요

[회사명] (이하 "회사")는 대리운전 서비스 제공을 위해 다음과 같은 개인정보를 수집하고 이용합니다. 본 개인정보처리방침은 회사가 운영하는 모든 앱(손님앱, 기사앱, 콜매니저, 콜디텍터)에 적용됩니다.

---

## 2. 수집하는 개인정보 항목

### 2.1 손님앱 (Customer App)
| 수집 항목 | 수집 목적 | 필수 여부 |
|----------|----------|----------|

|----------|----------|----------|

| 통화 상태 | 콜 감지 | 필수 |

---

## 3. 개인정보의 수집 방법

- 앱 회원가입 시 사용자가 직접 입력
- 서비스 이용 과정에서 자동 수집 (위치, 통화 상태)
- 전화 수신 시 발신자 번호 자동 수집

---

## 4. 개인정보의 이용 목적

회사는 수집한 개인정보를 다음 목적으로만 이용합니다:

1. **서비스 제공**: 대리운전 배차, 운행 관리, 정산
2. **회원 관리**: 본인 확인, 서비스 이용 기록 관리
3. **알림 서비스**: 배차 알림, 운행 완료 알림, 포인트 적립 안내
4. **포인트 관리**: 포인트 적립 및 사용 내역 관리
5. **서비스 개선**: 이용 통계 분석, 서비스 품질 향상

## 6. 개인정보의 제3자 제공

회사는 원칙적으로 이용자의 개인정보를 외부에 제공하지 않습니다. 다만, 다음의 경우에는 예외로 합니다:

1. 이용자가 사전에 동의한 경우
2. 법령의 규정에 의거하거나, 수사 목적으로 법령에 정해진 절차와 방법에 따라 수사기관의 요구가 있는 경우

### 서비스 운영 시 정보 공유

| 제공받는 자 | 제공 항목 | 제공 목적 |
|------------|----------|----------|
| 배차된 기사 | 고객 전화번호, 출발지 | 운행 서비스 제공 |
| 손님 | 기사 이름, 전화번호, 차량번호 | 기사 확인 |

## 8. 이용자의 권리와 행사 방법

이용자는 다음과 같은 권리를 행사할 수 있습니다:

### 8.1 권리 내용
- **열람권**: 본인의 개인정보 처리 현황 열람 요청
- **정정권**: 부정확한 개인정보의 정정 요청
- **삭제권**: 개인정보의 삭제 요청
- **처리정지권**: 개인정보 처리의 정지 요청

### 8.2 행사 방법
- 앱 내 "설정 > 개인정보" 메뉴에서 직접 처리
- 고객센터 연락: [전화번호]
- 이메일 문의: [이메일 주소]

### 8.3 회원 탈퇴
앱 내 "설정 > 회원 탈퇴" 메뉴에서 직접 탈퇴 가능하며, 탈퇴 시 모든 개인정보가 즉시 삭제됩니다.

## 10. 앱에서 사용하는 권한 안내

### 10.1 손님앱
| 권한 | 사용 목적 |
|------|----------|
| 위치 (ACCESS_FINE_LOCATION) | 현재 위치 확인하여 출발지로 설정 |
| 알림 (POST_NOTIFICATIONS) | 기사 배정, 운행 완료 알림 수신 |

### 10.2 기사앱
| 권한 | 사용 목적 |
|------|----------|
| 위치 (ACCESS_FINE_LOCATION) | 실시간 위치 공유, 고객 픽업 |
| 알림 (POST_NOTIFICATIONS) | 배차 알림 수신 |
| 마이크 (RECORD_AUDIO) | 음성 입력 기능 |

### 10.3 콜매니저 / 콜디텍터
| 권한 | 사용 목적 |
|------|----------|
| 전화 상태 (READ_PHONE_STATE) | 수신 전화 감지하여 자동 콜 등록 |
| 연락처 (READ_CONTACTS) | 발신자 이름 표시 |
| 다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW) | 전화 수신 시 배차 팝업 표시 |
| 알림 (POST_NOTIFICATIONS) | 새 콜 알림 수신 |
