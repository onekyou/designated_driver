# 이월 정산 시스템 설계서

## 1. 개요

기사의 미지급금(이월금)을 관리하는 시스템입니다.
- 기사 몫보다 현금 수령이 적으면 → 미지급 발생
- 미지급금은 누적되어 관리
- 매니저가 이체하면 기사가 수령 확인 후 정산 완료

---

## 2. 용어 정의

| 용어 | 콜매니저 (매니저 입장) | 기사앱 (기사 입장) |
|------|----------------------|-------------------|
| 미지급금 | 사무실이 기사에게 줘야 할 돈 | 내가 받아야 할 돈 (미수령금) |
| 이체하기 | 기사에게 돈을 보냄 | - |
| 수령완료 | - | 돈을 받았음을 확인 |

---

## 3. 상태 흐름

```
PENDING (미지급/미수령)
    │
    │ [매니저: 이체하기]
    ▼
TRANSFERRED (대기 - 기사 확인 중)
    │
    ├─ [매니저: 이체취소] → PENDING (원복)
    │
    └─ [기사: 수령완료] → SETTLED (완료, 리셋 0원)
```

### Firestore: drivers/{driverId}

```javascript
carryOver: {

  lastUpdatedAt: Timestamp,          // 마지막 업데이트

  transferredBy: "adminId" | null,   // 이체 처리한 매니저 ID
  todayAmount: 10000                 // 오늘 발생한 미지급금 (마감 전까지)
}
```

## 5. 계산 로직

### 5.1 기사별 오늘 미지급금 계산

```
총 운행료 = 각 운행의 fare 합계
사무실 몫 = 총 운행료 × 수수료율 (예: 60%)
기사 몫 = 총 운행료 - 사무실 몫 (예: 40%)

현금 수령 = 현금 결제 금액 + 현금+포인트의 현금 부분

오늘 미지급 = 기사 몫 - 현금 수령
  - 양수: 기사가 더 받아야 함 (미지급 발생)
  - 음수: 기사가 사무실에 납입 (정상)
  - 0: 정확히 맞음
```

### 5.2 누적 미지급금

```
누적 미지급 = 전일 이월 + 오늘 미지급
```

### 5.3 마감 시 처리

```
if (오늘 미지급 > 0) {
  carryOver.balance += 오늘 미지급
  carryOver.lastUpdatedAt = now
}
carryOver.todayAmount = 0  // 리셋
```

    // Firestore 업데이트

        "carryOver.status", "TRANSFERRED",
        "carryOver.transferredAt", Timestamp.now(),
        "carryOver.transferredBy", currentAdminId

## 8. 마감 시 처리

```kotlin
fun onFinalizeSettlement() {
    drivers.forEach { driver ->
        val todayUnpaid = calculateTodayUnpaid(driver)

        if (todayUnpaid > 0) {
            // 미지급 발생 - 누적에 추가
            driversRef.document(driver.id).update(
                "carryOver.balance", FieldValue.increment(todayUnpaid),
                "carryOver.todayAmount", 0,
                "carryOver.lastUpdatedAt", Timestamp.now()
            )
        }
    }
}
```
