## 📁 핵심 파일 (알아야 할 3개)

### 1. `lib/screens/home_screen_new.dart` (756줄)
```
- _WaitingScreen: 콜 대기 화면
- _CallAssignedScreen: 콜 배정 화면 (수락/거부)
- _OnTripScreen: 운행 중 화면 (완료 버튼)
```

### 2. `lib/services/fcm_service.dart` (207줄)
```
- FCM 토큰 관리
- 푸시 알림 처리
- Firestore에 토큰 저장
```

### 3. `lib/features/call/presentation/providers/call_notifier.dart`
```
- fetchAssignedCall(): 배정된 콜 조회
- acceptCall(callId): 콜 수락
- rejectCall(callId, reason): 콜 거부
- completeCall(callId): 콜 완료
```

## 🔑 Android vs Flutter 주요 차이

| 항목 | Android (driver_app) | Flutter (driver_app_flutter) |
|------|---------------------|------------------------------|
| 언어 | Kotlin | Dart |
| UI | Jetpack Compose | Flutter Widgets |
| 상태관리 | ViewModel + StateFlow | Riverpod + StateNotifier |
| 화면 | 별도 파일 3개 | home_screen_new.dart 1개에 전부 |
| 비동기 | Coroutines | async/await + Future |
| 불변 | data class | Freezed |
