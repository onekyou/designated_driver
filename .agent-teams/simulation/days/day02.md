# Day 2: 취소/거절 + 마감 공유 시작 (공유콜 5%)

## 목표

## 설정
- 전체 100콜: 일반 95건 + 공유콜 5건
- 전화콜 55건 + 앱콜 40건 + 공유콜 5건
- 결제: 현금 60 / 카드 15 / 이체 10 / 포인트 5 / 현금+포인트 3 / 외상 2
- 취소/거절: 기사거절 5건 + 관리자취소 5건 + 고객취소 3건 = 13건
- 사무실1 먼저 마감 → 마감 후 전화 5건 → 자동 공유콜 → 사무실2 or 3 수임
