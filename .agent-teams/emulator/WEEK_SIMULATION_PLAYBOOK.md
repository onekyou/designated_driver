# 4주 대규모 시뮬레이션 플레이북

## 개요
- 10사무실 × 50기사, 4주(28일), 총 ~15,000콜
- Firebase Emulator 기반 자동 실행
- 주 단위 분할 (매주 데이터 초기화 + 이월금 이어받기)

## 공유콜 자연 흐름

피크타임(목금토) 22:00~01:00에 대형사무실 기사 전원 운행 중 + WAITING 적체 시:
1. 매니저 판단 → 수동 공유콜 생성
2. 콜 적은 소형/중형 사무실이 수임
3. 새벽 마감(CLOSED) 후 전화 → 자동 공유콜 → 영업중인 사무실 수임

## 콜 시나리오 비율 (기본)

| 시나리오 | 비율 | 설명 |
|---------|------|------|
| 정상 완료 | 75% | create→assign→accept→drive→complete→finalize |

| 관리자 취소 | 5% | ASSIGNED/ACCEPTED 후 CANCELED |

| 공유콜 경합 | 2% | 2사무실 동시 수임 시도 |
| ASSIGNED 타임아웃 | 2% | 3분 무응답→CF 자동복구 |

## 검증 포인트

### 매일 마감 검증
- 사무실별 정산 세션 callCount/totalFare 정합성
- totalFare = totalCash + totalCard + totalCredit + totalPoints
- 취소 콜은 정산 제외
- 기사 전원 WAITING 복구

### 주 마감 검증
- Week 1: 기본 정산 정합성, 공유콜 정산 귀속 정확성
- Week 2: 포인트 잔액 일치, 이월금 계산 정확성
- Week 3: 스트레스 하 데이터 유실 없음, 경합 처리
- Week 4: 전체 정합성 - 이월 0원, 포인트 총합 일치, 전 콜 정산 완료

## 실행 방법

```bash
# 에뮬레이터 실행 (터미널 1)
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
export PATH="$JAVA_HOME/bin:$PATH"
firebase emulators:start --only functions,firestore

# 주 단위 실행 (터미널 2)
cd functions
export FIRESTORE_EMULATOR_HOST="127.0.0.1:8080"
npx ts-node test/weekly-sim/run-week.ts --week 1
npx ts-node test/weekly-sim/run-week.ts --week 2
npx ts-node test/weekly-sim/run-week.ts --week 3
npx ts-node test/weekly-sim/run-week.ts --week 4
```
