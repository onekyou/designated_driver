# 손님앱 (Customer App)

## 프로젝트 개요
대리운전 손님용 Android 앱 - 사무실별 독립 운영 시스템

## 개발 환경
- Android Studio Hedgehog | 2023.1.1
- Kotlin 1.9.0
- Min SDK: 24 (Android 7.0)
- Target SDK: 34 (Android 14)

## 프로젝트 구조
```
customer_app/
├── app/                    # Android 앱 모듈
├── landing/               # Next.js 랜딩 페이지
├── functions/             # Cloud Functions (어트리뷰션)
└── tests/                 # 테스트 코드
```
