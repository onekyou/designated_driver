Agora RTM (Real-time Messaging) SDK 2.x는 이전 버전에 비해 더 현대적이고 사용하기 쉬운 API 구조를 제공하며, 특히 비동기 작업 처리와 이벤트 중심 설계를 강화했습니다. 여기서는 RTM 2.x API의 주요 구조와 핵심 구성 요소를 설명합니다.1. 핵심 구성 요소RTM 2.x API의 주요 구성 요소는 다음과 같습니다.RtmClient: RTM SDK의 진입점(Entry Point)입니다. RTM 서비스에 연결하고, 메시지를 보내고, 채널을 관리하며, 로컬 사용자 정보를 제어하는 등 모든 주요 작업을 수행합니다.RtmClientListener: RtmClient에서 발생하는 다양한 이벤트를 수신하기 위한 리스너 인터페이스입니다. 연결 상태 변경, 메시지 수신 등 중요한 비동기 이벤트를 처리합니다.RtmConfig: RtmClient를 생성할 때 필요한 설정 정보를 담는 객체입니다. 앱 ID, 사용자 ID, 토큰, RTM 역할(role) 등을 지정합니다.RtmChannel: 실시간 메시징이 이루어지는 채널을 나타냅니다. 채널에 가입(join)하고, 채널 내에서 메시지를 주고받으며, 채널 멤버 목록을 관리합니다.RtmMessage: RTM 시스템을 통해 전송되는 메시지 객체입니다. 텍스트 메시지, 이진 데이터 메시지 등을 포함할 수 있습니다.RtmResult<T>: RTM 비동기 작업의 결과를 나타내는 제네릭 클래스입니다. 작업의 성공 여부, 성공 시 반환 값(T), 실패 시 오류 정보를 담고 있습니다.2. 초기화 및 설정 (RtmClient & RtmConfig)RTM 서비스를 사용하기 전에 RtmClient 인스턴스를 초기화해야 합니다. code Kotlindownloadcontent_copyexpand_less    import io.agora.rtm.RtmClient

// 채널 생성 및 가입
fun joinChannel(rtmClient: RtmClient, channelName: String, callback: (Boolean, String?, RtmChannel?) -> Unit) {
    val channel = rtmClient.createStreamChannel(channelName) // 또는 rtmClient.getChannel(channelName)

    channel?.let { rtmChannel ->
        rtmChannel.join { response ->
            if (response.isSuccess) {
                callback(true, null, rtmChannel)
                println("Joined channel $channelName successfully!")
            } else {
                val errorMsg = response.error?.errorDescription ?: "Unknown error"
                callback(false, errorMsg, null)
                println("Failed to join channel $channelName: $errorMsg")
            }
        }
    } ?: callback(false, "Channel $channelName could not be created.", null)
}

// 메시지 전송
fun sendMessageToChannel(rtmChannel: RtmChannel, message: String, callback: (Boolean, String?) -> Unit) {
    val rtmMessage = RtmMessage.Builder()
        .text(message)
        .build()

    rtmChannel.sendMessage(rtmMessage) { response ->
        if (response.isSuccess) {
            callback(true, null)
            println("Message sent to channel: $message")
        } else {
            val errorMsg = response.error?.errorDescription ?: "Unknown error"
            callback(false, errorMsg)
            println("Failed to send message: $errorMsg")
        }
    }
}

// 채널 떠나기
fun leaveChannel(rtmChannel: RtmChannel) {
    rtmChannel.leave { response ->
        if (response.isSuccess) {
            println("Left channel successfully!")
        } else {
            val errorMsg = response.error?.errorDescription ?: "Unknown error"
            println("Failed to leave channel: $errorMsg")
        }
    }
    rtmChannel.release() // 채널 리소스 해제
}

interface RtmResult<T> {
    val isSuccess: Boolean
    val data: T? // 성공 시 반환되는 데이터 (Unit 타입인 경우 null)

}

interface RtmErrorInfo {
    val errorCode: RtmConstants.RtmErrorCode
    val errorDescription: String
}

SDK 자체에서 suspend 함수를 제공하지 않는 경우, 콜백 기반 API를 suspendCancellableCoroutine 등을 사용하여 코루틴 래퍼로 만들 수 있습니다.예시 (로그인 함수를 코루틴으로 래핑): code Kotlindownloadcontent_copyexpand_lessIGNORE_WHEN_COPYING_STARTIGNORE_WHEN_COPYING_END    import kotlinx.coroutines.suspendCancellableCoroutine
import kotlin.coroutines.resume
import kotlin.coroutines.resumeWithException

suspend fun loginRtmSuspending(rtmClient: RtmClient, token: String) {
    return suspendCancellableCoroutine { continuation ->
        rtmClient.login(token) { response ->
            if (response.isSuccess) {
                continuation.resume(Unit) // 성공 시 Unit 반환
            } else {
                val errorMsg = response.error?.errorDescription ?: "Unknown error"
                continuation.resumeWithException(Exception("RTM Login failed: $errorMsg"))
            }
        }
    }
}
