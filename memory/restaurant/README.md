# restaurant — 식당 도메인 (콜마당 OS 의 4중 노드)

> 마스터 §3.4 식당의 4중 역할 + §10.2 업소용 앱.
> 자기추진 메커니즘의 진입점 (식당 영업 → 사무실 시스템 체감 → 자발적 귀속 경쟁).

## 식당의 4중 역할 (마스터 §3.4)

```
┌─────────────────────────────────────────┐
│           식당 (양평 생태계 허브)        │
├─────────────────────────────────────────┤
│  ① 호출 노드   대리·택시 (지금)         │
│              → 배달 (T2)                │
│  ② 포인트 적립 사장님 본인 + 단골 선물    │
│  ③ 손님앱 거점 손님이 콜마당 처음 만나는  │
│              장소                       │
│  ④ 쿠폰 발행   손님 대상 직접 발행       │
└─────────────────────────────────────────┘
```

**의미**: 식당은 단순 사용처가 아닌 인프라 구성요소. 영구 무료가 정당한 이유.

## 업소용 앱 (개발 예정, 마스터 §10.2)

| 항목 | 내용 |
|------|------|
| 사용자 | 식당 관리자 (사장님/직원) |
| 핵심 기능 | 단순호출 버튼 (대리/택시) + 포인트 표시 |
| 우선순위 | **1순위** (마스터 N=1 무기 직접 의존) |
| 개발 상태 | 미착수 (체크리스트 B-3) |

## 식당 포인트 — 환금성 0 구조 (마스터 §3.5)

**사용처 한정**:
- 사장님 본인 대리 사용
- 단골에게 무료 대리 선물

**규제 회피**: 환금 불가 → 선불전자지급수단·PG업 규제 진입 안 함

## 가격 (마스터 §3.3)

쿠폰 발행 시점부터 구독 전환. **현재 직감**: (B) 5,000 → 10,000원 (자기추진 다이내믹 가속에 유리).
