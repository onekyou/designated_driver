# user_profile — 사용자 프로필 (도메인 공통)

> 모든 도메인에 공통 적용되는 사용자 정보.

## 자산
- `user_ios_experience.md` — App Store 출시 무경험, Android 숙련. iOS 용어는 기초부터 + Android 비유
- `apple_ios_ids.md` — Apple Team ID `VCJD377MAU`, Bundle ID `com.designated.driverapp.app`

## 향후 추가 가능
- 사용자 영업 스타일 (시나리오 25년 경력 → 인물 관찰력 / 플롯 설계력)
- 사용자 자원 시계 (현금 4,000만 + 9~12개월 자원, 마스터 §2.3)
- 사용자 사고 모드 진화 (4년 환상기 → 디버깅 사고 모드, 마스터 §1)
