**유형**: feedback (작동 방식)
**관련**: CLAUDE.md §실행원칙 4(요구 이상 수정 금지)·§Claude 실행 규칙(한 가지 권장+진행)

**무엇**: "녹음파일 파싱해봐"라는 단순·탐색 요청에, 클코가 STT 모델(whisper) 다운로드·venv·HF throttle 우회까지 장시간 인프라를 구축. 본인이 두 번 중단하고 "지금 무슨 프로그램 만드냐, 간단히 파싱해보라는 건데" + "우리 콜매니저에 이미 파싱(CallMemoParser) 있는데?"로 재중심시킴.

**Why (왜 문제)**:
- grep 단계에서 `CallMemoParser`·`VoiceInputHelper`(기존 STT+파싱 자산)를 *이미 봤으면서* 못 쓰고 새 인프라로 감.
- 탐색·대화 단계인데 제품 빌드처럼 무겁게 진입 → 본인 의도(개념 확인)와 미스매치.
- 검증 단계에서 "어느 STT 쓸까?" AskUserQuestion → 헌장 "할까요/어느 쪽 금지" 위반. 본인 "묻지 말고 최선으로 해".

**How to apply (다음에)**:
1. 요청이 *탐색/개념 확인*인지 *제품 구현*인지 먼저 구분. 단순 요청엔 가장 가벼운 검증 경로.
2. 새로 만들기 전 **기존 코드 자산부터 확인**(grep 결과를 흘리지 말 것).
3. 무거운 인프라(다운로드·설치·클라우드)로 가기 전 1줄로 범위·의도 확인.
4. 검증 단계에서 막히면 "한 가지 권장 + 진행", 선택지 나열 질문 금지.
