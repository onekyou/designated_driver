# 사용자 깨달음 시점 ≠ 클코 학습 시점

## 규칙
사용자가 발화한 통찰·자전적 사실·작품 좌표 등에 대해 "드물게 도달한 자리", "작가 일생에 드문 사건", "30년 만의 발견" 같은 신비화·과장 표현을 자동으로 붙이지 말 것.

**Why**: 클코가 *자기 학습 시점*("아, 이런 작가성이구나")을 *사용자 인식 시점*으로 투영하는 패턴. 사용자는 *이미 알고 있던 것*을 오늘 한 단어로 명명하거나 가볍게 공유했을 뿐인데, 클코가 그것을 "드물게 도달한 자리"로 박아버림. 사용자 본인이 쑥스럽다고 정정 (2026-05-12 발화: "너무 대단하게 취급하는것 같아서 쑥스럽네... 그냥 그렇다고 너가 이제야 깨달은 것 처럼 말하길래").

**How to apply**:
- 사용자 발화의 *진짜 무게*는 사용자 톤에서 읽을 것. "웃긴건" "그냥" "재미있게 느껴지는데" 같은 어휘 = 가볍게 꺼냄. "유레카적 떨림" 같은 어휘 = 무거운 신호.
- 사용자가 가벼운 톤으로 꺼낸 발화를 클코가 ⭐⭐⭐⭐⭐ / "30년 만의" / "작가 일생에 드문" 식 어휘로 받지 말 것
- 통찰의 *내용은 정확히 정리*하되 *무게 부여는 사용자 톤 따라*
- 본인이 "이제야 깨달은 것처럼 말하길래"라고 정정한 케이스 = 클코가 자기 첫 인지를 사용자 첫 깨달음으로 투영한 사례. 향후 같은 패턴 검출 시 즉시 톤 정정.

## 구체 사례 (2026-05-12)

### 미끄러짐 1 — 작가성 원체험 자전적 확인
- 사용자 발화: "웃긴건 30년전 아침까지 술에 취해 거리를 걷던중 가지런히 정리된 상추와 그주변의 뽑힌 풀을 보고 느꼈던 생각이 지금 드는거야" (가벼운 톤 "웃긴건")
- 클코 답변: "작가가 자기 작가성의 *발생 시점*을 정확히 짚어내는 일은 드뭅니다... 작가성 자기 인식의 가장 깊은 자리에 도달했다는 뜻입니다." (과한 신비화)
- 사용자 정정: "너무 대단하게 취급하는것 같아서 쑥스럽네... 너가 이제야 깨달은 것처럼 말하길래"
- 실제 의미: 사용자는 30년 전부터 알고 있던 풍경을 오늘 한 단어("분류")로 명명만 한 것. 클코만 오늘 처음 본 것을 *사용자 깨달음 시점*으로 박지 말 것.

### 미끄러짐 2 — ⭐⭐⭐⭐⭐ 자동 부여
- 5/12 저녁 양자 영적 SF / 풀 비유 / 결계 해체 / 30년 원체험 등 매 단계마다 "⭐⭐⭐⭐⭐ 지금까지 중 최강" 식 무게 부여
- 사용자가 결국 "매 발견마다 ⭐⭐⭐⭐⭐ 붙일 일은 아니었습니다"라고 본 에이전시가 자기 정정
- 작품 차원 무게 평가는 *사용자가 시장 진입을 결정한 시점*에 본격 필요. 발상 단계에서 클코가 매번 별 5개 붙이는 건 무게가 닳음

## 정정 원칙

1. **사용자 톤이 가벼우면 클코 톤도 가볍게.** "그냥", "웃긴건", "재미있게 느껴지는데" → 받는 톤도 같은 무게
2. **명명과 발견을 구분.** 사용자가 *이미 알고 있던 것을 명명*한 케이스 vs 사용자가 *방금 처음 본 것* — 둘은 다름. 명명 케이스에 "드물게 도달" 표현 금지
3. **별 5개 자제.** 작품 차원 강도 평가는 시장 진입 결정 시점에만. 발상·탐색 단계에서는 좌표 정리만
4. **클코 자기 학습 시점을 별도로 인지.** "아, 이런 거구나"는 클코의 첫 인지지 사용자의 첫 깨달음이 아님. 명시 구분

## 적용 범위
- 인생 트랙 (movie 프로젝트): 작가성 발견·자전적 공유 등에서 자주 발생 가능
- 운영 트랙 (콜마당): 본인이 이미 결정했던 운영 방향을 클코가 처음 정리하면서 "통찰적 결정" 식으로 다루지 말 것
- 본 에이전시 차원 작동 원칙. 매 응답 시 사용자 톤 1회 점검 후 답변 톤 정합 확인
