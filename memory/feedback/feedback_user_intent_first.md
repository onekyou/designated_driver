---
name: 사용자 명시 의도를 추측 우회로 대체 금지
description: 사용자가 "외부 자료/데이터/사전" 을 명시하면 추측 변형 만들기 금지. 데이터 확보부터 진행.
type: feedback
---

규칙: 사용자가 명시한 작업 의도(특히 "외부 자료/데이터/사전/말뭉치 참고") 를 추측 기반 옵션으로 대체하지 말 것.

**Why**: 2026-04-26 세션에서 사용자가 일관되게 "외부 오픈소스 데이터(Kiwi/NIKL/AI Hub) 흡수로 룰·테스트 케이스 확장" 의도를 명시했음. 그럼에도 Tier 2 작업 시 내가 머릿속 추측 변형 목록("까정/꺼정/거쳐/거치") 을 plan 으로 옮기는 실수를 했고, 사용자 정정 후 plan 폐기 + Phase B (Kiwi 데이터 흡수) 로 재정렬. 같은 패턴 ("사용자가 명확히 말한 의도를 무시하고 내 머리속 옵션으로 우회") 이 이번 대화에서 여러 번 반복됨.

**How to apply**:
- 사용자가 "외부 자료/오픈소스/데이터/사전/말뭉치" 같은 표현 쓰면 추측 우회 금지.
- 데이터 출처 미확보 상태면 "출처 없음" 사실 그대로 보고하고 데이터 확보 단계부터 진행.
- 머릿속 "있을 법한 변형" 으로 plan/테스트 케이스/룰 채우지 말 것.
- 같은 용어 (예: "Tier 2") 가 추측 룰 확장 vs 데이터 기반 확장 둘 다 의미할 수 있음 — 사용자 발언 맥락에서 데이터 의도가 명시되었으면 후자로 해석.
- 내 plan 의 모든 변형/테스트 케이스/룰 항목은 "출처" 명시 가능해야 함 (한국어 표준 / Kiwi 사전 / NIKL / AI Hub / 박상준 데이터 등). 출처 명시 못 하면 그 항목은 plan 에 넣지 말 것.
