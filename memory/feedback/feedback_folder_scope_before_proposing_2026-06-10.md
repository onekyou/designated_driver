# "다음 할일" 제시 전 = 폴더 필터 + 선결 필터 (현저성 ≠ 실행가능성)

**2026-06-10 발생.** designated_driver 세션에서 "오늘 할일?"에 답하며, **미용실 통화예약(coupon_app 트랙)**을 "본류 Track B / 오늘 할일 옵션"으로 제시함. 원규씨 지적("왜 여기서 미용실이 나오지?") → 폴더 카테고리 혼동.

## 무엇이 틀렸나 (프레이밍 오류 — 정보 오류 아님)
- 미용실이 **본류인 건 사실**. 틀린 건 그걸 *이 폴더(designated_driver) 세션의 오늘 할일*로 제시한 **스코프/프레이밍**.
- 미용실 통화예약의 실제 작업 자리 = **coupon_app(로컬마루)**. designated_driver는 엔진을 검증한 **부품창고**일 뿐, 미용실 표면 짓는 자리 아님.

## Why (3겹 원인)
1. **결정 대장 평면 나열**: `designated_drive/_decisions.md`에는 PTT(대리, 이 폴더) + 통화예약 엔진 결정이 **둘 다** 산다(엔진을 여기서 검증했으므로). 로그의 열린 [잠정]을 전부 "오늘 할일"로 직역함.
2. **현저성 편향**: 6/9 밤2~밤3(미용실 전환)이 가장 최근·강조된 항목 → "현저한 것"을 "지금 할 일"로 착각. salience를 actionability로 바꿔치기.
3. **두 필터 누락(바닥)**: (a) 폴더 경계 — coupon_app 일을 여기 세션에 섞음. CLAUDE.md "두 폴더 오갈 때 착각 금지" 경고를 들고도 *역방향*으로 밟음. (b) 선결조건 — 미용실 GO바(현장 확보) 미확보라 "오늘 당장" 성립 불가.

## How to apply (제시 전 강제 2필터)
"다음 할일/오늘 할일"을 제시하기 **전에**, 후보마다:
1. **폴더 필터** — 실제 실행 자리가 *현재 작업 폴더*인가? 다른 폴더(coupon_app 등)면 "여기 작업 아님 — 별 폴더"로 **분리 명시**, 세션 할일 큐에 안 섞는다.
2. **선결 필터** — GO바·승인·선결 미충족이면 "오늘"이 아니라 "선결 충족 후"로 라벨. 미확보 선결 걸린 트랙은 "오늘 할일"로 제시 금지.
3. **우선순위 판정 금지(같은 날 2차 교훈)** — 남은 작업을 "must-do / 안 해도 됨"으로 **클코가 임의 등급화 금지**. 우선순위·필요성 판정 = **원규씨 종결권**(헌장). 클코 역할 = 상태·트레이드오프·비용을 *사실대로 제시*까지, "이건 안 해도 됨"으로 **강등은 월권**. (2026-06-10 채팅 블랙박스 9-B를 "인지 보험이라 nice-to-have"로 강등 → 원규씨 "판정하는 게 아니야, 반드시 해야 하는 거야" 기각.)

핵심: **결정 대장 = "무엇이 확정/잠정/열림"의 저장소지, "이 폴더에서 지금 뭘 하나"의 큐가 아니다. 현저성 ≠ 실행가능성. 그리고 "할지 말지"는 내 판정이 아니라 원규씨 종결.**
