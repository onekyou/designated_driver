최종 목표: 2000개 사무실 운영 규모의 플랫폼.

**Why:** 현재는 개발/테스트 단계라 기기 3대지만, 이것은 개발 환경일 뿐 프로젝트 자체는 대규모 SaaS 플랫폼을 지향함.

**How to apply:** 배포, 아키텍처, 비용 관련 논의 시 "소규모"라고 단정하지 말 것. 항상 2000개 사무실 확장을 전제로 판단할 것. 예: 앱 배포 방식 → 수천 명 대상 배포 가능한 방법 기준으로 추천.
