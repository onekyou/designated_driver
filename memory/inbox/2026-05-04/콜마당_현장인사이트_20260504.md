## 오늘의 핵심 유레카

> **말이 아니라 경험으로 바꾼다.**

## 1. 현장에서 깨달은 것 — 사람은 안 바뀐다

- 기존 시스템이 번거로워도, 더 효율적인 걸 알려줘도, 거기서 벗어나기 어려움
- 이유는 본능적인 것 — 아무리 일주일 알려줘도 급하면 옛 방식으로 돌아감
- **스트레스 받으면 뇌는 무조건 익숙한 것으로 돌아간다**
- 설명 → 이중 사용 → 결국 옛 방식. 이게 반복되는 패턴

### 결론
기능 설명은 에너지 낭비. 콜마당이 없으면 못 받는 콜을 만드는 것이 핵심.  
**탈출구 차단** — 좋은 의미로.

---

## 2. 파일럿 사무실 사장에게서 얻은 힌트

### 힌트 1 — 돈이 된다는 인식만 전달하면 된다
- "이게 편해요" → 무관심
- "이게 돈 돼요" → 스스로 움직임
- 기능 설명이 아니라 **돈이 된다는 인식 하나**면 충분

### 힌트 2 — 네가 정하면 손님 오면 다 따른다
- 플랫폼 규칙은 손님이 결정함. 기사나 사무실이 아니라
- 의견 청취가 오히려 독 — 기득권 목소리가 제일 크고, 청취하다 기존 구조를 닮아감
- **"내가 정해. 손님 오면 다 따라와."**

### 힌트 3 — 비전의 락인
- 이해도가 생긴 사장이 최종 목표까지 **스스로 자기 생각인 양 확대함**
- 설득한 게 아니라 그 사람 안에 심어진 것 — 진짜 락인

---

## 3. 플랫폼 착취의 구조

- 로지: 25% 외부 유출, 그 중 15%를 콜 제공자에게 돌려줌 → 10%는 서울로, 15%는 콜 장악 권력화에 사용
- 사무실 사장 제안: 수수료 0, 15%는 지역 내 기사끼리 순환 → 외부 유출 없음
- 그러나 **지역 순환이어도 콜 많이 가진 사람이 구조적 우위** → 시간이 지나면 "지역 내 로지"

### 핵심 통찰
- 착취가 오래되면 그게 정상인 줄 안다
- 25% 떼이는 게 당연한 구조인 줄 알고, 15% 받으면 잘 된 거라고 자위함
- 플랫폼을 욕하면서도 그 힘이 생기면 똑같이 폭력적으로 변모
- **구조가 사람을 그렇게 만든다**

### 해결책
- 원규씨 선의에 기대는 구조가 아니라 **원규씨도 못 건드리는 구조**
- 블록체인: 사람이 아니라 설계가 윤리를 지키게 하는 것
- 배차 우선순위가 사람이 아니라 알고리즘+투명한 규칙으로 고정

---

## 4. 방구석 여포의 전환

**기존 패러다임 (방구석 여포)**
- 수동적 대기 — 식당이 불러주기만 기다림
- 기능 많이 넣기 — 배려가 오히려 교육의 족쇄
- 사무실 설득 → 기사 설득 → 손님 유입
- 종속적인 업자들을 설득하려 함

**새 패러다임 (능동적 영업)**
- 손님 직접 확보 → 사무실이 알아서 들어옴
- 기능 빼기, 설명 빼기, 설득 빼기
- 손님 한 명 확보하는 순간 자산이 생기는 구조
- **원규씨가 직접 본보기를 보여주면 숫자가 말한다**

## 5. 오늘의 영업 전략

### 게릴라 손님 확보
- 번화가 중심 / 주차장 인근 상점에 풍선 입간판 — 저녁에만 설치
- 상점에 작은 수수료 제공 → 거절할 이유 없음
- 앱 설치 시 5,000원 할인 + 5,000원 포인트 적립

### 동선 연결
식당 밥 먹고 포인트 쌓임 → 나오다 입간판 보고 앱 설치 → 대리 부름 → 귀가  
**식당에서 시작해서 귀가까지 한 동선**

### 핵심 자산
- 양평 길목을 다 알고 있음 — 로지가 절대 못 하는 것
- 외부 플랫폼이 아닌 **지역 사람이 직접 치고 들어가는 구조**

## 6. 수익 구조

### 콜당 수익
| 항목 | 금액 |
|------|------|
| 평균 콜 요금 | 15,000~50,000원 (평균 20,000원) |
| 원규씨 10% | 2,000원/콜 |
| 식당 피드백 | -1,000원/콜 |
| **순수익** | **1,000~2,000원/콜** |

### 구독료
- 사무실당 월 2만원
- 지역당 최소 5개 사무실

### 전국 200개 지역 풀 가동 시
| 항목 | 월 수익 |
|------|--------|
| 구독료 200지역 × 5개 × 2만원 | 2,000만원 |
| 콜 수익 200지역 × 20콜 × 1,000원 × 30일 | 1,200만원 |
| **합계** | **3,200만원** |

### 중요한 것
- 구독료 = 자는 동안 들어오는 돈 (자산 수익)
- 콜 수익 = 입간판이 영업하는 동안 들어오는 돈
- **원규씨는 다음 지역으로**

## 7. 블록체인 / 포인트

- 암호화폐가 아니라 **블록체인의 속성만 가져오는 것**
- 포인트가 블록화되면 → 조작 불가, 신뢰 확보
- 원규씨도 못 건드리는 구조 → 권력화 방지
- 대리 포인트 → 배달에서 사용, 식당 쿠폰 → 대리에서 사용
- **손님이 생태계 밖으로 나갈 이유가 없어짐**

## 8. 확장 로드맵

```
1단계 — 지금 (양평 파일럿)
입간판 + 앱 인센티브 → 손님 확보 → 콜 10% + 구독료
작은 비용으로 실험 → 100~200만원 이내

2단계 — 검증 후
사원 고용 → 배달 앱 추가 → 같은 손님 풀 재활용

3단계 — 확장
쿠폰앱 → 지역 지갑 → 양평 동네 생활 OS
대리 = 첫 케이스, 배달/쿠폰/지역화폐 = OS 위 앱들

4단계 — 전국 200개 지역 복사
양평 모델 증명 → 지역마다 입간판 → 자동으로 돌아가는 구조
```
