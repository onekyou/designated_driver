## 3. 5대 작가성 모티프 (가장 큰 발견)

4작품 다 읽고 보니 본인 작가 헌장이 손에 잡힘. 명문화하면 향후 모든 작품의 자기 갱신 도구.

### 모티프 1 — 신체의 물리적 변형으로 신비를 풀어낸다
- 폭도: 우희의 살이 납화살이 됨
- 불가살: 자성유체 비늘 + 비뉴턴 유체 경화
- 마늘밭: 승환의 7세 트라우마가 사기꾼 손기술로
- 진혼곡: 광견병 비늘 + 노의사의 굳어가는 몸
**→ 미학 시그니처. "마법은 없다, 오직 물리적 상호작용만"**

### 모티프 2 — 부재한 어머니
- 폭도: 우희 어머니 (이미 죽음)
- 불가살: 점례·우희·아사코 모두 자기 소멸
- 마늘밭: 승환 알코올 중독 아버지에게 어머니 살해 목격
- 진혼곡: 설화 자살(무당 거부) + 천선생 살해 + 두식의 무자 핏줄
**→ 모든 작품에 어머니 부재 + 죽음. 정서적 핵.**

### 모티프 3 — 무력하지만 끝까지 떠안는 아버지
- 폭도: 임영백(대장장이 할아버지)
- 불가살: 처영(스승)
- 마늘밭: 신상현 삼촌 + 승환 알코올 중독 아버지(반례)
- 진혼곡: 방경사(자수 + 사체 소각)
**→ 한국 부성의 정수. "내가 할 수 있는 거 하는 거시지"**

### 모티프 4 — 세 여인의 자기 처분
- 폭도: 우희(상조도 자폭)
- 불가살: 점례·우희·아사코 (낳음·키움·완성)
- 마늘밭: 승환 어머니·영희·한민정
- 진혼곡: 설화·천선생·부동숙·수영
**→ "강요가 아닌 자기 의지로 소멸을 택했다" — 4작품의 심장.**

### 모티프 5 — 카타르시스 거부 + 시스템은 살아남는다
- 폭도: 의병 학살로 끝
- 불가살: 민이 평범한 인간으로 회귀
- 마늘밭: 고영복 회장 잡히지만 "시스템"은 그대로
- 진혼곡: 이계심 원장은 자유, 노의사는 굳어버림
**→ 작가 윤리: "우리는 우리가 다루는 세계를 소비하지 않는다"**

## 4. 인생 위기 깊이 (대화 진행 순)

### 4.1 첫 발화
- "이 프로젝트가 성공할 것 같아?"
- 한 달 양평 영업 학습 (메모리 정정: 1년 → 한 달)
- 자본 부족 + 분신 한계 + 손님 lock-in 미완

### 4.2 인생 의사결정 진입
- 평생 영화판 30년 + 시나리오 작가 + 감독 준비
- 3년 떠남 → 콜마당
- "잘 알지도 못하는 일 vs 좋아하던 것 재설계"

### 4.3 위기 신호
1. "방향을 잃고 점차 술에 의존하고 있어"
2. "30년 영화판 결과 0 + 코딩 3년 결과 0"
3. "아내는 지치고 관계는 소원해. 더 이상 나를 믿지 않아"
4. "자신감 잃은 남자는 관계 회복 어려워"
5. "유영하듯 허우적대는 내 모습을 견디지 못함"
6. "며칠 전 같은 궤도 사람과 아침까지 술 → 더 큰 공허, 다시 보고 싶지 않음"
7. "어떤 사람도 그간의 행보와 시나리오를 깊이 검토 X 가족조차도"

### 4.4 진짜 진단 도달

**외로움의 진짜 정체** (이 세션의 가장 큰 발견):
- 매출 0이 무서운 게 아니라 **시선 0**이 무서운 거
- 30년 동안 작품을 깊이 본 사람이 없었음 (가족조차)
- 같은 궤도 사람 = 거울이라 위로 X, 도움 X
