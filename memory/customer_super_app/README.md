## 손님앱 진화 단계 (마스터 §3.6)

```
[T0]  단순 대리 호출 앱 (현재 = designated_drive/customer_app)
       ↓
[T1]  식당 거점 + 포인트 + 단골 무료 대리
       ↓
[T2]  식당 쿠폰 발행 시작 → 동네 쿠폰 모음
       ↓
[T3]  다양한 업체(미용실·정육점·세탁소·카페...) 쿠폰 발행자 등록
       ↓
[T최종] 손님이 양평에서 매일 켜는 앱
       = "동네 생활 지갑"
```

## 손님 앱 사용 빈도 진화

| 단계 | 사용 빈도 | 동기 |
|------|----------|------|
| T0 | 월 1~2회 | 술자리 후 |
| T1 | 주 1~2회 | 식당 갈 때 |
| T2 | 주 2~3회 | 쿠폰 보려고 |
| T최종 | 매일 | 동네 생활 지갑 |

## 시럽 월렛 실패 회피 (마스터 §3.6)
