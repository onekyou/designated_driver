플랜모드에서 논의한 내용은 반드시 메모리 파일로 저장할 것.

**Why:** 2026-03-13 세션에서 자동로그인 관련 플랜 논의 후 "저장한다"고 했으나 실제 Write가 실행되지 않아 내용이 유실됨. 사용자가 다음 세션에서 이어서 작업하려 했으나 아무 기록이 없었음.

**How to apply:**
1. 플랜모드에서 중요한 논의/결정이 나오면 즉시 메모리 파일에 저장 (말만 하지 말고 Write 도구 실행 확인)
2. 세션 종료 전 "저장해줘"라는 요청이 있으면 반드시 Write 실행 후 결과 확인
3. 미구현 플랜은 `pending-work.md`에도 추가
