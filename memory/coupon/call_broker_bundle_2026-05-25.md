# 5/25 콜 브로커 모델 — 쿠폰앱 식당 영업의 협상 카드로 재정의

> 5/19 [[pivot-2026-05-19]] 콜마당 휴면 정책의 **부분 해제**.
> 콜마당이 *단독 부활*하는 것이 아니라, *식당앱 그릇 안의 한 줄기*로 재진입.
> 쿠폰앱 우선 결정은 그대로 (5/19 §본 트랙 유지).

## 한 줄 요약
콜 브로커 = 독립 수익 사업 X, **식당 영업의 협상 카드**. 양평 = N=1 증명 거점 (수익 거점 X). 식당앱 한 그릇에 쿠폰 + 콜 5% 환원 + 포인트 묶음 깔기.

## 결정 트레일 (대화 흐름 보존)

본인 진입 발화: "이대로 방치하기는 아까워서 그래. 양평 콜 시스템·관계 자산을 어떻게 살릴까."

대화 도달 그림 (단계별):
1. 로지처럼 공유콜 단일 모드로 축소 → 매니저 수동 + 손님 웹앱 → 공유콜 풀 → 양평 등록 기사 잡기 (CallDetector 비활성화)
2. 사무실은 공유콜 15% 지급 용의 있음 (시장 관행) → 본인 10% + 식당 5% 분배 구조
3. 평균 단가 2만원 → 콜당 본인 몫 2,000원
4. 광고 CAC 1.5만원 → 손익분기 7.5콜 → 체리피커 비율 적자 위험 (광고 비효율 확정)
5. 양평 하루 <20콜 → 단독 수익 사업 미달 → **광역 모델이 본업, 양평은 증명 거점**
6. **본인 진짜 저의 노출**: "쿠폰앱 영업 시 해당 식당을 묶어서 할까라는 저의가 깔려있어" → 콜 브로커가 *독립 사업이 아니라 영업 협상 카드*임이 명확해짐
7. 따로 영업 vs 묶음 영업 — 묶음이 유리하되 영업 *멘트*는 단계적이어야 함

## 재무 골격 (양평 단독)

| 항목 | 값 |
|------|----|
| 콜 평균 단가 | 20,000원 |
| 사무실 공유료 | 15% = 3,000원/콜 (시장 관행, 협상 0) |
| 식당 환원 | 5% = 1,000원/콜 |
| 본인 몫 | 10% = 2,000원/콜 |
| 양평 일일 콜 | <20콜 추정 (1년 영업 학습 기반) |
| 본인 월 매출 | <120만원 (하루 20콜 가정) |

**결론**: 양평 단독 = 단독 수익 사업 X. *알바 수익* 수준. 본인 시간 풀로 갈아넣을 그림 아님.

콜 브로커는 본질적으로 **광역 모델** — 양평·서종·강하·옥천·용문 다수 군이 같은 인프라에 묶여야 의미 있는 수익.

## 광고 효율 (확정 결론: 광고 비효율)

- CAC(가입자 1명 광고비) = 1만원 할인 + 5,000원 포인트 = **15,000원**
- 손익분기 콜 수 = 15,000 / 2,000 = **7.5콜**
- 양평 동네 단골 시장이면 가능한 숫자이긴 하나, *광고로 사는* 풀은 체리피커 비율이 높음 → 단발 가입자 다수, 평균 LTV가 CAC 못 따라감
- **반대로 식당 거점으로 흘러드는 가입 = 식당 단골, 신뢰 기반 진입, LTV 높음**
- 같은 "신규 가입자 1명"이라도 *유입 채널에 따라 LTV 완전히 다름*

**행동 원칙**:
- 광고 예산은 *식당 보급 예산*으로 옮김
- 단가 2만원에 마진 2,000원인 모델은 카카오·로지처럼 광고 태우면 안 됨 (자본력 다름, 단가 다름, 빈도 다름)
- 식당이 우리 광고판이 되는 구조 — 우리 단가에 맞는 *유일한 채널*
- 광고를 굳이 한다면 "할인은 첫 콜 완료 후 다음 콜에 적용" 같은 조건부 자연 필터링 + 금액 다운사이즈 (CAC 7,000원대 → 손익분기 3.5콜)

## 식당 영업 전략 — 묶음 깔기 + 멘트 단계적

**왜 묶음인가**: 우리 무기를 각각 떼면 다 약함.
- 쿠폰만 = 카카오·망고·캐치테이블이 다 함 (차별화 X)
- 콜 5% 환원만 = 식당당 월 2만원 수준 (금액 약함)
- 포인트만 = 직관적 매력 약함
- 셋 묶음 = *우리만 할 수 있는 영업 멘트* — 카카오도 못 따라옴 (콜 인프라 없음)

**왜 멘트는 단계적인가**: 묶음 다 한 번에 설명하면 식당 사장님 정보 과부하 → "복잡하네 나중에" → 약한 부품이 강한 부품 인상을 깎음.

영업 매뉴얼 (반복 가능한 구조):
- **1단 진입 = 쿠폰** — 익숙한 가치, 5분 설명, *그 자리 결정* 가능. "사장님 매출 직접 도움 되는 거 하나 깔아드리려고요"로 문 열기
- **2단 차별화 = 콜 5% 환원** — *깔린 다음에* 꺼냄. "사장님 통해 가입한 손님이 평생 대리비 부르면 5%가 자동 입금됩니다. 다른 쿠폰 서비스 못하는 거예요" → 우리만의 임팩트
- **3단 깊이 = 포인트** — 운영 1~2주 후 자연스럽게

**설치는 한 번에 묶음, 활성화·설명은 분산**. 식당 1곳에 3번 가는 게 아니라 1번 방문으로 끝.

## 식당 4중 노드 비전 — 처음으로 영업 멘트로 실증

콜마당 마스터 §3.4 "식당 = 4중 노드 (호출/포인트/거점/쿠폰)"가 그동안 *추상 비전*이었으나, 5/25 결정으로 **구체 영업 멘트**로 떨어짐:

> "사장님 통해 가입한 손님이 평생 대리비 부르면 그 5%가 매달 자동 입금됩니다."

이게 작동하는 이유:
1. 식당 사장님 입장 추가 비용 = 0 (어차피 손님들 대리 부름, 그게 우리 채널로 가면 5% 떨어짐)
2. *손님 한 번 가입 = 평생 단골 채널*. 식당 사장님의 손님 단골화 직접 동기 폭발
3. 카카오·망고 못 따라옴 (콜 인프라 없음) → 우리만의 차별화

**전제 (코드에서 받쳐줘야 작동)**:
- 손님 어느 식당 통해 가입했는지 *영구 귀속 추적* — customer_app Install Referrer 자동 매칭으로 이미 깔려있음 ([[abundant-floating-island]])
- 식당 사장님이 *내 환원 누적 금액* 식당앱에서 바로 확인 + 인출 — 5/4 P0 plan 포인트 결제 풀 그릇에 콜 환원 대시보드 추가

## 양평 역할 재정의

5/8 §13.3 "N=1 인큐베이션 사무실"의 *진짜 의미*가 5/25에 또렷해짐:

- 양평 = **수익 거점 X, *N=1 증명 거점***
- 콜 브로커 단독 수익은 *광역 보급 단계*에서 본격화
- 양평에서 할 일:
  - 식당 4중 노드가 *실제로 식당 매출에 도움 되는지* 데이터 확인
  - 손님이 *식당 권유로 진짜 들어오는지* 진입 데이터 확인
  - 식당이 *손님한테 진짜 권하는지* 거점 행동 데이터 확인
- 이 3개 데이터가 모이면 다른 군 보급 시 *팩트로 영업* 가능. 안 되면 모델 재설계.
- **무리해서 콜 수 늘리려 광고 태우거나 본인 시간 다 갈아넣을 필요 X** — 양평은 살려두기 + 증명하기

## 클코 학습 (본 세션 4건)

### 1. "최소 운영 파이프라인" 단어 그대로 받지 말 것
- 콜 브로커는 본질적으로 *매일 손님 영업해야 도는 수동 채널*. 식당 거점 없이는 본인이 1인 콜센터 + 1인 영업이 됨.
- **Why**: "최소"라는 단어가 *진짜 최소*가 되려면 자동 유입 채널이 있어야 함. 식당이 5% 동기로 자발적 노출하는 구조여야 비로소 본인이 매일 영업 안 해도 콜이 흘러들어옴.
- **How to apply**: 사용자가 "최소", "파이프라인", "자동" 같은 단어 쓸 때 → *진짜로 자동인 메커니즘이 있는가* 한 단계 더 짚을 것. 추상 단어로 통과시키지 말 것.

### 2. 사용자가 도달한 자리를 *부정 없이 확장*해 본인 마스터/plan과 연결할 것
- 본인이 도달한 콜 브로커 모델 = 콜마당 마스터 §3.4 식당 4중 노드 비전 + 5/4 P0 plan `abundant-floating-island.md`와 *같은 자리*. 다른 입구로 도달.
- **Why**: 본인이 자력으로 도달한 결론은 *외부 권장보다 가볍게 받아들이고 실행함*. 기존 plan에 끼워 맞추려고 부정하면 *본인 도달의 신뢰감*이 깎임.
- **How to apply**: 본인 결론과 기존 plan이 같은 자리라면 → "본인 도달이 맞고, 기존 plan과 같은 그릇"으로 *추상화해서 연결*. 한쪽을 덮어쓰지 말 것.

### 3. 광고비 단가 모델은 *우리 마진 구조*에 어울리지 않을 수 있음
- 단가 2만원 × 마진 10% = 콜당 2,000원 모델은 광고 CAC 1.5만원을 못 견딤. 카카오·로지는 자본력 + 단가 + 빈도가 다 다름.
- **Why**: 같은 시장처럼 보여도 *수익 구조 단위*가 다르면 같은 마케팅 전술이 적자 만듦.
- **How to apply**: 비교 사례 가져올 때 *단위 경제(unit economics)*가 같은지 먼저 확인. 익숙한 전술이어도 우리 단가·마진·CAC 시뮬레이션해서 손익분기 콜 수 떨어뜨려볼 것.

### 4. "본인 저의" 발화가 *진짜 의사결정의 본질*
- 본인이 처음에 "축소 운영 콜마당", "최소 파이프라인"으로 그림 시작 → 대화 중반 *"쿠폰앱 영업 시 식당을 묶어서 할까라는 저의가 깔려있어"* 발화가 진짜 본질이었음.
- **Why**: 본인이 *진짜 의도*를 첫 발화로 드러내는 경우 드뭄. 대화가 무르익으면서 *저의*가 노출됨. 그 저의가 모델 전체를 재해석하게 함.
- **How to apply**: 본인이 *추가로 속마음 꺼내는 순간* = 결정의 본질 노출 시점. 그 시점 이전 모든 분석을 *그 저의로 재정렬*해서 보고할 것. 첫 발화에 묶여있지 말 것.
