## ★ 우리의 3대 강점

### ① 데이터 주권 — *코드*가 강제

> 손님이 가게 QR로 들어오면 → **그 손님은 영구히 그 가게의 자산**.
> Firebase Security Rules로 *코드 차원에서 강제* — 플랫폼 관리자도 접근 차단.
> **해지해도 사장님이 손님 데이터 그대로 보유**.

```
[중앙 플랫폼]                           [콜마당]
손님 = 플랫폼 자산           ◄────►     손님 = 가게 자산
가게 = 채널 임대인                       가게 = OS의 주인
약관으로 보호                            코드로 강제
```

### ② 디지털 소외 포용 — *전화*만 받아도 자동 CRM

> 앱 미사용 50대 이상 군민이 *평소처럼 전화*만 걸어도
> 시스템이 자동 인식 → 포인트 적립 + 단골 등록.
> **학습 비용 0**. (특허 청구항 4)

### ③ 자생 무수수료 — *구독료 1만원만*

> 거래 수수료 0. 광고비 0. 데이터 판매 0.
> 가게가 내는 건 **월 1만원 미만 실비**만.
> **보조금 없이 자생** — 공공배달앱(F2 실패) 회피.
