## 1. 발명 한 줄 정의

**컨텍스트 자동 진입 손님 OS + NFC 도장 인터페이스**.
손님 단일 앱이 가게마다 다른 컨텍스트(쿠폰·메뉴·예약·후기·배달)로 자동 활성되는 OS를, 점주가 손님 폰 화면 위에 도장을 1회 찍는 0차 물리 행위로 가입·귀속·적립을 동시 트리거하는 시스템.

|---|---|---|

## 4. 기술 차별점 3가지

### 4.1 0차 인터페이스 (1차 동작 제거)
- 점주: 30년 사용한 도장 손짓 그대로 유지. 카메라 조준·앱 메뉴 진입 등 디지털 학습 부담 0
- 손님: 손님앱 켜고 화면 내밀기만. QR 스캔에 필요한 카메라 활성화·조준·초점 같은 1차 동작 없음
- 결과: 영세 점주·디지털 비네이티브 손님 양측의 진입 마찰을 동시에 제거

### 4.2 NFC 동적 OTP (정적 인쇄 QR과의 차별)
- 도장 NFC IC가 매 회 HMAC-SHA256 기반 일회성 토큰을 동적 생성 (도장 ID + 시간 윈도우 + nonce)
- URL 형식 예: `https://callmadang.app/r/{officeId}/{otp_token}`
- 정적 인쇄 QR이 갖는 사진 캡처·복제·도용 위험 제거
- 도장 분실 시 서버 측 토큰 거부만으로 즉시 무효화 가능 (물리 회수 불요)
- 시각적 노출이 없어 OTP 캡처 도용 위험 0

### 4.3 referrer 자동 귀속 + 컨텍스트 자동 진입
- 도장 NFC 토큰이 손님 단말에 전달 → 미설치 시 Install Referrer 경로, 설치 시 DeepLink 경로로 동일 토큰을 서버가 검증 → **앱 설치/미설치를 분기 처리하면서 귀속 노드(점포)를 자동 결정**
- 같은 손님앱이 도장 토큰의 officeId에 따라 가게별 컨텍스트(쿠폰·메뉴·예약·후기·배달)로 자동 활성
- 점주 측 BLE 페어링으로 officeId가 동적 갱신 가능 → 도장 교체·점포 이전 시 귀속 노드 동기 유지

### 4.4 (참고) 회피 설계
- 정전식 멀티터치·음파 방식은 동종 업계 등록 특허군과 청구범위 충돌 가능성 존재 → **NFC 단독 채택으로 해당 영역 회피**
- 1건의 만료 특허(정적 QR/NFC 도장 적립, 2020년 효력 상실 — 추정)와 청구범위 무관
- 동종 업계 17건 포트폴리오 보유 권리자가 알려져 있으며 정전식·음파 영역 중심으로 추정 — 본 자문에서 정확한 권리범위·NFC 영역 충돌 가능성 확인 필요

## 5. 청구항 후보 3건 (출원 중인 referrer 귀속 특허 보강 또는 신규 출원)

### 5.1 종속항 후보 1 — 물리적 발생 장치 결합
"제1항의 referrer 귀속 시스템에 있어서, 상기 referrer 토큰을 발생시키는 수단이 **점주가 손님 단말 화면 위에 접촉·근접시키는 물리적 도장 장치**이며, 상기 도장 장치는 NFC IC와 시간 기반 동적 토큰 생성 수단을 포함하는 것을 특징으로 하는 referrer 귀속 시스템."

### 5.2 방법청구항 후보 2 — 설치/미설치 분기 처리
"점주 도장 장치의 NFC 토큰 발생 → 손님 단말의 NFC 수신 → 손님 앱 미설치 시 앱 마켓 경유 Install Referrer 토큰 전달, 설치 시 DeepLink 토큰 전달 → 서버 측 토큰 검증 → 검증 결과에 따라 **귀속 노드(점포 식별자)를 자동 결정 또는 갱신**하는 단계를 포함하는 referrer 귀속 방법."

### 5.3 종속항 후보 3 — 점주 단말 BLE 페어링을 통한 동적 갱신
"제1항의 도장 장치에 있어서, 점주 단말과의 무선 근거리 통신(BLE) 페어링을 통해 상기 도장 장치 내 사무실 식별자(officeId)와 비밀 시드가 갱신 가능하며, 갱신 시점에 서버 측 귀속 노드 매핑이 동기화되는 것을 특징으로 하는 도장 장치 및 그 운용 방법."
