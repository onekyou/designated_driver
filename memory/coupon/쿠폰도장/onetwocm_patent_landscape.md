# 원투씨엠 주식회사 특허 포트폴리오 정리 자료

**작성일**: 2026-05-15
**작성자**: 클코 (본 에이전시) — 원규씨 변리사 자문 미팅 자료용
**출처**: Google Patents 각 특허 페이지 직접 조회 (2026-05-15)
**전제**: 본인 발명 = NFC 단독 채택 (정전식·음파·카메라 채널 미사용). 본 자료의 평가 축은 *NFC 단독 채택 시 회피 가능성*에 한정
**주의**: 17건 중 3건은 사용자가 제시한 특허번호의 실제 권리자가 원투씨엠이 아닌 다른 법인(비즈모델라인 2건, 엔에이치엔고도 1건, LG전자 1건)으로 확인됨 — *원투씨엠 한국 법인 기준* 검증 결과 표에 명시

## 1. 요약 (1줄)

원투씨엠 핵심 청구항은 *정전식 다중 터치 점의 기하학적 관계 매칭* 1축 + *광학(카메라)·역방향 인증·골프 응용*으로 확장된 변형 — **NFC 단독 채택 시 청구항 1번 구성요건(정전식 터치 입력부의 N개 동시 터치점 인식 + 기하학적 관계 매칭) 자체에 미해당하여 원투씨엠 17건 중 12건의 직접 침해 가능성은 낮음**. 단 역방향 인증(KR102582768B1) + 광학 스탬프(KR102597951B1)는 청구항 표현이 정전식에 *한정되지 않은* 자리가 있어 변리사 검토 필요.

## 3. NFC 단독 채택 시 회피 가능 영역 정리

### 3.1 정전식 다중 터치 구성요건 미해당 — 회피 자동 성립 (12건)

원투씨엠 Active 5건 중 4건의 청구항 1번이 *정전식 터치 입력부 + N개 동시 터치점 + 기하학적 관계 매칭* 3중 구성요건을 모두 포함:

- KR101495589B1 — "정전식 터치 입력부의 다중 터치점 거리·각도 기하학적 관계"
- KR102652760B1 — "터치스크린에 N개 터치부 모듈 터치"
- KR102569800B1 — "다중 터치 인식 터치스크린에서 N개 터치부 터치모듈"
- KR102582768B1 — "터치스크린의 N개 다중 터치점이 터치모듈 설계 기하학적 관계와 매칭"

**NFC 단독 채택 시**: 손님 폰의 NFC 안테나가 도장 NFC 칩과 *근거리 무선 통신*으로 OTP를 전달. 터치스크린 표면의 *물리적 터치점*이 발생하지 않음 → 정전식 다중 터치 구성요건 미해당 → 직접 침해 성립 안 됨.

Expired 8건은 권리 소멸로 회피 불필요.

### 3.2 카메라(광학) 구성요건 미해당 — 회피 자동 성립 (1건)

- KR102597951B1 — "카메라로 촬영된 광학 스탬프의 기하학적 관계 이미지 + 인증코드 분석"

**NFC 단독 채택 시**: 카메라 이미지 입력 자체가 발생하지 않음. 화면 시각 코드 캡처 불필요. 회피 성립.

### 3.3 도메인 외 — 회피 자동 성립 (Active 1건 + 타 법인 3건)

- KR102652760B1 (골프 스코어 카드) / KR102569800B1 (골프 버디) — *골프 게임* 한정
- KR102195456B1 (엔에이치엔고도, 안면+모션) — *안면 인식* 도메인
- KR102410211B1 (LG전자, 디스플레이 다중 포인터) — *디스플레이 협업* 도메인

콜마당 *동네 상점 적립* 도메인과 청구항 표현 자체가 부정합.

## 4. NFC 일부 검토 필요 자리 (변리사 확인 요청)

### 4.1 KR102582768B1 (역방향 인증을 이용한 서비스 제공 방법) — 변리사 검토 필요

**상태**: Active (2023-09-21 등록, 2036-02-29 만료)

**청구항 1번 표현 위험 자리**:
- "**역방향 인증**" — 손님 단말이 서버에 *역방향으로* 인증 정보를 제출하여 서비스 받는 구조
- 명세서·종속항에 NFC·BLE 등 *대체 채널*이 명시되어 있는지 확인 필요
- 콜마당 NFC 흐름: 도장 NFC 칩 → 손님 폰 NFC 안테나 → 동적 URL → 손님앱 → 서버 OTP 검증. *역방향 인증* 패턴과 형식 유사성 있음

**변리사 검토 요청 항목**:
1. 청구항 1번의 *터치모듈 설계 기하학적 관계* 구성요건이 NFC 통신 OTP 검증과 균등(Doctrine of Equivalents) 평가될 위험
2. 명세서 도면·실시예에 NFC·BLE 변형이 등장하는지
3. 종속항 중 *광학·NFC·음파 등 다른 채널을 함께 사용하는* 청구항이 있는지
4. 한국 특허법 균등론(균등침해) 4요소 적용 시 본인 발명 침해 평가

### 4.2 KR101495589B1 (Active 1건) — 보조 검토

**상태**: Active (2015-02-26 등록, 2032-11-19 만료, 약 6.5년 잔여)

**검토 요청**: 명세서·도면에 NFC 변형 실시예가 등장하는지. 도장 발명의 *원조* 격 특허로 후속 분할·우선권 자녀 특허 추적 필요.

## 6. 변리사 미팅 핵심 질문 5건

### 6.1 균등론 평가

### 6.2 명세서 확장 가능성
