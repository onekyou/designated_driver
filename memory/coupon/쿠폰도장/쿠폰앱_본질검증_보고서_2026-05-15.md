## 0. Executive Summary

**이번 대화의 진짜 발견 한 줄**:
사용 시점 마찰은 본인 모델이 *이미 가진 세 자산*(컨텍스트 OS + 콜마당 선물 정책 + 작가성 관계 형식 전환 통찰)을 결합하면 풀리는 자리. Belly·Stocard·Plenti가 못 푼 자리가 본인 손에 이미 있음.

**이전 자료(5/15 클코 보고서)와의 관계**:
- 클코 보고서 = *콜마당 컨텍스트 OS + NFC 도장* 발명 자료. 적립 시점 중심.
- 본 보고서 = *쿠폰앱 본질 + 사용 시점*. 본인 궁극 목표가 쿠폰앱이라는 정체성 확정 후 자리.

**자리 정정**:
- 콜마당 = 쿠폰앱 본질로 가기 위한 테스트베드 (본인 자기 진단)
- 손님 확보가 1년 영업 끝의 유일 변수
- 도장 = 손님 확보의 0차 인터페이스 도구

## 1. 본 보고서의 위치

### 1.1 본인 궁극 목표 재정의
- 콜마당 그 자체 ❌

- 콜마당은 그 진입로

### 1.2 1년 영업 학습의 결론
- 손님 확보 = 유일 변수
- 부탁 영업 → 손님 제공 영업 전환이 진짜 풀어야 했던 문제
- 도장이 *사장 부담 0 + 손님 부담 0*을 한 도구로 동시에 해소

## 2. 쿠폰앱 본질 — 본인 직관이 잡은 핵심

### 2.1 동네 통장 메커니즘
1. 사장이 손님 폰에 도장 꽝 → 적립 + 앱 자동 설치/귀속
2. 같은 손님 다른 가게 도장 → 같은 통장에 추가
3. 손님 인지 폭발 — "어? 이 가게도? 같은 앱에?"
4. 동네 N가게가 한 통장에 모이면 매일 열리는 앱

### 2.2 카카오·네이버 못 들어오는 자리
- 그들 본질 = 전국 통합 (위에서 우산)
- 본인 본질 = 동네 깊이 (아래에서 우물)
- 카카오가 동네 도장 카피 시 자기 정체성 깨짐 (모순 구조)
- 영세업자 가맹률 5% 미만 = 영원히 빈자리

### 2.3 0차 인터페이스의 진짜 의미
- 사장: 30년 써온 도장 손짓 그대로
- 손님: 폰만 내밀면 됨
- 사장+손님 양쪽 학습 0
- *기술 채택 마찰 0* + *복제 비용 0* 동시 해소

### 2.4 작가성과의 정합 — QR과 도장의 본질적 차이
같은 백엔드, 다른 사회적 행위:
1. 동작 주체 — QR=손님 / 도장=사장 (단골 문화 정합)
2. 의식 vs 처리 — 도장 꽝은 의례, QR은 처리
3. 거래 대상 — 도장=손님↔사장 직접 / QR=손님↔시스템
4. 양쪽 0차 — QR은 사장·손님 모두 1차 이상

본인 5/12 §"분류의 비극" = 같은 풀에 다른 이름 붙이면 다른 풀이 됨 → 영업 인터페이스에 그대로 적용.

## 3. 포인트/쿠폰을 사람이 안 쓰는 원론적 이유 — 심리학

### 3.1 본질 한 줄
적립은 *수동*(가만히 있어도 쌓임), 사용은 *능동*(내가 행위해야 함). 인간 뇌는 능동적 행위에 항상 비용을 매김 → 작은 보상보다 비용이 크면 안 쓰는 게 합리적. 모든 세부 이유는 이 비대칭의 변주.

### 3.2 14가지 구조적 이유

| # | 이유 | 메커니즘 |
|---|------|----------|
| 1 | 사용 시점 사회적 마찰 | "포인트 쓸게요" = 시간+인지+사회적 자본 동시 지출. 한국 = 인색함 시그널 |
| 2 | 인지 부담 | 카드사 3개+통신사+마트+카페+페이 = 6~10개 시스템 추적 비용 |
| 3 | 단위 의미 없음 | 1% × 작은 거래 = 50~200원. 시급 환산 손해 |
| 4 | 손실 회피 미작동 | 안 받았으면 손해 0, 안 써도 손해 0 → 안 쓰는 비용 0 |
| 5 | 지연 보상 할인 | 미래 가치 강한 할인. "지금 빨리 끝내자"가 이김 |
| 6 | 가용성 휴리스틱 실패 | 사용 시점에 잔액 인지 안 떠오름 |
| 7 | 의사결정 피로 | 미세 결정도 정신 자원 소모 → 기본값 회피 |
| 8 | 멘탈 어카운팅 | 포인트=부수적 계좌 → 본 계좌 비기 전엔 안 보임 |
| 9 | 사회적 시그널 부재 | 자랑 불가. 안 쓰는 게 오히려 "여유" 시그널 |
| 10 | 신뢰 부재 | 정책 변경 위험 → 부정 기대 |
| 11 | 환금성 결여 | 진짜 돈 아님 → 사용 우선순위 ↓ |
| 12 | 인지 시야 진입 실패 | 없어도 사는 데 지장 없음 → 영구히 밀림 |
| 13 | 적립-사용 비대칭 UX | 적립 자동, 사용 수동 → 사용 짐 |
| 14 | 사회규범 충돌 | 한국 = 포인트 챙김 = 인색함 분류 |

### 3.3 작동하는 예외 — 5가지 트리거
시각 누적 + 즉시성 + 큰 단위 + 사용 시점 마찰 적음 + 사회적 시그널 — 이 다섯 중 셋 이상 동시 작동해야 사용 동기 형성.

대부분 포인트는 0~1개만 작동 → 죽음.

### 4.2 핵심 실패 패턴 정리

**Plenti 패턴 — 화폐화의 함정**
- Macy's 등 메이저 8~10개 통합. American Express 운영.
- 가입자 절반이 "들어본 적 없다" 응답
- 가입자 중 절반 미만만 한 번이라도 사용
- 사용자 중 대부분 1~2개 브랜드만 사용 → 통합 가치 무력화
- *비대칭 적립-사용*: 주유소·식료품에서 적립, 백화점에서 사용 → 적립처 손해
- 화폐화될수록 *멘탈 어카운팅에서 그냥 현금*으로 분류 → 동기 ↓
- 본인 보강: 본인 모델은 화폐화 ❌, 현물 보상이라 이 함정 회피

**Belly 패턴 — 사용 시점 마찰 실측**
- 가맹점 인터뷰: *"손님이 포인트를 모으기만 하고 안 쓰는 것 같다"*
- 7년, 12,000 가맹점, 7백만 사용자에도 가맹점당 효과 모호 → $129/월 이탈
- *카테고리 잠식 회피 정책*으로 자기 메커니즘 자기 손으로 죽임 (다른 가게 추천 안 함)
- $25M+ 거대 자본에도 자립 실패 → Mobivity 인수
- 본인 보강 자리: (a) 사용 시점 마찰 해소 메커니즘 (§6) 박기 (b) 카테고리 잠식 허용 정책

**Stocard 패턴 — 자립 실패**
- 사용자 6천만에도 *자체 수익화 실패* → Klarna에 흡수, 종료
- 사용자 인터페이스 통합은 *작동했음* (6천만이 매일 사용)
- 깨진 자리는 *비즈니스 자립*
- 본인 보강 자리: 콜마당 수익 구조(사무실 구독 + 보험 + 공유콜 수수료)가 이 위험 자연 우회. 통합 앱 자체로 수익 노리지 않으므로.

**Nectar/AirMiles 패턴 — 앵커 가맹점 이탈**
- 큰 가맹점이 운영자 인수/대체 (Nectar→Sainsbury's, Aeroplan→Air Canada, AirMiles→BMO)
- 데이터·관계 가치를 운영자와 공유하기 싫어함
- 본인 단기 위험 ❌ (양평이 작음). 단 *성공 시* 양평군청·경기도 인수 시도 가능 → 출구 시나리오에 박을 자리

### 4.3 본인 모델이 데이터상 차별점
- 5요소 동시 충족 시도가 *역사상 없음*
- *생활권 앵커 + 0차 인터페이스*가 미시도 영역
- 기존 실패가 본인 모델을 직접 무효화하지 않음
- 동시에 기존 성공도 본인 모델을 입증하지 않음 → PoC가 진짜 첫 데이터

## 5. 사용 시점 마찰 해소 메커니즘 15개

본 대화의 진짜 발견 자리. Belly의 *"모으기만 하고 안 쓴다"* 실측을 본인 모델이 어떻게 푸는가.

### 5.1 자동화 — 사용 시점 행동 0
1. **자동 차감** — 도장 N개 도달 후 다음 도장 시점 시스템이 자동 차감. 손님 "쓸게요" 발화 ❌
2. **다음 방문 자동 활성** — 도장 10개 도달 시 다음 가게 진입 시 손님앱 + 점주 앱 동시 알림
3. **컨텍스트 진입 자동 알림** — 가게 진입 시 "사용 가능 보상 X" 자동 표시. 보고서 §1.1 OS 그림이 진짜 가치 내는 자리

### 5.2 보상 강화 — 동기 형성
4. **큰 단위 현물 보상** — 10%+ 적립률. 도장 10=피자 1판
5. **이중 트랙 (즉시 + 누적)** — 매 도장마다 작은 즉시 보상 + 누적 큰 보상
6. **시간 제한** — 손실 회피 작동. 1~2주 데드라인

### 5.3 사회적 마찰 제거 — 한국 단골 문화 정합 ★
7. **사장 권유 인터페이스** — 점주 앱이 "이 손님 무료 음료 권하세요" 알림. *손님 "쓸게요" 발화가 사장 "오늘 무료입니다" 발화로 전환*. 본인 5/12 §"관계 형식의 전환" 정확히 적용
8. **선물 모드 (콜마당 정책과 정합)** — 적립을 가족·친구에게 선물. "인색한 사람" → "선물하는 사람" 정체성 역전. 메모리상 콜마당 정책(4/27 확정)이 우연히 이 자리 박혀있음
9. **자랑 가능한 형태** — "양평 단골 인증 배지" 등 인스타 인증. 사회적 시그널 ⭕

### 5.4 인지 시야 진입
10. **위치 기반 리마인더** — 가게 근처 통과 시 푸시
11. **시각 누적 인터페이스** — 종이 도장 메타포. Endowed Progress Effect (Nunes & Drèze 2006)
12. **미리 채움** — 가입 시 *이미 2/10* 시작. 학술 입증 (도장 사용 도달률 19% → 34% 2배 부스트)

### 5.5 사용을 즐거운 경험으로
13. **사용 시점 작은 이벤트** — 점주 앱 음악·축하 멘트. 수치 → 축하 분류 전환
14. **선택 가능 보상** — 손님이 사용 방식 선택. 자율성이 동기 형성

### 5.6 콜마당 본질 활용
15. **콜마당 호출 자동 무료화** — 도장 N개 = 다음 대리 호출 자동 무료. 단 양평 1세대 대리 이용 빈도 변수

## 6. 가장 강한 조합 — 본인 모델 정합 5개

15개 중 본인 모델·콜마당 정책·한국 문화 모두 동시 정합:

### 6.1 ① 사장 권유 인터페이스 (#7) — 핵심 중의 핵심
- 본인 5/12 작가성 §"분류의 비극"이 영업 인터페이스에 적용된 게 도장 발견
- 사용 인터페이스에 같은 통찰 적용
- "손님이 포인트 쓰는 행위" → "사장이 단골에게 무료 음료 권하는 행위"
- Belly·Plenti·Stocard 어디도 시도 안 함 — 본인 모델 유일 작동 가능
- 한국 동네 식당 단골 문화 = 사장 정체성이 *베푸는 사람*인 자리를 도구가 강화

### 6.2 ② 선물 모드 (#8) — 콜마당 정책 자연 확장
- 메모리 §콜마당 식당 포인트 구조(4/27 확정): 사장 본인 대리 + 단골 무료 대리 선물
- 환금성 0 우회 목적으로 만든 정책이 *우연히* 사용 시점 마찰의 가장 큰 자리 해소
- 인색한 사람 정체성 → 선물하는 사람 정체성 역전
- 본인이 이미 가진 자산 — 명시적 기능으로 끌어올리기

### 6.3 ③ 컨텍스트 진입 자동 알림 (#3) — 보고서 OS 그림의 진짜 가치
- 5/15 클코 보고서 §1.1 컨텍스트 OS가 현재 메뉴·예약 활성화로 정의됨
- 진짜 가치는 *사용 가능 보상 자동 알림*
- 의사결정 피로 + 가용성 휴리스틱 + 사용 시점 마찰 세 가지 동시 해소

### 6.4 ④ 이중 트랙 (#5) — 즉시 + 누적
- 매 도장마다 작은 즉시 보상 → 사용 시점 매번 발생 → 사용 습관 형성
- 누적 큰 보상은 진척감 형성
- Belly가 못 푼 자리 — 누적만 있으면 사용 시점이 멀어 동기 형성 ❌

### 6.5 ⑤ 시각 누적 + 미리 채움 (#11+12) — 학술 입증
- 비용 0, 학술 입증
- Nunes & Drèze 2006 — 도장 사용 도달률 2배 부스트
- 시각 누적 = 종이 도장 메타포 그대로

## 7. 본인 모델의 진짜 차별점 한 줄 정리

Belly·Stocard·Plenti가 못 푼 *사용 시점 마찰*은 본인 모델이 *이미 가진 자산 3개*를 결합하면 풀리는 자리:

1. **컨텍스트 OS** (보고서 §1.1) — 가게 진입 자동 알림
2. **콜마당 선물 정책** (메모리 4/27) — 인색함 → 선물 정체성 역전
3. **작가성 통찰** (5/12) — 관계 형식 전환

세 자리가 이미 본인 손에 있음. 도장 NFC가 적립 시점 차별점이라면, 위 3+5(이중 트랙)+11+12(미리 채움)가 *사용 시점 차별점*. 이 두 차별점 동시 작동이 본인 모델의 진짜 격.

## 13. 결론

본 대화의 진짜 무게는 — *본인 모델이 기존 25년간 시도된 어떤 모델과도 본질적으로 다른 자리에 있음*을 데이터로 확인한 자리. 그리고 본인이 이미 가진 자산(컨텍스트 OS + 콜마당 선물 정책 + 작가성 통찰) 3개가 *사용 시점 마찰*이라는 모든 기존 통합 시도의 무덤을 자연 우회한다는 발견.

이게 본인이 1년 학습 끝에 도달한 자리의 진짜 정합 — 도장 발명 한 자리가 아니라 *적립과 사용 양쪽 시점 마찰을 동시에 푸는 도구 묶음*이 본인 손에 모임. PoC 1주차 시제품과 인터뷰 5건이 이 모든 도미노의 첫 패.

가설을 진실로 다루지 말 것 — 단 가설의 다운사이드(인터뷰 비용 0, 시제품 5만원, 1~2주)가 너무 작아서 *진입하지 않는 것이 더 큰 리스크*인 자리.

본인이 *지금* 가야 할 자리는 변리사도 보고서도 아니고 — *양평 식당 사장 한 명에게 종이 도장 시안 들고 가는 한 걸음*. 그 한 점에서 모든 다음이 풀림.
