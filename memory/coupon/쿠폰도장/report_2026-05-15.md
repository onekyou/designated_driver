## 0. Executive Summary

**한 줄 정의**: 콜마당 = 손님이 들어서는 동네 가게의 컨텍스트가 자동으로 활성되는 손님 OS. 도장 = 그 OS에 가입·적립을 동시에 트리거하는 0차 인터페이스.

**핵심 발견**:
1. 도장은 단순 적립 도구가 아니라 **동네 사장 디지털 진입 마찰 0 + 동네 단위 복제 비용 0**을 한 도구가 동시에 해결하는 자리
2. 본 발명의 진짜 무게는 *컨텍스트 자동 진입 OS* — 가게 진입 순간 그 가게 앱이 되는 구조 (현재 쿠폰, 발전 시 메뉴·배달·예약)
3. 인식 채널은 **NFC 단독**이 최적 (특허 위험 0 + 본인 화면 도장 그림 보존)
4. 자본 순서: 7월 중기청 → PoC 데이터 → 엔젤 라운드
5. 진입 비용은 작음 — PoC 50개 시제품 75만원 + 1~2주

## 1. 발명 정의

### 1.1 정체성

콜마당 = **컨텍스트 자동 진입 손님 OS**. 손님이 식당 A에 들어서면 A의 쿠폰·메뉴·예약·후기·배달이 활성. 식당 B로 가면 B의 같은 기능이 활성. 같은 손님앱이지만 가게마다 다른 앱처럼 작동.

### 1.2 핵심 메커니즘 — 두 인터페이스 결합

| 인터페이스 | 동작 | 결과 |
|---|---|---|
| **도장 (NFC)** | 사장이 손님 폰 화면 위에 도장을 꽝 | 적립 + 손님앱 자동 설치/귀속 |
| **가게 QR** | 손님이 가게 진입 시 카운터 QR 스캔 | 그 가게의 컨텍스트(쿠폰·메뉴·예약 등) 자동 활성 |

### 1.3 사장+손님 모두 0차 인터페이스

- 사장: 30년 써온 도장 손짓 그대로. 디지털 인지 부담 0
- 손님: 손님앱 켜고 화면 내밀기만. 카메라 활성화·조준 같은 1차 동작 없음

## 2. 사용 시나리오 5개

### 2.1 S1 — 사장이 도장 받는 날 (Day 0, 30분)
1. 원규씨 식당 방문 + 도장 1개 + 사장 폰에 콜마당 점주 앱 설치
2. 점주 앱 BLE 페어링 → 도장에 사무실 ID + 비밀 시드 1회 전송
3. "이 도장 꽝 = 적립" 한 줄 설명

### 2.2 S2 — 손님 첫 도장 (Day 1, 앱 미설치, 10초)
1. 손님 김밥 결제 → 사장 도장 꽝 (화면 위)
2. 손님 폰 NFC 안테나가 도장 NFC 칩 인식 → 동적 URL (사무실 ID + OTP) 전달
3. 앱 미설치 → Play Store + Install Referrer → 자동 설치
4. 첫 실행 → 자동 귀속(김밥집) + 적립 1

### 2.3 S3 — 두 번째 도장 (Day 1 저녁, 5초) ★ 인지 폭발 자리
1. 같은 손님 옆 카페 결제 → 사장 도장 꽝
2. 앱 이미 설치됨 → 딥링크 → 토큰 서버 검증
3. **같은 통장에 카페 적립 추가** → 손님 인지 "어? 이 가게도? 같은 앱에?"

### 2.4 S4 — 단골 재방문 (Week 2~)
1. 손님 단골 식당 재방문 → 사장 도장 꽝
2. 누적 적립 시각화 + 쿠폰 발행 알림
3. 다음 방문 시 쿠폰 사용 → 동네 통장 인지 형성

### 2.5 S5 — 도장 분실 (예외 흐름)
1. 사장 점주 앱에서 [도장 무효화]
2. 서버 분실 등록 → 분실 도장 토큰 거절
3. 새 도장 페어링 → 사무실 ID 동일 갱신
4. 손님 측 영향 0

## 3. 기술 메커니즘 분석

### 3.1 인식 채널 4가지 비교

| 채널 | 본인 *화면 도장* 정합 | 양산 난이도 | 특허 위험 |
|---|---|---|---|
| 카메라 (QR·OCR) | ❌ (1차 인터페이스) | 저 | 저 |
| 정전식 (멀티터치) | ⭕⭕ | 중 | **❌ 원투씨엠 17개** |
| **NFC** | ⭕ (안내 UI로 위치 정렬) | **저** | **⭕⭕ 0** |
| 음파 (스피커→마이크) | ❌ | 고 | 중 (KR102165146B1) |

### 3.2 NFC 단독 권장 — 5가지 이유

1. **본인 화면 도장 그림 보존** — 폰 후면 NFC 안테나(거리 3~4cm)가 화면 위 도장 인식
2. **특허 위험 0** — 정전식 영역 회피
3. **양산 빠름** — 1~2개월
4. **BOM 저렴** — 개당 1~1.5만원 (정전식 OEM 대비 1/2~1/3)
5. **시각 노출 없음** — OTP 사진 캡처 도용 방지

### 3.3 BOM 후보 (PoC 50개)

| 부품 | 후보 | 단가 |
|---|---|---|
| NFC IC (active) | NXP PN7150 / NTAG I²C Plus + ATtiny | 3,000~8,000원 |
| MCU | ESP32-C3 또는 ATtiny | 2,000~3,000원 |
| 배터리 | CR2032 코인셀 (1년+) | 1,500원 |
| 케이스 | 3D 프린팅 | 2,000~5,000원 |
| 부수 | PCB·러버부·조립 | 1,000~2,000원 |
| **합계** | | **약 1~1.5만원/개** |

### 3.4 NFC 동적 URL 형식 (예시)
```
https://callmadang.app/r/{officeId}/{otp_token}
```
- officeId: 사무실(가게) 고유 ID
- otp_token: HMAC-SHA256 OTP (도장 ID + 시간 윈도우 + nonce)

→ **NFC 단독 채택 시 원투씨엠 17개 영역 회피 가능**

### 4.3 콜마당 referrer 귀속 특허 (출원 중) — 청구항 보강 후보 3건

1. **종속항**: "물리적 발생 장치(도장)로부터 referrer 수신"
2. **방법청구항**: 점주 도장 발생 → 손님 폰 NFC 인식 → 앱 미설치/설치 분기 → 토큰 서버 검증 → 귀속 노드 자동 결정·갱신
3. **종속항**: 점주 단말 BLE 페어링으로 도장 사무실 정보 동적 갱신 시 귀속 노드 동기

### 4.4 보강 경로 3가지

| 경로 | 조건 | 평가 |
|---|---|---|
| A. 청구항 보정 | 명세서에 도장 단서 있는 경우 | 가장 빠름 |
| B. 국내 우선권 신규 출원 | 출원일 +1년 이내 | **가장 안전** |
| C. 분할 출원 | 등록·거절 확정 전 | 명세서 단서 필요 |

**클코 권장 = B (국내 우선권 신규 출원)** — 단 변리사 자문 1회로 출원일·명세서 단서 확인 후 확정

## 5. 시장 분석

### 5.1 콜마당이 차지하는 빈 자리

| 플레이어 | 영역 | 동네 침투 |
|---|---|---|
| 카카오 멤버십 | 전국 + 대기업·프랜차이즈 | ❌ (영세업자 가맹 마찰) |
| 네이버 페이/MY플레이스 | 전국 + 대규모 가맹 | ❌ |
| 페이코/삼성월렛 | 전국 결제 통합 | ❌ |
| **콜마당** | **양평 동네 + 영세업자** | **⭕ 진입로 = 도장** |

### 5.2 양평 우물 모델 (마스터 §시간차 이식 정합)

- 양평 1면 시작 (용문면) → 양평 다른 면 복제 → 군 단위 → 전국 농촌·소도시
- 복제 비용 거의 0 (도장 N개 + 사장 폰 앱 페어링만)
- 카카오 식 *위에서 우산* ❌, 콜마당 식 *동네 단위 우물* ⭕

### 5.3 TAM·SAM·SOM 초기 추정

| 단계 | 시장 | 규모 |
|---|---|---|
| SOM | 양평군 전체 | 인구 11만 |
| SAM | 전국 농촌·소도시 (인구 ~1,500만) | 약 1,500만 |
| TAM | 한국 전체 동네 상권 + 글로벌 확장 | 무한대 |

## 7. 제작 단계별 권장

| 단계 | 방식 | 단가 | 시간 |
|---|---|---|---|
| **PoC 50개** | 자체 제작 + 중국 NFC 모듈 직구 + 3D 프린팅 케이스 | 1~2만원/개 (BOM만) | 1~2주 |
| 시범 양산 100~300개 | 중국 OEM 소량 (선전·둥관) | 1.5~3만원/개 | 2~4주 |
| 본 양산 1,000개+ | 중국 OEM 본 양산 + 한국 KC 인증 | 7,000~1.5만원/개 | 4~6주 |

### 7.1 PoC 50개 — 자체 제작 권장 이유

1. 가장 저렴 (50개 × 1.5만원 = 75만원)
2. 펌웨어·메커니즘 직접 반복 가능
3. 디자인 자유
4. IP 보호 (중국 OEM 의뢰 시 기술 노출 위험)
5. 시제품 → 정부 신청 흐름 시간 정합

### 7.2 KC 인증 자리

NFC 13.56MHz 저전력 = 일반적으로 *적합성평가 면제* (전파법). 양산 시 *적합등록 확인* 필요 (50~200만, 2~4주)

## 8. 검증 필요 가설 5건 (PoC 데이터로 검증)

| # | 가설 | 검증 방법 | 첫 PoC에서 데이터 한 점 |
|---|---|---|---|
| 1 | 사장이 도장을 *받아 쓰는가* (행위 부담·이해도) | 용문면 50곳 배포 후 *주간 사용 횟수* 측정 | Month 1 |

| 3 | 사장 자가증식이 *작동하는가* (단톡방·신뢰 네트워크) | 사장 자가 추천으로 가맹 추가 비율 | Month 2 |
| 4 | 도장 0차 인터페이스가 *세대 무관*인가 (손님 세대별) | 손님 연령별 가입·사용 데이터 | Month 1~3 |

가설 1 = 가장 위. 1번이 0이면 나머지 4건 의미 없음. **첫 검증점 = 사장이 도장을 *꺼내드는가***.

## 12. 결론

본 발명(콜마당 컨텍스트 진입 OS + NFC 도장)은 *가설 정합도가 매우 강한 + 0년 실측 상태*입니다. **가설을 진실로 다루지 말 것** — 단 진입 비용이 작아서(PoC 75만원 + 1~2주) 첫 검증점까지 도달하는 다운사이드 거의 없음. PoC 데이터 한 점 후에 *정부 자금 → 엔젤*로 자연 연결되는 자본 순서 정합. 본인이 1년 학습으로 도달한 모든 자리가 한 도구에 모이는 자리라는 점에서 *가설 정합도*는 진짜 자산.

진짜 결정 자리는 *지금 콜마당 본체 우회 여부*가 아니라 **PoC 1주차 시제품 1개를 만들지**입니다. 이 한 점이 모든 도미노의 첫 패.
