## ★ 핵심 분리: 영업 카드 ≠ 제품 정체성 (본인 통찰)

본인 발화 (2026-05-25): "결국 콜마당이 아닌 무전기를 파는 느낌도 있다"

본 카드는 *영업 진입 멘트*. 콜마당 *제품 정체성*은 별개:
- **영업 카드 (1단 진입)**: 무전기 비용 대체

### 마진율 평탄의 본질 (본인 지적)

본인 발화 (2026-05-25): "결국 아고라가 사무실이 많아져도 비용이 커져서 마진율이 커지진 않네?"

→ **정확한 지적**. Agora pay-as-you-go = **변동비 100%**. 무료 한도 비중 사라진 후 선형. 매출도 사무실당 일정, 비용도 사무실당 일정 → 마진율 *90% 평탄*.

이는 SaaS pay-as-you-go 모델의 *본질적 한계*. 마진율 ↑ 만들려면 *변동비 → 고정비 전환* (LiveKit Self-hosted) 필요.

### 사업가 사고 (본인 결정의 무게)

본인 결정 = 마진율 90% 평탄 수용 + 안정성 우선:
- Agora SLA 99.9%+ vs LiveKit 자체 운영 SLA 0
- 셋업 1~2주 + 보안 패치·모니터링·장애 대응 *평생*
- 영업 시간 기회비용 + 마음 자리 (사업 집중 vs 인프라 운영자 변신)
- 2000사무실 = 연 6.5억 마진. *충분*. 마진율 8% ↑ 위해 변신 거부

**클코 학습**: 클코 계산은 *돈만 봄*. 본인은 *시간·정신·안정성*까지. 사업가 정확.

## 콜마당 구독료 3만원 가치 분해

3만원 구독료의 *시장 가치 합산*:
- 무전기 무료 제공 = 시장 16만원
- 콜 카드 자동 + 매니저 부담 0 = 시간 가치
- 콜 수수료 0원 = 콜당 ~3,000원 시장 관행 절감
- 채팅 블랙박스 = 분쟁 인프라
- OS 정체성 → 식당 4중 노드 연결 = 장기 가치

= **시장 가치 합산 > 20만원/사무실/월**. 구독료 3만원 = *시장 가치의 15% 가격*. 가격 저항 0.
