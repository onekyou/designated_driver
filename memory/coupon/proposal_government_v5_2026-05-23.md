## §1. WHY — 무엇이 잘못되었는가

### 1.1 자본 흐름의 두 방향

```
┌──────────────────────────────────────────────────────────────┐
│  중앙 플랫폼 (카카오·배민·쿠팡)         콜마당                  │
│                                                              │
│        ↑ 수수료 6~25%                  ↑ 월 1만원 미만 실비    │
│        ↑ 광고비                                              │
│        ↑ 손님 데이터                    ↓ 데이터·고객 자산     │
│        ↑ 브랜드 인지도                  ↓ 브랜드 충성도        │
│                                                              │
│   [서울 본사로 유출]               [지역 안에 잔류]             │
│                                                              │
│   영세 상인 = 채널 임대인          영세 상인 = OS의 주인        │
└──────────────────────────────────────────────────────────────┘
```
> *[도표 1] 자본 흐름의 두 방향 — 콜마당이 중앙 플랫폼의 정확한 반대편에 위치*

### 1.2 지방 영세 상인의 진짜 위기 — *데이터 종속*

수수료보다 더 결정적인 문제는 **데이터 종속**. 손님 정보를 가게가 *볼 수도 없음*. 약관은 언제든 바뀜 — *배달앱 수수료 변동 사례: 6.8% → 9.8%*. 윤리적 선언만으로는 보호 불가.

### 1.3 지방 정부의 딜레마

| 지방 정부가 원하는 것 | 현실의 벽 |
|----------------|---------|
| 지방 소멸 대응 | 자본 유출이 원인인데 막을 도구 없음 |
| 영세 상인 보호 | 직접 보조금 = 받는 사람도 부담, 정치적 효과 낮음 |
| 공공배달앱 (배달의명수·먹깨비) | *보조금 끊기면 사용량 폭락* (F2 실패 패턴) |
| 지역사랑상품권 | 충전 보조 없으면 자생 ❌ |
| 카카오·배민에 대한 대안 | 지자체 단독 개발 = 외주비 3억+, 자체 운영 인력 없음 |
| 디지털 소외 계층(고령층) 포용 | 앱 사용 못하는 군민이 다수 |

→ **지자체가 *효과적이고 자생 가능한 도구*를 갖지 못함**. 콜마당이 그 도구.

## §3. HOW — 8대 핵심 기술 (특허 청구항)

### 3.1 8대 기술 요약

| # | 기술 | 한 줄 설명 | 사회적 가치 |
|---|------|----------|-----------|
| 1 | **동적 노드 귀속** | QR Install Referrer로 손님을 가게에 영구 귀속 | 데이터 주권 회복 |
| 2 | **이벤트 드리븐 콜 감지·배차** | PhoneStateListener + FCM 자동 배차 | 운전 중 6번 클릭 → 1번 (현장 안전) |
| 3 | **전화번호 기반 고객 자동 인식** ★ | 앱 미사용 고객도 전화만 받으면 포인트 자동 적립 | **디지털 소외 계층(고령층) 포용** |
| 4 | **협력적 콜 공유 + 원노드 보상** ★ | 영업 종료·인력 부족 시 타 노드에 공유, 자동 10% 보상 | **카르텔 친화적 협력** (파괴 ❌ 흡수 ✅) |
| 5 | **지역 자율형 파라미터** | 노드별 수익 분배율·포인트 적립률 자율 설정 | **지역 자치 디지털 플랫폼** |
| 6 | **고객 등급별 포인트** | BRONZE·SILVER·GOLD·VIP 자동 승급 + 차등 적립 | 단골 자동 관리 |
| 7 | **Offline-First + 실시간 동기화** | Room DB 로컬 우선 → 네트워크 복구 시 자동 동기화 | **산간·통신음영 작동 보장** |
| 8 | **FCM ACK + 자동 재전송** | 배차 알림 유실 방지 (10초 미수신 시 2회 재전송) | 신뢰성 보장 |

### 3.2 가장 강력한 3대 기술 — *지방 정부 정책과 직접 매칭*

#### ① 동적 노드 귀속 — *코드*가 강제하는 데이터 주권

```
[손님] QR 스캔 → [앱 스토어] Install Referrer → [앱 설치]
                                                    ↓
                                          [노드 ID 추출]
                                                    ↓
                                  /offices/{사무실ID}/customers/{손님ID}
                                                    ↓
                                  Firebase Security Rules:
                                  → 해당 사무실 사장님만 읽기/쓰기
                                  → 플랫폼 관리자도 접근 차단
```
> *[도표 3] 동적 노드 귀속 흐름 — 데이터가 노드 하위에만 저장, 코드가 강제*

**3중 보호 장치**: ① 기술적 (Security Rules 자동 차단) ② 법적 (약관 명시) ③ 감사 (Audit Log 사장님 열람 가능). **해지 시에도 사장님이 손님 데이터 그대로 보유**.

#### ③ 전화번호 기반 자동 인식 — *디지털 소외 계층 포용*

> 50대 이상 군민·도민이 *평소처럼 전화만 걸어도* 자동 회원 인식 + 포인트 적립. 앱 학습 비용 0.

이는 *지방 정부의 디지털 포용 정책*과 정확히 매칭. 기존 플랫폼은 앱 미사용 고객 = 디지털 혜택 제외 → 콜마당은 *앱 가입 1회 후 전화만 해도 동일 혜택*.

#### ④ 협력적 콜 공유 — *카르텔 친화적 협력*

> 폐쇄적 영세 사업자 네트워크(카르텔)를 *파괴 ❌ 디지털 흡수 ✅*. 영업 종료·인력 부족 노드의 콜을 다른 노드에 공유 → 처리 시 *원본 노드에 매출의 10% 자동 보상*. 경쟁 구조가 아닌 *상생 네트워크*.

지방 영세 사업자가 *카카오·배민 같은 외부 진입을 막아온 진입장벽*을 그대로 살리면서 디지털화. 사업자들이 *디지털 플랫폼을 자신의 도구로* 받아들일 수 있는 유일한 구조.
