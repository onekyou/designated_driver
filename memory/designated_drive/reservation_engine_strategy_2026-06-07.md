# 통화예약 + 도장 = 거인과 싸울 "돌팔매(행동 0)" — 전략

> 2026-06-07 사적 대화의 수렴. 기술 플랜은 [[reservation_engine_plan_2026-06-07]], 출발 발견은 [[call_recording_ai_parse_2026-06-03]]. CLAUDE.md 최우선목표("사용자행동 0", 2026-06-05 확정)의 *왜 이게 무기인가*에 대한 답.

## 한 줄
**NFC 도장 + 통화예약, 둘 다 "상인·손님 행동 0".** 이게 지방 소상공인에게 통하는 이유이자, 거인이 구조적으로 못 따라오는 단 하나의 비대칭 = 다윗의 돌팔매.

## 돌팔매 논리 (왜 행동 0이 거인을 이기나)
- **거인은 규모를 위해 표준화를 강제당한다.** 전국·전업종을 다루려면 사용자를 자기 틀에 맞춰야 함 → "봇 틀에 맞춰 말해라(KT)", "네이버 양식에 입력해라(상인)".
- **표준화 = 사용자에게 행동을 요구.** 그래서 거인은 *행동 0을 줄 수 없다* — 규모 구조와 양립 불가.
- 우리는 사용자의 자연 행동(평소 전화 통화)을 그대로 받고, AI가 뒤에서 조용히 처리 → 행동 0. 자본·GPT-4o·무료미끼로도 거인은 이 자리에 못 옴.

## 해자 조준 (대화에서 정정된 것 — 약한 논거 버리고 강한 것만)
- ❌ **"LLM 갭"은 해자 아님.** KT는 2024.9 MS와 조 단위 제휴 → Azure OpenAI GPT-4o 한국형 보유. 모델은 붙이면 됨(카카오도 GPT). 따라잡힌다.
- ❌ **"수수료 0이라 거인 수지타산 안 맞음"도 부분 반박됨.** 거인은 통화예약을 *무료 미끼*로 깔고 광고·데이터로 회수 가능(네이버 방식).
- ❌ **"귀속"은 상인의 언어가 아님.** 상인 대부분은 데이터 주권에 관심 0, *작은 구체적 이익*을 본다.
- ✅ **진짜 해자 = 행동 0 + 이익언어 번역 + 정면 안 붙고 선점.**
  - 귀속을 *돈의 언어*로: 단골 재방문 매출 / 노동 0 / 수수료 안 떼임 / 광고경쟁 탈출.
  - 거인이 무료로 줘도 *데이터·관계는 흡수*함(플랫폼의 존재이유) → 그걸 손님·상인에게 *남기는 것*은 거인의 자기부정 = 못 함. (단 이건 상인이 *나중에* 체감, 초기 설득은 위 이익언어로.)
  - 기능 동등 정면싸움은 작은 우리가 짐 → 거인이 무시하는 작은 시장에서 *먼저* 뿌리. 단골 끈이 쌓이면 거인이 기능 베껴도 전환비용이 막음.

## 거인 팩트 (2026-06-07 확인)
- **KT AI 통화비서**: AI가 전화 *대신 받는* 봇/시나리오 응대(예약·주문 옵션 설정, 인사말). 미용사회중앙회 MOU, 연내 1만개 추진. = 손님 행동↑(봇과 씨름) + 단순화된 대화 한정. KT-MS GPT-4o 보유.
- **뷰티 CRM(공비서·뷰카·팅커뷰·뷰티인프라 등)**: 네이버 예약 연동 + CRM + 매출분석. 공통 한계 = **온라인 예약만 자동, 전화 통화는 사장이 수기 입력.** 전화→자동예약은 누구도 안 함(빈 공간).
- **우리 vs 거인**: 거인=봇이 사람 *대체*(손님이 봇과 통화, 관계 깸). 우리=사람 통화 *유지* + 사후 파싱(관계 보존). 지방=관계 사회라 우리 쪽이 맞음.

## 명중 조건 (돌이 빗나가지 않으려면 — 셋 다 실행에 달림, 운 아님)
1. **통화예약 정확도 = 헛예약 0.** 깨지면 "행동 0"이 "다시 확인하는 행동"으로 뒤집힘. (측정 슬라이스 W/C 채점의 그 지점.)
2. **도장 NFC 체감 0.** 손님 행동을 "태그 한 번"까지 줄여야 0이 무기가 됨.
3. **거인 오기 전 선점 속도.** 동네에 단골 끈이 먼저 쌓이면 거인이 못 뽑음.
- + 🚩 선결: 타깃 살롱 안드로이드+자동녹음 비율 현장 실사.

## 최초 질문에 대한 답
*"도장+통화예약만 완성되면 지방 소상공인에게 무조건 통할까?"* →
**"무조건"은 아니다**(그 단어가 방심을 부름). **하지만 "통한다"엔 동의.** 처음 우려(지속결제→lock-in/단면으로 해소, 양면→통화예약 단면으로 우회, 거인→행동0 비대칭+선점으로 약화)가 대화 거치며 거의 사라졌고, **남은 변수는 "완성"의 정의 = 정확도·NFC체감0·선점속도 셋뿐. 셋 다 운이 아니라 우리 실행에 달림.**
