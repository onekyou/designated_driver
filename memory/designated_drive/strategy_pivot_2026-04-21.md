# 2026-04-21 전략 피벗: 첫 영업 + 병렬 낚싯대

## 🔄 2026-04-26 업데이트: 식당 채널 재포함 + 택시 호출 무마진 번들

원래 4-21 피벗에서 식당은 **"배민 얽힘, 배달 연동 복잡"** 이유로 제외했음. 사용자 의도적 재포함 결정.

### 핵심 재정의
식당을 **새 낚싯대(new vertical)** 가 아닌 **기존 손님앱·대리의 배포 채널** 로 본다.

- 손님이 식당에서 술을 마신다 = 대리 호출의 가장 강한 사전 신호
- 식당 사장님 = 손님앱 보급의 자연스러운 접점 (테이블 QR 등)
- 배민 얽힘 회피: **배달 연동 ❌ / 음식 주문 ❌ / 단순 호출 통로 ⭕**
- 손님앱을 **식당 전용 UX** 로 1차 리브랜딩 (대리 호출 + 택시 호출 + 귀속)

### 확장 기능: 택시 호출 무마진 번들
- 목적: 마진 ❌ / **플랫폼 완성도 + 식당 사장님 락인(Lock-in)** ⭕
- 구현 범위: 조합 콜센터로 메시지 1건 push (배차는 조합이 함)
- 책임/충돌 회피를 위해 **"디지털 전화기"** 포지셔닝 (배차 시스템 ❌)

### 조합 설득 카드 (3개)
1. **카카오 대항 지역 우군** — 수수료 0원, 지역 기사에게 양질 콜 우선 (가장 강한 카드)
2. **노쇼 없음** — 식당 안에 손님이 머무는 콜은 노쇼 확률 압도적으로 낮음
3. **피크타임 응대 정확도 향상** — "응대 줄임" 아닌 "정확도 올림" 으로 표현 (콜센터 인력 위협감 회피)

### 선결 검증 (코딩 진입 전 필수)
1. 양평 택시 조합 자체 앱/시스템 유무 (있으면 우리가 끼어들 자리 없음)
2. 콜센터 운영 구조 (조합 직영 / 외주 / 개인 콜센터)
3. 박상준 사장님께 "식당 사장님 입장에서 이거 받으면 쓸래?" 1차 검증

### 기능 범위 (MVP)
- 원터치 호출 + 식당 주소 자동 전송 ✅
- 상태 알림 (배차/완료/도착) — 조합이 데이터 못 주면 SMS 만으로 충분
- 기사 정보 노출 — **안심번호 필수** (직접 노출 ❌)

### Tier 구조 적용
- **Tier 1 (랜딩)** — 불필요 (기존 손님앱 + 식당 채널 = 이미 검증된 대리 product 의 배포 확장)
- 단, **식당 사장님 영업용 1페이지 제안서** 는 Tier 1 동급 자료로 준비
- **조합 미팅용 1페이지 제안서** 별도 준비 (수수료 0원 + 디지털 전화기 포지셔닝 명시)

### 우선순위 — 필라테스/미용실과의 관계
- **식당** = 대리 강화의 일환 (병렬 낚싯대 #3 강화, 박상준 영업 채널 종속)
- **필라테스/미용실** = 새 낚싯대 (병렬 #1, #2, 본인 영업)
- 동시 진행 가능. 단, 시간/자원 충돌 시 입질 신호 강한 쪽 우선

## 배경: 첫 영업 경험

박상준/양평 사장님 설치 방문 (본격적인 첫 대면 영업). 세 가지 뼈아픈 교훈:

1. **영업은 개발의 10배 어렵다** — 컴퓨터 앞 6개월 타임라인은 환상. 스타트업 통계: MVP 도달 10% / 런칭 생존 1% / 성공 0.1% / 10년.
2. **대리운전은 사양산업이다** (테스터 지적) — 회식 축소, 2030 음주 감소, 카카오T 대형 흡수. 파리날리는 사장에게 키오스크 무료도 안 통함 (학습 비용 + 실패 리스크).
3. **현장 병목은 기술이 아니라 운영** — 오타 하나 앞에서 얼음 (스트레스 → 전두엽 차단). 체크리스트 문화 필수.

## 테스터 친구 핵심 조언 (20년 노가다, 매일 새벽부터 가리지 않고 일하는 사람)

1. **"병렬 낚시대"** — 대리만 testbed는 언제 될지 모름. 낚싯대 여러 개 깔고 입질 있는 쪽 먼저 디벨롭
2. **"보자마자 알아차리는 대상"** — 20~40대, 앱 UX에 길들여진 계층 타겟
3. **"귀속노드는 접지 마라"** — QR + Install Referrer + 영구 매칭 + customerInfo 공유 토큰은 대리 전용 아님. 이게 진짜 자산

**Why 이 조언을 중시하는가**: 몸으로 번 돈의 무게. 이론 perfection이 아닌 현장 감각. 사용자가 오늘 대리 영업 체감 실패 후 이 말이 뼈에 꽂혔다.

## 후보 낚싯대 3개 (젊은 + 즉각 aha + 귀속노드 fit)

### 1. 필라테스/요가/PT 1인 스튜디오 ⭐ 최고
- 원장 대부분 20~40대 여성, IT 친화적
- 현재 도구: 네이버예약 + 오프라인 회원권
- Pain: 네이버예약 수수료, 출석·회원권 차감 수기
- 데모 한 줄: "QR 한 번 = 출석 + 회원권 자동차감 + 단골 푸시"

### 2. 미용실/네일샵 1인샵 ⭐ 2순위
- 젊은 원장, Instagram 네이티브
- Pain: 수수료 + 단골 관리 불편
- 데모 한 줄: "QR 한 번 = 영구 단골 + 예약 + 수수료 0원"

### 3. 대리 (유지) — 최소 유지만
- 이미 돌고 있으니 접지 말 것. 박상준 사장님 통한 2호 기대
- Phase 6 iOS 출시 **보류** (신호 확인 전엔 자원 투입 안 함)
- 손님앱 MVP 재작성도 **보류**

### 제외 시장과 이유
- **카페**: 카카오스탬프 이미 점유, 전환 비용 높음
- ~~**식당**: 배민 얽힘, 배달 연동 복잡~~ → **2026-04-26 재포함** (위 §업데이트 참조). 식당 = 대리 배포 채널 + 택시 무마진 번들로 락인. 배달 연동 회피 전제
- **학원**: 의사결정 느리고 보수적

## Tier 1 실행 계획 (1주)

1. **랜딩 2종 제작** (각 1~2일)
   - Next.js 또는 단순 HTML (`head_manager_web` 스택 재사용)
   - 각 업종 30초 데모 영상 (실제 앱 화면 녹화)
   - 공통 CTA: "베타 신청 — 월 1만원, 수수료 0원"

2. **배포 (진짜 병목)**
   - Instagram DM 각 업종 20~30곳
   - Naver 카페 (업종별 원장 커뮤니티) 글
   - 현지 도보 영업 1~2일 (테스터 친구 동행 제안)

3. **1주 후 신호 기준**
   - "언제 쓸 수 있어요?" 문의 ≥ 3건
   - 연락처 남긴 사람 ≥ 10명
   - 지인 소개 ≥ 1건
   - → 통과한 낚싯대만 Tier 2 진입

## 병목 인식
