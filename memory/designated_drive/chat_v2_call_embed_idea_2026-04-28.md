# V2 후보 — 메시지 안에 콜 카드 임베드 (2026-04-28)

## 발견 경위
2026-04-28 양평 단톡방 실측 데이터 분석 중 발견. 데이터 출처: `yangpyeong_chat_data_2026-04-28.md`.

기사들이 단톡방에 콜 메타 정보를 텍스트로 일일이 적음:
- "공흥1리경유 석장리착25"
- "군청 이윤계공인중계사 공세리 출"
- "양평갈매기 용천리 출"
- "호랭이잔치상 한라 출"

이게 카톡엔 콜 카드 인용 기능이 없어서 발생하는 패턴. 매번 출발지 + 경유 + 도착지 + 시간을 직접 타이핑.

## V2 핵심 아이디어

**메시지 안에 콜 카드를 인용/링크 + 클릭 시 콜 상세로 이동**

### 사용자 경험
1. 매니저가 채팅창 입력바에 `+` 또는 `@` 아이콘 누름
2. 현재 진행 중인 콜 목록 모달 표시 (WAITING/ASSIGNED/IN_PROGRESS 상태)
3. 콜 1건 선택 → 메시지에 콜 카드 인라인 첨부
4. 카드 표시 형태 (예시):
   ```
   ┌──────────────────────┐
   │ 📞 #00123 양평갈매기      │
   │ 🚗 양평갈매기 → 용천리      │
   │ 💰 25,000원 · 진행중     │
   │ 👤 조수현 기사            │
   └──────────────────────┘
   ```
5. 다른 사용자가 카드 탭 → 해당 콜 상세 화면으로 navigate
6. 사이드 효과: 운행 중 기사가 카드 받으면 콜 정보 즉시 확인 (텍스트 다 안 적어도 됨)

### 기술 설계 초안
- 메시지 필드에 `embed: { type: "CALL_CARD", callId: "abc", snapshot: {...} }` 추가
- snapshot은 발송 시점의 콜 데이터 비정규화 (콜 상태 변하면 카드 stale, 클릭 시 navigate해서 최신 상태 확인)
- Compose UI: ChatScreen 메시지 버블 안에서 `embed != null`이면 카드 컴포저블 렌더링

### 카톡이 절대 못 하는 차별 가치
- 카톡은 콜마당과 분리된 외부 앱 → 콜 데이터 임베드 X
- 콜마당 단톡방 안에서는 콜 카드 = 1급 시민
- 운영 효율 향상 (타이핑 시간 절감 + 정확도 향상)

## 우선순위 / 시점
- V1: 텍스트만 (단순화 우선)
- V1.1: 이미지 (외부 사진 공유, 단 필요성 약함)
- **V2: 콜 카드 임베드 (콜마당 차별 가치)**
- V2 작업 추정: ~1주 (콜 목록 모달 + 임베드 데이터 모델 + Compose 카드 컴포저블)

## 부가 아이디어 (V2+ 묶음)
1. **시스템 메시지 자동화**: 콜 ASSIGNED → "🤖 [기사명]이 #00123 콜을 수락했습니다" 자동 메시지 (멤버 입퇴장 안내도 같이)
2. **콜 카드 → 메시지 답글**: 콜 카드 위에 직접 댓글 (그 콜에 묶인 채팅 스레드)
3. **빈도 약어 단축 버튼**: 자주 쓰는 "통완", "착25" 등 자동 완성 또는 단축 버튼
4. **기사 위치 임베드**: 운행 중인 기사 현재 위치 카드 (개인정보 동의 필요)
