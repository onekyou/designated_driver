## 핵심 차별점 (vs 로지소프트/콜마너/대리몬)

기존 대리운전 프로그램사(로지소프트, 콜마너, 아이콘 등)는 **중앙 집중형**: 고객이 프로그램사에 귀속, 사무실은 종속, 수수료+벌과금+차수 통제.

콜마당은 **사무실 독립형**:
1. **원클릭 배차**: 전화 자동 감지 → 기사 선택 → 배차 (기존 6클릭 → 1클릭, 콜마당의 출발점이자 핵심 가치)
2. **고객 귀속**: 고객은 각 사무실에 귀속 (QR 기반 온보딩으로 사무실에 직접 연결)
2. **독립 운영**: 각 사무실이 자체 고객을 관리하고 배차
3. **지역 콜 공유**: 영업시간 외 콜만 지역 내 사무실 간 공유 (shared_calls)
4. **중앙 개입 없음**: 프로그램사가 콜을 통제하거나 벌과금을 부과하지 않음
5. **수익 모델**: 소수 구독료만 — 건당 수수료 없음

## 비전 한 줄

Shopify가 소상공인에게 이커머스를 준 것처럼, 콜마당은 지역/개인 사업자에게 대기업 프랜차이즈급 서비스 인프라를 제공한다.

**Why:** 이것이 사용자가 밝힌 가장 큰 무기. 기존 업체들의 플랫폼 종속 문제를 정면으로 해결.

**How to apply:** 기능 설계/우선순위 논의 시 이 차별점을 훼손하는 방향은 피할 것. 예: 중앙 서버 의존도를 높이는 설계보다 사무실 독립성을 유지하는 설계 우선.
