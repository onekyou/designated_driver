## 1. 위험 권한 제거 작업

### 1.1 READ_CALL_LOG 권한 제거

#### 제거 이유
- Google Play Store의 2019년 Call Log & SMS Policy 위반 (90% 이상 거부율)
- 실제로 사용하지 않는 권한 (모든 CallLog 관련 코드가 주석처리됨)
- 전화번호는 TelephonyManager의 `EXTRA_INCOMING_NUMBER`로 충분히 확보 가능

## 2. 고객 알림 Cloud Function 구현

### 2.1 구현 목적
사무실이 마감되어 `shared_calls` 컬렉션에 공유콜이 생성될 때, 앱에 가입한 고객에게 자동으로 FCM 알림을 전송합니다.

### 2.2 작동 조건
- **앱호출 + 앱회원 + 사무실마감**: ✅ 알림 전송
- **전화호출 + 앱회원 + 사무실마감**: ✅ 알림 전송
- **전화호출 + 비회원 + 사무실마감**: ❌ 알림 불가 (향후 SMS/카카오톡 보강 필요)

### 2.3 구현 코드

**파일**: `functions/src/index.ts` (lines 464-561)

```typescript
/**
 * 고객에게 사무실 마감 알림 전송
 * shared_calls 문서 생성 시 고객 앱에 FCM 알림 전송
 */
export const notifyCustomerOnOfficeClosed = onDocumentCreated(
  {
    region: "asia-northeast3",
    document: "shared_calls/{callId}"
  },
  async (event: any) => {
    const callId = event.params.callId;

    if (!event.data) {
      logger.warn(`[customer-closed:${callId}] 이벤트 데이터가 없습니다.`);
      return;
    }

    const sharedCallData = event.data.data() as SharedCallData;

    if (!sharedCallData || sharedCallData.status !== "OPEN") {
      logger.info(`[customer-closed:${callId}] OPEN 상태가 아니므로 고객 알림을 보내지 않습니다. Status: ${sharedCallData?.status}`);
      return;
    }

    const phoneNumber = sharedCallData.phoneNumber;
    if (!phoneNumber) {
      logger.warn(`[customer-closed:${callId}] 전화번호가 없어 고객 알림을 보낼 수 없습니다.`);
      return;
    }

    const sourceRegionId = sharedCallData.sourceRegionId;
    const sourceOfficeId = sharedCallData.sourceOfficeId;

    logger.info(`[customer-closed:${callId}] 사무실 마감으로 인한 공유콜 생성. 고객에게 알림 전송 시작: ${phoneNumber}`);

    try {
      // 원본 사무실의 customerInfo에서 고객 FCM 토큰 조회
      const customerDoc = await admin.firestore()
        .collection("regions").doc(sourceRegionId)
        .collection("offices").doc(sourceOfficeId)
        .collection("customerInfo")
        .doc(phoneNumber)
        .get();

      if (!customerDoc.exists) {
        logger.info(`[customer-closed:${callId}] customerInfo에 등록되지 않은 고객: ${phoneNumber}`);
        return;
      }

      const fcmToken = customerDoc.data()?.fcmToken;
      if (!fcmToken) {
        logger.info(`[customer-closed:${callId}] 고객 FCM 토큰 없음 (앱 미설치 또는 미가입): ${phoneNumber}`);
        return;
      }

      // FCM 알림 전송
      const message: admin.messaging.Message = {
        data: {
          type: "OFFICE_CLOSED",
          sharedCallId: callId,
          phoneNumber: phoneNumber,
          title: "🏢 사무실 마감 안내",
          body: "사무실이 마감되어 잠시후 운행가능한 다른 사무실과 연결해 드리겠습니다.",
        },
        android: {
          priority: "high",
          ttl: 300000, // 5분
        },
        token: fcmToken
      };

      await admin.messaging().send(message);
      logger.info(`[customer-closed:${callId}] 고객에게 사무실 마감 알림 전송 완료: ${phoneNumber}`);

    } catch (error: any) {
      // FCM 토큰이 무효한 경우 자동 정리
      if (error?.code === 'messaging/registration-token-not-registered' ||
          error?.code === 'messaging/invalid-registration-token') {
        logger.warn(`[customer-closed:${callId}] 무효한 FCM 토큰 발견, 자동 정리: ${phoneNumber}`);

        try {
          await admin.firestore()
            .collection("regions").doc(sourceRegionId)
            .collection("offices").doc(sourceOfficeId)
            .collection("customerInfo")
            .doc(phoneNumber)
            .update({ fcmToken: admin.firestore.FieldValue.delete() });

          logger.info(`[customer-closed:${callId}] 무효한 FCM 토큰 제거 완료: ${phoneNumber}`);
        } catch (deleteError) {
          logger.error(`[customer-closed:${callId}] 토큰 제거 중 오류:`, deleteError);
        }
      } else {
        logger.error(`[customer-closed:${callId}] 알림 전송 중 오류:`, error);
      }
    }
  }
);
```

### 2.4 작동 흐름

1. **트리거**: `shared_calls/{callId}` 문서 생성 감지
2. **검증**: status가 "OPEN"인지 확인
3. **전화번호 추출**: `sharedCallData.phoneNumber`
4. **고객 조회**: `regions/{sourceRegionId}/offices/{sourceOfficeId}/customerInfo/{phoneNumber}`
5. **FCM 토큰 확인**: `fcmToken` 필드 존재 여부
6. **알림 전송**: FCM 메시지 타입 "OFFICE_CLOSED" 전송
7. **에러 처리**: 무효한 토큰 자동 정리

### 2.5 알림 메시지 내용

```
제목: 🏢 사무실 마감 안내
내용: 사무실이 마감되어 잠시후 운행가능한 다른 사무실과 연결해 드리겠습니다.
```

## 4. 테스트 시나리오

### 4.1 정상 작동 테스트

1. **앱 회원이 전화 호출 (사무실 마감 상태)**
   - CallDetector가 전화 감지
   - `shared_calls` 컬렉션에 문서 생성
   - Cloud Function 트리거
   - customerInfo에서 FCM 토큰 조회
   - 고객 앱에 "사무실 마감 안내" 알림 표시

2. **앱 회원이 앱에서 호출 (사무실 마감 상태)**
   - 고객앱에서 호출 버튼 클릭
   - `shared_calls` 컬렉션에 문서 생성
   - 위와 동일한 프로세스

### 4.2 알림 미전송 케이스 (정상)

1. **비회원 전화 호출**
   - customerInfo에 해당 전화번호 없음
   - 로그: `customerInfo에 등록되지 않은 고객`
   - 알림 미전송 (나중에 SMS/카카오톡 보강)

2. **앱 삭제한 회원**
   - customerInfo에 전화번호는 있지만 fcmToken 없음
   - 로그: `고객 FCM 토큰 없음 (앱 미설치 또는 미가입)`
   - 알림 미전송

3. **토큰 만료된 회원**
   - FCM 전송 실패 에러 발생
   - 자동으로 무효한 토큰 제거
   - 로그: `무효한 FCM 토큰 발견, 자동 정리`
