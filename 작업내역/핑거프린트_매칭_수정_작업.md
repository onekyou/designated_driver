# 핑거프린트 매칭 수정 작업

## 작업 일시
2025-10-22

## 현재 문제
- 랜딩페이지에서 APK 다운로드 → 설치 → 실행 시 사무실 정보가 자동으로 연결되지 않음
- 핑거프린트 매칭 시스템이 작동하지 않음

## 시스템 구조 (올바른 로직)
1. 사용자가 QR 코드 스캔 → 랜딩페이지 접속
2. 랜딩페이지에서 핑거프린트 수집 → Firebase에 저장 (`regions/{regionId}/offices/{officeId}/attributions/`)
3. APK 다운로드 → 설치 → 앱 실행
4. 앱에서 핑거프린트 매칭 → 사무실 정보 자동 연결
5. 완료

## 핑거프린트 매칭 시스템 구성요소

### 1. 랜딩페이지 (customer_app/landing/app/page.tsx)
- FingerprintJS로 핑거프린트 수집
- Firebase에 저장하는 로직 있음 ✅
- 현재 정상 작동 확인됨 (Firebase에 데이터 5건 저장됨)
- visitorId: `9d5d1318d3bb61471db848fe41e5f87f`

### 2. 앱 - AttributionMatchingService.kt
- 경로: `customer_app/app/app/src/main/java/com/designated/customer/service/AttributionMatchingService.kt`
- 역할: 디바이스 핑거프린트를 수집하고 Cloud Function을 호출하여 매칭
- Cloud Function 이름: `matchAttribution`
- 리전: `asia-northeast3`

### 3. 앱 - MainActivity.kt
- 경로: `customer_app/app/app/src/main/java/com/designated/customer/MainActivity.kt`
- 라인 153-196: Attribution 매칭 실행 로직
- `LaunchedEffect(Unit)` 내에서 실행 (앱 시작 시 자동 실행)
- 조건: `currentOfficeId == null || currentRegionId == null`

### 4. Cloud Function (추정)
- 함수 이름: `matchAttribution`
- 역할: 디바이스 정보를 받아서 Firebase의 attributions 컬렉션과 매칭
- 문제: 이 함수가 존재하는지, 제대로 작동하는지 확인 필요
