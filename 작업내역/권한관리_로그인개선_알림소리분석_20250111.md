#### 🔸 완전한 로그아웃 구현
**콜디텍터**:
```kotlin
onLogout = {
    // 모든 설정 데이터 삭제
    authPrefs.edit().apply {
        clear()
        putBoolean("explicitly_logged_out", true)
        apply()
    }
    
    // 저장된 로그인 정보 삭제 (자동로그인 설정은 유지)
    loginPrefs.edit().apply {
        remove("email")
        remove("password")
        apply()
    }
    
    // Firebase 로그아웃 + 서비스 중지 + 앱 완전 종료
    FirebaseAuth.getInstance().signOut()
    stopService(serviceIntent)
    finishAffinity()
    System.exit(0)
}
```

**콜매니저**:
```kotlin
onLogout = {
```

## 🚨 현재 확인된 문제

### 1. 일반공유콜 vs 마감공유콜 소리 차이
**사용자 보고**: 일반공유콜과 마감공유콜의 알림소리가 다르게 들림
**분석 결과**: 
- 코드상으로는 **동일한 설정** 사용 (`SHARED_CALL_CHANNEL_ID` + `TYPE_ALARM`)
- 마감콜 구분은 알림 **내용만** 다름:
  ```kotlin
  when (callType) {
      "AFTER_HOURS", "MISSED_CALL", "AFTER_HOURS_QUICK" -> {
          Triple("🌙 마감콜 공유", "마감 후 접수된 콜", ...)
      }
      else -> {
          Triple("🚨 새로운 공유콜이 도착했습니다! 🚨", ..., ...)
      }
  }
  ```

**추정 원인**:
- 디바이스별/Android 버전별 `TYPE_ALARM` 소리 차이
- FCM 자동 알림과 커스텀 알림의 타이밍 겹침
- 시스템 알림 설정 또는 알림 채널 캐시 문제

### 2. 운행상태 알림음 변경 미적용
**설정**: 채널 레벨에서 `DEFAULT_NOTIFICATION_URI`로 변경 완료
**문제**: 실제 기기에서 여전히 이전 소리 재생
**분석 결과**: 
- 코드상 설정은 정상 (`MyFirebaseMessagingService.kt:275-281`)
- `showNotification` 메서드에서 추가 소리 설정 없음 (운행상태 알림은 채널 소리 사용)

**추정 원인**:
1. **Android 채널 캐시**: 기기에서 알림 채널 설정이 캐시되어 변경 미반영
2. **앱 재시작 필요**: 채널 설정 변경 후 완전 재시작 필요
3. **시스템 알림 설정**: 사용자가 시스템에서 채널 소리를 수동 변경
4. **제조사 커스텀**: 안드로이드 제조사별 알림 처리 차이
