# FCM 팝업 출발/도착/요금 표시 문제 진단 (2026-01-07)

## 현재 상황

### 정상 작동 ✅
1. **내부호출목록**: 상태 및 목적지 업데이트 정상
2. **기사 카드**: 상태 업데이트 정상 (WAITING ↔ ON_TRIP)
3. **다음 배차**: 운행 완료 후 정상적으로 가능

### 문제 ❌
1. **운행시작 팝업**: 출발지/도착지/요금이 표시되지 않음
2. **운행완료 팝업**: 출발지/도착지/요금이 표시되지 않음

### 증상 변화
- **이전**: 출발지/도착지는 표시되었으나 **요금만** 표시 안 됨
- **현재**: 출발지/도착지/요금 **모두** 표시 안 됨 (요금은 "0원"으로 표시)

## 작업 히스토리

### 초기 문제 (2026-01-06)
- **문제**: 재배차 시 목적지 미표시
- **원인**: CallDao가 일반 필드 업데이트, UI는 `_set` 필드 읽음
- **해결**: `updateDestinationInfo`를 `departure_set`, `destination_set`으로 변경

### FCM 메시지 미수신 문제
- **원인**: Cloud Functions가 `admins` 컬렉션에서 토큰 조회 (실제는 `managerTokens`에 있음)
- **해결**: `managerTokens` 컬렉션에서 토큰 조회하도록 변경

### 포그라운드 메시지 무시 문제
- **원인**: 앱이 포그라운드에 있을 때 모든 FCM 메시지 무시 (리스너 기반 시절의 로직)
- **해결**: 포그라운드 체크 로직 제거 → 모든 메시지 처리

### CALL_STATUS_UPDATE 미도착 문제
- **원인**: `android: { priority: "high" }` 설정 없어서 안드로이드가 메시지 무시
- **해결**: CALL_STATUS_UPDATE에 android priority 추가

### 로컬 DB 업데이트 미작동 문제
- **원인**:
  1. CALL_STATUS_UPDATE 처리 로직 자체가 없음
  2. DRIVER_STATUS_UPDATE가 `callId` 필수인데 메시지에는 `driverId`만 있음
- **해결**:
  1. `handleCallStatusUpdate` 함수 추가 (로컬 DB 업데이트)
  2. DRIVER_STATUS_UPDATE는 callId 없이도 처리 가능하도록 수정
  3. `handleDriverStatusUpdate`에 로컬 DB 업데이트 추가

### 요금 표시 문제 (최근)
- **원인 추정**: `||` 연산자가 `0`을 falsy로 취급
- **시도한 해결**: `||` → `??` (nullish coalescing) 변경
- **결과**: 오히려 출발지/도착지/요금 모두 표시 안 됨

```kotlin
// MyFirebaseMessagingService.kt:613-624
private fun handleStatusChange(remoteMessage: RemoteMessage, callId: String) {
    val statusText = remoteMessage.data["statusText"] ?: "상태 변경"
    val customerName = remoteMessage.data["customerName"] ?: "고객"
    val customerPhone = remoteMessage.data["customerPhone"] ?: "-"
    val departure = remoteMessage.data["departure"] ?: ""
    val destination = remoteMessage.data["destination"] ?: ""
    val fare = remoteMessage.data["fare"] ?: ""
    val driverName = remoteMessage.data["driverName"] ?: "기사"

    Log.d(TAG, "🚗 [STATUS_CHANGE] statusText=$statusText, departure=$departure, destination=$destination, fare=$fare")

    val tripInfo = buildString {
        if (departure.isNotEmpty()) append("\n출발: $departure")
        if (destination.isNotEmpty()) append("\n도착: $destination")
        if (fare.isNotEmpty() && fare != "0") append("\n요금: ${fare}원")
    }
}
```

## 참고: FCM 메시지 타입

### CALL_STATUS_UPDATE
- **용도**: 로컬 DB 업데이트 (내부호출목록, 기사카드)
- **전송 시점**: 모든 상태 변경
- **포함 데이터**: status, departure, destination, assignedDriverName

### STATUS_CHANGE
- **용도**: 팝업 알림 표시
- **전송 시점**: 운행 시작, 운행 완료
- **포함 데이터**: statusText, customerName, customerPhone, driverName, departure, destination, fare

### DRIVER_STATUS_UPDATE
- **용도**: 기사 상태 카드 업데이트
- **전송 시점**: 기사 상태 변경
- **포함 데이터**: driverId, driverName, newStatus, oldStatus
