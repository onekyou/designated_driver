# FCM 공유콜 알림 문제 최종 분석 및 해결 시도
작성일: 2025-09-15

## 📌 문제의 시작

### 원래 상황 (문제 제기 전)
- **동작 방식**: Full-Screen Intent로 화면꺼짐 상태에서 알림 없이 직접 배차팝업 표시
- **문제점**: 사용자가 "알림이 필요하다"고 요청
- **사용자 요구**: 화면꺼짐 상태에서도 알림을 보고 싶어함

## 🔄 해결 시도 과정

### 1단계: 하이브리드 FCM 방식 도입
**목표**: 알림 표시 + 배차팝업 연결

**구현**:
- FCM 메시지: `notification` + `data` 필드 포함
- 화면꺼짐: 시스템 알림 의존
- 화면켜짐: 앱에서 커스텀 처리

**결과**:
- ✅ 알림은 표시됨
- ❌ **핵심 문제 발견**: 알림 표시 시간이 너무 짧음 (빠르게 여러 번 클릭해야 포그라운드 전환)

### 2단계: 알림 지속 시간 연장 시도
**시도한 방법들**:
- `sticky: true` 추가 → 효과 없음 (Firebase Admin SDK 미지원)
- `autoCancel: false` 추가 → TypeScript 타입 오류
- `ongoing: true` 추가 → TypeScript 타입 오류

**결과**: 모든 시도 실패

### 3단계: 전문가 상담
**전문가 답변 요약**:
> **하이브리드 메시지(`notification` + `data`)의 한계 때문이며, Data-only 메시지로 전환하여 앱에서 직접 알림을 생성하는 것이 가장 확실하고 올바른 해결책**

**권장 해결책**:
1. **Data-only FCM 메시지** 사용
2. **Full-Screen Intent** 구현 (전화 수신과 같은 방식)
3. **Ongoing Notification** 사용

### 4단계: Data-only + 커스텀 알림 구현
**서버 변경사항**:
```typescript
// AS-IS (하이브리드)
const message = {
  notification: { title: "...", body: "..." },
  data: { ... },
  android: { notification: { ... } }
};

// TO-BE (Data-only)
const message = {
  data: {
    type: "NEW_SHARED_CALL",
    title: "🔄 새로운 공유콜!",
    body: "...",
    // ... 기타 데이터
  },
  android: { priority: "high" }
};
```

**앱 변경사항**:
```kotlin
// 기존: 화면 상태에 따른 분기 처리
// 변경: 항상 커스텀 알림 생성
private fun showCustomSharedCallNotification(remoteMessage: RemoteMessage) {
    val notificationBuilder = NotificationCompat.Builder(this, "shared_call_fcm_channel_v3")
        .setOngoing(true) // 스와이프로 삭제 불가
        // ... 기타 설정
}
```

**결과**:
- ✅ 알림 생성됨
- ❌ 여전히 "빠르게 두 번 클릭해야 포그라운드 전환" 문제 지속

### 5단계: Full-Screen Intent 구현
**의도**: 전문가 권장에 따라 즉시 전체화면 실행

**구현**:
```kotlin
.setFullScreenIntent(pendingIntent, true) // 전체화면 즉시 실행
.setCategory(NotificationCompat.CATEGORY_CALL) // 전화 카테고리
```

**결과**: 알림과 Full-Screen Intent가 동시 작동 → 혼란 가중

## 🔄 순환 논리의 발견

### 모순 상황
1. **원래**: Full-Screen Intent (알림 없이 직접 배차) → 사용자 "알림 필요" 요청
2. **하이브리드**: 알림 표시 시간 짧음 → 전문가 "기술적 불가능" 결론
3. **Data-only + Full-Screen**: 다시 알림 없이 직접 배차 → **원점 회귀**

### 기술적 한계 확인
**FCM 하이브리드 메시지의 시스템 알림**:
- 표시 시간은 Android OS가 제어
- 개발자가 직접 연장할 수 있는 표준 방법 없음
- Firebase Admin SDK에서 관련 옵션 미지원

**현실적 선택지**:
- **알림 우선**: 짧은 표시 시간, 클릭 어려움 (불가능)
- **기능성 우선**: Full-Screen Intent, 알림 없음 (가능)

## 🎯 사용자 최종 요구사항 (2025-09-15)

**새로운 해결 방향**:
> 현재상황에서 포그라운드 전환, 중간팝업 생성 팝업내용은 공유콜상황알리고 수락 취소 버튼 어느것을 누르던 알림 종료. 수락시 배차팝업.

**요구사항 분석**:
1. ✅ **포그라운드 전환**: 가능 (현재 작동 중)
2. ❓ **중간팝업 생성**: 새로운 요구사항
   - 내용: 공유콜 상황 알림
   - 버튼: 수락/취소
   - 동작: 어느 버튼이든 알림 종료
   - 수락 시: 기존 배차팝업으로 이동
3. ❓ **구현 가능성**: 분석 필요

- 사용자가 알림을 "봤다"는 확신 제공

4. 수락 시 기존 배차팝업으로 연결
