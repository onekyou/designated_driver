# 콜디텍터 백그라운드 팝업 수정 및 개인번호관리 기능 이식 완료

## 작업 일자: 2025-09-09

## 1. 백그라운드 팝업 문제 해결

### 문제 상황
- 독립 콜디텍터 앱에서 백그라운드 상태일 때 배차 팝업이 생성되지 않음
- Android 10+ 백그라운드 액티비티 시작 제한으로 인한 문제
- 콜매니저는 정상 작동하는데 콜디텍터만 팝업 생성 실패

### 해결 방법
1. **SYSTEM_ALERT_WINDOW 권한 활용**
   - MainActivity 경유 방식에서 직접 DispatchActivity 실행으로 변경
   - WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY 사용

2. **Intent Extra 이름 통일**
   - Service와 Activity 간 Extra 이름 불일치 문제 해결
   - "phoneNumber" → "EXTRA_PHONE_NUMBER" 등으로 통일

### 수정된 파일
- `call_detector/app/src/main/java/com/example/calldetector/CallDetectorService.kt`
  ```kotlin
  private fun showOverlayPopup(phoneNumber: String, adminUid: String, adminName: String) {
      if (Settings.canDrawOverlays(this)) {
          val dispatchIntent = Intent(this, com.example.calldetector.ui.DispatchActivity::class.java).apply {
              putExtra("EXTRA_PHONE_NUMBER", phoneNumber)
              putExtra("EXTRA_ADMIN_UID", adminUid)
              putExtra("EXTRA_ADMIN_NAME", adminName)
              putExtra("EXTRA_CALL_TIME", System.currentTimeMillis())
              addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
              addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP)
              addFlags(Intent.FLAG_ACTIVITY_SINGLE_TOP)
          }
          startActivity(dispatchIntent)
      }
  }
  ```

## 2. 개인번호관리 기능 콜매니저 이식

### 작업 내용
독립 콜디텍터 앱의 개인번호관리 기능을 콜매니저 내장 콜디텍터로 완전 이식

### 구현된 기능
1. **개인번호 관리 시스템**
   - 번호 추가/삭제/검색
   - 백업/복원 기능
   - 연락처 연동 준비 (UI만 구현)

2. **콜 생성 필터링**
   - 개인번호로 등록된 번호는 콜 생성 제외
   - CallDetectorService에서 자동 필터링

## 4. 데이터 구조

### SharedPreferences 키
- `exclude_numbers`: 개인번호 목록 (Set<String>)
- `exclude_number_{번호}`: 개별 번호 정보 (이름 포함)

### 백업 파일
- 위치: 앱 내부 저장소 `/files/exclude_numbers_backup.json`
- 형식: JSON 배열
```json
[
  {
    "phoneNumber": "010-1234-5678",
    "name": "홍길동",
    "addedAt": 1234567890000
  }
]
```
