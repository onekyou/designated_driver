# 운행 상태 알림 벨소리 문제 심화 분석 및 해결 시도

**작업일**: 2025년 1월 12일  
**문제**: 운행 시작/완료 알림이 기본 알림음 대신 벨소리로 재생되는 문제  
**목표**: 공유콜은 큰 알람 소리 유지, 운행 상태는 기본 알림음으로 변경  

---

## 🔍 문제 상황 요약

### 원하는 동작
- **공유콜**: 큰 알람 소리 (TYPE_ALARM) - **정상 작동**
- **운행 상태**: 기본 알림음 (DEFAULT_NOTIFICATION_URI) - **문제 발생**

### 실제 동작
- **공유콜**: 정상적으로 큰 알람 소리
- **운행 상태**: 벨소리가 재생됨 (의도와 다름)

```kotlin
// 시도 1: 채널별 다른 설정 적용

    STATUS_CHANGE_CHANNEL_ID -> {

        Triple(
            NotificationCompat.PRIORITY_MAX,       // 최고 우선순위 유지
            NotificationCompat.CATEGORY_CALL,      // 통화 카테고리 유지
            NotificationCompat.DEFAULT_VIBRATE or NotificationCompat.DEFAULT_LIGHTS
        )
    }
}
```

## 🤔 근본 원인 분석

### 확정된 사실들
1. **앱이 정상적으로 FCM 메시지 처리** (`onMessageReceived()` 호출)
2. **채널 설정도 정상** (기본 우선순위, 상태 카테고리)
3. **채널 무음 설정해도 벨소리 재생** → 시스템이 다른 방식으로 알림 생성
4. **공유콜은 정상 작동** (동일한 `alertTitle`, `alertMessage` 키 사용)

### 추정 원인들

#### A. FCM 메시지 이중 처리
- 앱이 `onMessageReceived()`로 처리한 후
- Android 시스템이 추가로 동일한 FCM 메시지를 자동 처리
- 시스템 처리 시 높은 우선순위로 인식되어 벨소리 재생

#### B. FCM priority="normal"의 시스템 해석 차이
- `priority: "normal"`이어도 특정 조건에서 시스템이 높은 우선순위로 처리
- 메시지 내용, 타입, 또는 다른 메타데이터 영향

#### C. Android 시스템 버전/제조사별 FCM 처리 차이
- 특정 Android 버전이나 제조사에서 FCM 처리 방식이 다름
- 동일한 메시지도 다르게 해석

#### D. Firebase 프로젝트 설정 문제
- Firebase 콘솔이나 프로젝트 설정에서 알림 동작 관련 설정
- 앱 등록 시 설정된 기본 알림 동작

## 🔍 공유콜과의 차이점 분석

### 공유콜 (정상 작동)
```kotlin
// showNotificationWithActions() 사용
.setDefaults(NotificationCompat.DEFAULT_VIBRATE)  // 진동만 기본값
.setSound(alarmUri, AudioManager.STREAM_ALARM)    // 명시적 알람 소리 설정
```

### 운행 상태 (문제 발생)
```kotlin
// showNotification() 사용
.setDefaults(NotificationCompat.DEFAULT_VIBRATE or NotificationCompat.DEFAULT_LIGHTS)  // 소리 제외
// 채널 소리에 의존 (명시적 소리 설정 없음)
```

### 핵심 차이점
1. **소리 설정 방식**: 공유콜은 명시적, 운행상태는 채널 의존
2. **사용 메서드**: 서로 다른 알림 생성 메서드
3. **FCM priority**: 공유콜 `high`, 운행상태 `normal`

```kotlin
// showNotification에서 운행 상태 알림 시
when (channelId) {
    STATUS_CHANGE_CHANNEL_ID -> {
        val basicNotificationUri = Settings.System.DEFAULT_NOTIFICATION_URI
        notificationBuilder.setSound(basicNotificationUri, AudioManager.STREAM_NOTIFICATION)
    }
}
```
