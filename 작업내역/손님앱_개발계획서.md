# 고객앱 개발 계획서 (콜매니저 연동 버전)

## 1. 프로젝트 개요

### 1.1 목적
- 지역 대리운전 사무실과 고객을 직접 연결하는 전용 앱
- **콜매니저와 완벽히 호환되는 데이터 구조**
- 고객 편의성 향상 및 재이용률 증대
- 단순하고 실용적인 사무실-고객 연결 시스템

### 1.2 핵심 원칙
- **콜매니저 호환성**: 기존 콜매니저 데이터 구조와 100% 호환
- **단순한 구현**: QR 스캔 → 사무실 연결 (복잡한 어트리뷰션 제거)
- **간편한 사용성**: 최소한의 조작으로 대리 호출
- **실용적 접근**: MVP 우선, 단계적 기능 확장
- **Android 우선**: 국내 시장 점유율 75%에 집중

## 2. 시스템 아키텍처

### 2.1 기술 스택 (콜매니저 호환)
- **플랫폼**: Android Native (Kotlin)
- **최소 SDK**: API 24 (Android 7.0)
- **타겟 SDK**: API 34 (Android 14)
- **UI 프레임워크**: Jetpack Compose
- **인증**: Firebase Phone Authentication
- **데이터베이스**: Cloud Firestore (콜매니저와 공유)
- **푸시 알림**: Firebase Cloud Messaging (FCM)
- **지도**: Kakao Maps API (차후 추가)
- **QR 스캔**: ZXing 라이브러리
- **연결 방식**: QR 스캔 → SharedPreferences 저장

## 3. 주요 기능 명세

### 3.1 Phase 1: MVP - 기본 호출 기능 (2주)

#### A. QR 스캔 및 사무실 연결
1. **QR 코드 시스템 (콜매니저 호환)**
   - QR 데이터: `https://designated-driver.app/office/{regionId}/{officeId}`
   - 콜매니저에서 자동 생성된 QR 사용
   - 단순 스캔 → 저장 (복잡한 매칭 없음)
   - SharedPreferences에 사무실 정보 저장

2. **전화번호 인증**
   - Firebase Phone Auth 구현
   - SMS 6자리 코드 자동 읽기
   - 인증 후 고객 정보 저장

3. **고객 등록 (콜매니저 CustomerInfo 구조)**
   ```kotlin
   // 고객 정보 저장
   val customer = hashMapOf(
       "id" to customerId,
       "phoneNumber" to phoneNumber,
       "name" to userName,
       "grade" to "bronze", // 기본 등급
       "points" to 0,
       "totalRides" to 0,
       "totalSpent" to 0L,
       "linkedOfficeId" to officeId,
       "primaryOfficeId" to officeId,
       "registeredAt" to Timestamp.now()
   )
   // regions/{regionId}/offices/{officeId}/customers/{customerId}
   firestore.collection("regions").document(regionId)
       .collection("offices").document(officeId)
       .collection("customers").document(customerId)
       .set(customer)
   ```


4. **메인 화면**
   - 대형 "전화 걸기" 버튼 (원터치 호출)
   - 현재 위치 자동 표시
   - 출발지/도착지 입력 옵션

5. **콜 생성 (콜매니저 CallInfo 구조)**
   ```kotlin

   ```

## 8. 사무실 연결 전략 (단순화)

### 8.1 QR 기반 단순 연결

#### MVP: QR 스캔 → SharedPreferences 저장
```kotlin
class OfficeConnectionManager {
    // 단순 QR 스캔 처리
    fun processQRData(qrUrl: String): OfficeInfo? {
        // https://designated-driver.app/office/{regionId}/{officeId}
        val pattern = "https://designated-driver.app/office/([^/]+)/([^/]+)"
        val matcher = Regex(pattern).find(qrUrl)

        return if (matcher != null) {
            val regionId = matcher.groupValues[1]
            val officeId = matcher.groupValues[2]

            // SharedPreferences에 저장
            sharedPrefs.edit {
                putString("linkedRegionId", regionId)
                putString("linkedOfficeId", officeId)
                putBoolean("isLinked", true)
                putLong("linkedAt", System.currentTimeMillis())
            }

            OfficeInfo(regionId, officeId)
        } else null
    }
}
```

#### 예비 방안: 랜딩페이지 (차후 구현)
- QR 스캔 실패 시 대안
- 버셀 랜딩페이지 활용
