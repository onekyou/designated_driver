# 🚗 일반관리자용 콜매니저 앱 - 완성 및 작동 방식 상세 설명

## 📅 작업 완료일: 2024.12

## 📱 앱 개요
**콜매니저 앱은 대리운전 사무실 관리자가 사용하는 통합 관리 앱입니다.**
관리자는 이 앱 하나로 전화 콜을 받고, 기사를 배차하고, 고객을 관리하는 모든 업무를 처리할 수 있습니다.

---

## 1️⃣ 회원가입과 초기 설정

### 관리자가 처음 앱을 설치하면:

1. **회원가입 화면**에서 사무실 정보를 입력합니다
   - 지역 선택 (예: 서울, 경기)
   - 사무실 이름 입력 (예: 천사대리운전)
   - 관리자 계정 생성

2. **자동으로 QR 코드가 생성됩니다**
   - 이 QR은 고객이 스캔해서 사무실을 등록하는 용도
   - 한 번 생성되면 수정 불가능 (보기/다운로드만 가능)
   - 랜딩페이지 URL도 자동 설정됨

---

## 2️⃣ 메인 대시보드 - 실시간 콜 관리

### 로그인 후 보이는 메인 화면:

**상단 영역 - 요약 정보**
- 오늘의 콜 수, 완료된 콜, 대기 중 콜
- 활성 기사 수, 대기 기사 수

**중앙 영역 - 콜 리스트**
실시간으로 들어오는 콜들이 카드 형태로 표시됩니다:

- **일반 전화 콜**: 그냥 표시
- **앱 콜**: 📱 초록색 폰 아이콘 표시 (고객이 앱/랜딩페이지로 요청)
- **공유 콜**: 🔄 노란색 공유 아이콘 (다른 사무실과 공유된 콜)

각 콜 카드에 표시되는 정보:
- 고객 이름과 출발지
- 고객 등급: 🥉브론즈, 🥈실버, 🥇골드, ⭐VIP
- 매칭 점수: 70점 이상이면 "신뢰 고객"
- 경과 시간: "5분 전", "30분 전" 등
- 콜 상태: 대기중, 배차됨, 운행중, 완료

---

## 3️⃣ 콜 처리 프로세스

### 새로운 콜이 들어오면:

1. **콜 디텍터 앱**(별도 전화기)이 자동으로 전화를 감지
2. 콜매니저 앱에 실시간으로 전달
3. 관리자 화면에 팝업 알림 표시

### 관리자가 콜을 클릭하면:

**배차 화면이 열립니다:**
- 대기 중인 기사 목록 표시
- 각 기사의 현재 위치와 상태
- 기사 선택 → 배차 버튼 클릭

**배차 후:**
- 기사 앱으로 푸시 알림 전송
- 콜 상태가 "배차됨"으로 변경
- 기사가 수락하면 "운행중"으로 변경

---

## 4️⃣ 회원관리 시스템 (구 어트리뷰션)

### 설정 → 회원관리 메뉴에서:

**QR 코드 관리**
- 생성된 QR 코드 보기
- QR 다운로드/공유/인쇄
- 고객은 이 QR로 사무실 등록

**고객 목록 관리**
- 전체 고객 수, 활성 고객 수 통계
- 고객 검색 (전화번호)
- 등급별 필터링
- 페이지네이션으로 대량 데이터 처리

**고객 상세 정보**
- 기본 정보: 이름, 전화번호, 가입일
- 이용 통계: 총 이용 횟수, 월평균 이용
- 포인트 현황: 현재 포인트, 적립/사용 내역
- 매칭 정보: 어떤 경로로 가입했는지

---

## 5️⃣ 고객앱과의 연동

### 고객이 QR을 스캔하면:

1. **자동으로 사무실과 연결됩니다**
   - 고객 정보가 회원 목록에 추가
   - 매칭 점수 자동 계산 (70점 이상이면 확실한 우리 고객)

2. **고객이 앱으로 콜 요청하면:**
   - 콜 카드에 📱 아이콘 표시
   - 고객 등급 자동 표시
   - 포인트 자동 적립

### 포인트 시스템:
- **브론즈**: 3% 적립
- **실버**: 5% 적립
- **골드**: 7% 적립
- **VIP**: 9% 적립

---

## 6️⃣ 기타 관리 기능

### 기사 관리
- 가입 승인 대기 기사 목록
- 기사 정보 수정/삭제
- 기사별 정산 관리

### 정산 관리
- 일별/월별 정산 내역
- 기사별 수수료 계산
- 엑셀 내보내기

### 제외 번호 관리
- 스팸/악성 전화번호 등록
- 자동으로 콜 차단

## 🎯 핵심 특징

1. **실시간 동기화**: 모든 데이터가 Firebase로 실시간 동기화
2. **자동화**: QR 생성, 고객 매칭, 포인트 적립 모두 자동
3. **권한 제한**: 일반관리자는 자기 사무실 데이터만 접근 가능
4. **간단한 UI**: 복잡한 분석 없이 실무에 필요한 정보만 표시
