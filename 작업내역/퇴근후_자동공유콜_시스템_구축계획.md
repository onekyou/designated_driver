# 퇴근 후 자동 공유콜 시스템 구축 계획서

## 📋 프로젝트 개요

### 목표
- **사무실 퇴근 후 신규 콜을 자동으로 다른 사무실에 공유**
- **24시간 서비스 제공으로 비즈니스 기회 손실 최소화**
- **기존 시스템 활용으로 빠른 구현 및 안정성 확보**

### 현재 상황
- 2000개 사무실 규모의 대리운전 통합 플랫폼
- Firebase 기반 실시간 데이터 동기화
- Call Detector를 통한 자동 콜 생성 시스템
- 공유콜 시스템 완전 구현 (OPEN → CLAIMED → COMPLETED)
- 포인트 기반 정산 시스템 운영 중

### 문제점
- **퇴근 시간 후 고객 전화 → 아무도 받을 수 없음**
- **신규 콜이 다음날까지 방치되는 상황**
- **야간 시간대 매출 기회 완전 손실**

---

## 🎯 해결 방안

### 핵심 아이디어
**Call Detector에서 직접 공유콜 생성**
- 평상시: 일반 콜 → 자신의 사무실 calls 컬렉션에 저장
- 마감 후: **공유콜 → shared_calls 컬렉션에 직접 저장**

### 시스템 동작 흐름
```
1. 고객이 사무실에 전화 (밤 11시)
2. Call Detector가 전화번호 자동 추출
3. 사무실 상태 확인: "CLOSED"
4. shared_calls에 바로 공유콜 생성
5. 인근 사무실들에게 FCM 알림 발송
6. 수락한 사무실에서 고객에게 직접 전화
7. 정상적인 대리운전 서비스 진행
```

## 🔧 기술적 구현 방안

### 1. Call Detector 앱 수정

#### 추가 기능
- **사무실 상태 실시간 확인** (Firebase 캐싱 활용)
- **공유콜 직접 생성** 로직 추가
- **스마트 요금 추정** 시스템

#### 동작 로직
```javascript
// 전화 감지 시 분기 처리
if (officeStatus === "CLOSED") {
    // 공유콜로 직접 생성
    createSharedCall({
        phoneNumber: extractedNumber,
        sourceRegionId: regionId,
        sourceOfficeId: officeId,
        departure: "고객 연락 필요",
        destination: "상담 후 결정", 
        fare: estimateFare(regionId),
        status: "OPEN",
        timestamp: now()
    });
} else {
    // 기존 방식: 일반 콜 생성
    createNormalCall(...);
}
```

#### 요금 추정 알고리즘
```javascript
function estimateFare(regionId, timeOfDay) {
    const baseFare = REGION_BASE_FARE[regionId] || 15000;
    const nightSurcharge = (timeOfDay >= 22 || timeOfDay <= 6) ? 1.2 : 1.0;
    return Math.round(baseFare * nightSurcharge);
}
```

### 2. 자동응답 시스템 구축

#### 필요성
- 고객이 전화를 끊지 않고 기다리도록 안내
- 전문적인 서비스 이미지 유지
- Call Detector가 번호를 추출할 시간 확보

#### 구현 방법
```
Android 자동응답 기능:
- CLOSED 상태일 때만 활성화
- 권한: ANSWER_PHONE_CALLS, MODIFY_PHONE_STATE
- 멘트: "업무시간 외이지만 협력사 연결 중입니다. 3분 내 연락드리겠습니다."
- 재생 시간: 15-20초 후 자동 종료
```

### 3. 스마트 알림 시스템

#### 우선순위 기반 알림
```javascript
// 거리별 우선순위 알림
const nearbyOffices = calculateDistance(sourceLocation, allOffices)
    .filter(office => office.status === "OPEN")
    .slice(0, 5); // 가까운 5개 사무실

// 단계적 알림 발송
sendPriorityNotification(nearbyOffices, sharedCallInfo);
```

#### 알림 메시지 최적화
```json
{
    "title": "🌙 심야 공유콜",
    "body": "거리 3km | 예상수익 1,500원 | 고객 연락 필요",
    "data": {
        "callId": "shared_call_123",
        "priority": "high",
        "estimatedDistance": "3km",
        "estimatedEarnings": "1500"
    }
}
```

```javascript
        maxShareDistance: 10 // km
    }

```

### 자동 마감 체크 시스템
```javascript
// Cloud Functions - 30분마다 실행
exports.checkAutoClosing = functions.pubsub
    .schedule('*/30 * * * *')
    .onRun(async (context) => {
        const offices = await getOfficesWithAutoClose();
        
        for (const office of offices) {
            if (shouldCloseNow(office.operatingHours)) {
                await updateOfficeStatus(office.id, "CLOSED");
                await triggerAutoSharing(office.id);
            }
        }
    });
```
