손님앱 테스트방법

✅ 가능한 부분:

  1. 콜매니저에서 QR 생성 - 가능 (이미 구현됨)
  2. 랜딩페이지 - 가능 (Next.js 프로젝트 존재)
  3. 고객앱 딥링크 처리 - 가능 (이미 구현됨)
  4. 사무실 자동 연결 - 가능 (SharedPreferences 저장)
  5. 콜 생성 및 콜매니저 연동 - 가능 (호환성 확보됨)

  ❌ 제한 사항:

  - 앱스토어 업로드: 불가능 (개발자 계정 필요)
  - 실제 QR 스캔: APK 직접 설치로 대체 필요

  📋 당신이 해야 할 일들:

  1단계: QR 코드 생성

  콜매니저 앱 실행 → 설정 → 회원관리 → QR 코드 생성/확인

  2단계: 랜딩페이지 실행 (로컬)

  customer_app/landing 폴더에서 npm run dev
  → http://localhost:3000/office/seoul/TEST_OFFICE 접속 테스트

  3단계: 고객앱 설치 (APK)

  customer_app/app/app/build/outputs/apk/debug/app-debug.apk
  → 실제 폰에 설치

  4단계: 딥링크 테스트

  랜딩페이지의 "앱 다운로드" 버튼 클릭
  → 고객앱이 딥링크로 실행되는지 확인

  5단계: 전체 플로우 테스트

  전화인증 → 자동 사무실 연결 → 콜 생성 → 콜매니저에서 📱 아이콘 확인

  모든 구성 요소가 준비되어 있어서 완전한 테스트가 가능합니다!
