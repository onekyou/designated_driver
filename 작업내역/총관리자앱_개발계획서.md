# 총관리자 앱 종합 계획서 (보안/유지보수/확장성 중심)

## 🔒 1. 보안 아키텍처 (최우선)

### 인증 & 권한 시스템
```
Multi-Layer Authentication:
├── Firebase Admin Authentication (최상위)
├── Custom Claims (역할별 권한)
├── IP 화이트리스트
├── 2FA (OTP/SMS)
└── Session Management (자동 로그아웃)
```

**구현 방안:**
- Firebase Admin SDK 사용 (일반 Authentication과 분리)
- Custom Claims: `{admin: true, permissions: ['point_management', 'settlement']}`
- 모든 포인트 거래에 디지털 서명 추가
- 거래 로그 암호화 저장

### 포인트 보안 설계

## 📋 8. 콜매니저 포인트 시스템 수정 사항

### 즉시 적용할 수정사항 (테스트용)
1. **포인트 거래 내역을 사무실별로 이동**
   - 현재: `firestore.collection("point_transactions")`
   - 변경: `officeRef.collection("point_transactions")`

2. **거래 타입 확장**
   ```kotlin
   enum class PointTransactionType {
       CHARGE,           // 포인트 충전
       SHARED_CALL_SEND, // 공유콜 송금
       SHARED_CALL_RECEIVE, // 공유콜 수익
       ADMIN_CHARGE,     // 관리자 충전 (추가)
       ADMIN_EXCHANGE,   // 관리자 환전 (추가)
       ADJUSTMENT        // 정산 조정 (추가)
   }
   ```

3. **잔액 검증 로직 추가**
   ```kotlin
   fun validateBalanceConsistency(): Boolean {
       val calculatedBalance = pointTransactions.sumOf { it.amount }
       val storedBalance = pointsInfo.balance
       return calculatedBalance == storedBalance
   }
   ```
