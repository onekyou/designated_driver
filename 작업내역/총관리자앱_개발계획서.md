# 총관리자 웹앱 개발 계획서 (2025년 최신 버전)

## 📋 개요

### 목적
- **콜매니저 앱**(일반 사무실 관리자용)과 연동하여 **총관리자** 전용 통합 관리 기능 제공
- 다중 사무실 실시간 모니터링 및 성과 비교
- 전사 Attribution 시스템 관리 및 분석
- 전체 포인트 경제 시스템 관리
- 고객 재귀속 승인 및 분쟁 조정

### 플랫폼 선택: 웹앱 (Web Application)

#### 왜 웹앱인가?

| 비교 항목 | 웹앱 ✅ | 안드로이드 앱 |
|-----------|---------|--------------|
| **주 사용 환경** | PC 큰 화면 (사무실) | 모바일 작은 화면 |
| **사용자** | 본사 관리자 1-2명 | 본사 관리자 1-2명 |
| **배포/업데이트** | URL 공유 → 즉시 반영 | APK 빌드 → 재설치 필요 |
| **접근성** | PC/태블릿/모바일 모두 | 안드로이드만 |
| **개발 기간** | 4주 | 6주+ |
| **대시보드/차트** | 최적화됨 | 작은 화면에 부적합 |
| **UI 라이브러리** | 매우 풍부 | 상대적으로 제한적 |

#### 사용 시나리오
```
총관리자의 일과:
09:00 - 본사 사무실 출근, PC 켜고 웹 대시보드 확인
10:00 - 2,000개 사무실 실시간 현황 모니터링 (큰 화면 필수)
11:00 - 사무실별 성과 비교 차트 분석
14:00 - 재귀속 요청 승인 처리
16:00 - 포인트 정책 조정
17:00 - Attribution 통계 분석
18:00 - 일일 리포트 다운로드

→ 모든 작업이 사무실 PC에서 진행
→ 큰 화면, 편한 입력, 풍부한 시각화가 필수
→ 웹앱이 최적!
```

### 현재 시스템 상태 (2025년 기준)

#### ✅ 완성된 앱들
1. **콜매니저 앱** (Android - 일반관리자용)
   - 단일 사무실 콜 관리 및 기사 배차
   - 고객 관리 (등급별 필터링, 활동 상태 추적)
   - Attribution 통계 조회 (ReadOnly)
   - 정산 관리 (일일 세션, 크레딧 관리)
   - 공유콜 시스템

2. **고객 앱** (Android)
   - 익명 인증 기반 회원 시스템
   - 포인트 적립/사용 (등급별: 3%/5%/7%/9%)
   - 콜 요청 및 실시간 추적
   - QR 코드 기반 사무실 연결

3. **기사 앱** (Android)
   - 콜 수락 및 운행 관리
   - 실시간 FCM 알림
   - 운행 기록 및 정산

4. **Call Detector 앱** (Android)
   - 전화 수신 자동 감지
   - Firestore 자동 콜 생성

5. **고객앱 랜딩페이지** (Web - Next.js)
   - QR 스캔 후 앱 다운로드
   - Attribution 토큰 처리

#### ✅ 구현된 백엔드 시스템
- **Firebase Cloud Functions**
  - oncallassigned: 콜 배정 FCM 알림
  - onCallCancelledByDriver: 취소 알림
  - processSharedCallPoints: 공유콜 정산
  - onRideCompleted: 포인트 적립

- **Attribution 시스템**
  - 토큰 기반 고객 매칭
  - 70점 임계값 기준
  - 소스별 분석

- **포인트 시스템**
  - 4단계 등급 (BRONZE/SILVER/GOLD/VIP)
  - 자동 승급
  - 만료 관리 (12개월)

- **공유콜 시스템**
  - 10% 수수료 자동 정산

### 3. Attribution 통합 관리

```typescript
// lib/services/attribution.ts
export class HeadManagerAttributionService {
  // 전사 Attribution 통계
  async getGlobalAttributionStats() {
    const attributions = await this.getAllAttributions();

    return {
      totalAttributions: attributions.length,
      successfulAttributions: attributions.filter(a => a.score >= 70).length,
      avgScore: calculateAverage(attributions.map(a => a.score)),
      bySource: groupBy(attributions, 'source'),
      byOffice: groupBy(attributions, 'officeId'),
      dailyTrend: calculateDailyTrend(attributions, 30)
    };
  }

  // 임계값 정책 관리
  async updateAttributionThreshold(officeId: string, newThreshold: number) {
    const settingRef = doc(
      db,
      `regions/${regionId}/offices/${officeId}/settings/attribution`
    );
    await updateDoc(settingRef, { threshold: newThreshold });
  }

  // Attribution 토큰 관리
  async getActiveTokens() {
    const tokensRef = collection(db, 'attributionTokens');
    const snapshot = await getDocs(query(tokensRef, where('status', '==', 'active')));
    return snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() }));
  }
}
```

```typescript
import { useQuery } from '@tanstack/react-query';
import { httpsCallable } from 'firebase/functions';
import { functions } from '@/lib/firebase';

export function useArchivedStats(params: {
  startDate: string;

  regionId?: string;
  officeId?: string;
}) {
  return useQuery({
    queryKey: ['archivedStats', params],
```

```javascript
// 총관리자 체크 함수
function isHeadManager() {
  let adminDoc = get(/databases/$(database)/documents/admins/$(request.auth.uid));
  return request.auth != null &&
         adminDoc.data.role in ['HEAD_MANAGER', 'SUPER_ADMIN'];
}

// 총관리자 전용 컬렉션
match /regions/{regionId}/globalStats/{document=**} {
```

## 📝 참고사항

### 왜 안드로이드 앱이 아닌가?

콜매니저, 기사앱, 고객앱은 모두 **이동 중** 또는 **현장**에서 사용되므로 Android 앱이 적합합니다:
- ✅ 콜매니저: 사무실에서 실시간 배차 (하지만 하루 종일 앱만 봄)
- ✅ 기사앱: 차량 이동 중 콜 수락
- ✅ 고객앱: 외출 중 콜 요청

하지만 **총관리자**는:
- ❌ 이동하며 작업하지 않음 (본사 사무실 근무)
- ❌ 긴급 푸시 알림 불필요 (주기적 모니터링)
- ✅ 큰 화면에서 많은 데이터 분석 필요
- ✅ 차트/그래프 시각화가 중요
- ✅ 편한 입력 환경 필요 (정책 설정 등)

→ **웹앱이 압도적으로 유리!**
