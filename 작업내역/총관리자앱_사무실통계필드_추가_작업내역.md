## 📋 작업 개요

### 문제
총관리자 웹앱의 사무실 목록 페이지에서 다음 정보가 표시되지 않음:
- 연락처 (phoneNumber)
- 기사 수 (driverCount)
- 고객 수 (customerCount)
- 구독 정보 (subscriptionTier, subscriptionStatus)

### 원인 분석
1. Firestore의 `offices` 문서에 해당 필드가 없음
2. 실제 필드명 불일치: `phoneNumber` → `phone`
3. 기사/고객 수를 조회하려면 서브컬렉션 쿼리 필요
   - 문제점: 2000개 사무실 시 6000개 쿼리 발생 (비용↑, 속도↓)

### 3. Cloud Functions 작성 (자동 카운트 업데이트)

**수정 파일**: `functions/src/index.ts` (2271-2345줄)

#### Function 1: 기사 수 자동 업데이트
```typescript
export const onDriverCountChange = onDocumentWritten(
  {
    region: "asia-northeast3",
    document: "regions/{regionId}/offices/{officeId}/designated_drivers/{driverId}"
  },
  async (event: any) => {
    // 기사 추가/삭제 시 자동 실행
    const driversSnapshot = await getDocs(driversRef);
    const driverCount = driversSnapshot.size;

    // 사무실 문서 업데이트
    await officeRef.update({
      driverCount: driverCount,
      statsUpdatedAt: serverTimestamp()
    });
  }
);
```

#### Function 2: 고객 수 자동 업데이트
```typescript
export const onCustomerCountChange = onDocumentWritten(
  {
    region: "asia-northeast3",
    document: "regions/{regionId}/offices/{officeId}/customers/{customerId}"
  },
  async (event: any) => {
    // 고객 추가/삭제 시 자동 실행
    const customersSnapshot = await getDocs(customersRef);
    const customerCount = customersSnapshot.size;

    // 사무실 문서 업데이트
    await officeRef.update({
      customerCount: customerCount,
      statsUpdatedAt: serverTimestamp()
    });
  }
);
```

**작동 방식**:
1. 기사가 회원가입 → `designated_drivers` 컬렉션에 문서 생성
2. `onDriverCountChange` 자동 실행
3. 해당 사무실의 전체 기사 수 조회
4. 사무실 문서의 `driverCount` 필드 자동 업데이트
