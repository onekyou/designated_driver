## 2. 시스템 아키텍처 (실제 구현)

### 2.1 기술 스택 ✅ **계획대로 구현**
- ✅ **플랫폼**: Android Native (Kotlin)
- ✅ **최소 SDK**: API 24 (Android 7.0)
- ✅ **타겟 SDK**: API 34 (Android 14)
- ✅ **UI 프레임워크**: Jetpack Compose
- ✅ **인증**: Firebase Phone Authentication
- ✅ **데이터베이스**: Cloud Firestore (콜매니저와 공유)
- ⏸️ **푸시 알림**: Firebase Cloud Messaging (구현 예정)
- ⏸️ **지도**: Kakao Maps API (구현 예정)
- ❌ **QR 스캔**: ZXing 라이브러리 (**실제로는 단순 URL 파싱 방식 채택**)
- ✅ **연결 방식**: QR 스캔 → SharedPreferences 저장

### 2.2 실제 구현된 데이터 구조

```firestore

│       │   ├── customerName: string
│       │   ├── customerAddress: string (departure와 매핑)

// PointService.kt - 실시간 포인트 업데이트
fun observeCustomerPoints(phoneNumber: String): Flow<CustomerPoints?> = callbackFlow {
    val listener = firestore
        .collection("regions").document(regionId)
        .collection("offices").document(officeId)
        .collection("customerPoints")
        .document(phoneNumber)
        .addSnapshotListener { snapshot, error ->
            val points = CustomerPoints.fromMap(snapshot.data ?: emptyMap())
            trySend(points)
        }
    awaitClose { listener.remove() }
}
```
