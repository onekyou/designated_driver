- ✅ 고객앱 **앱호출** 시 포인트 **적립** 기능

### 미구현 기능
- ❌ 포인트 **사용** 기능 없음
- ❌ **전화호출** 시 포인트 처리 불완전

- `observeCustomerPoints()` 타이밍 이슈 → PERMISSION_DENIED (해결됨)

## 🎯 개선 목표

### 핵심 원칙
**"기사앱 정산 시 모든 포인트 처리 통합"**

1. **통일성**: 앱호출/전화호출 구분 없이 동일한 포인트 처리
2. **단순성**: 기사앱 정산 시 한 번에 처리 (사용 + 적립)
3. **정확성**: 실제 확정 요금 기준으로 포인트 계산
4. **실시간성**: 고객앱에 즉시 반영 및 팝업 표시

### 기대 효과
- 앱 회원은 어떤 방법으로든 포인트 혜택
- 기사는 간단한 UI로 포인트 처리
- 고객은 실시간 포인트 적립/사용 확인

## 🏗️ 시스템 설계

### 회원 판별 로직

```
회원 여부 = customers 컬렉션에 phoneNumber 존재 여부
```

**판별 시점**:
- 앱호출: 고객앱에서 자동 설정 (isAppCustomer = true)
- 전화호출: 콜 디텍터에서 customers 조회 후 설정

### 포인트 처리 흐름

```
┌─────────────────────────────────────────────┐
│ 1. 콜 생성 (앱호출 또는 전화호출)            │
│    → isAppCustomer 필드 설정                │
└─────────────────┬───────────────────────────┘
                  ↓
┌─────────────────────────────────────────────┐
│ 2. 콜매니저: 기사 배차                      │
│    → 앱 회원이면 핸드폰 아이콘 표시         │
└─────────────────┬───────────────────────────┘
                  ↓
┌─────────────────────────────────────────────┐
│ 3. 기사앱: 운행 → 정산 화면                 │
│    → isAppCustomer == true면:               │
│      - 고객 포인트 정보 표시                │
│      - 포인트 사용 입력 UI 제공             │
└─────────────────┬───────────────────────────┘
                  ↓
┌─────────────────────────────────────────────┐
│ 4. 기사앱: 정산 완료 처리                   │
│    → 포인트 사용/적립 트랜잭션 실행         │
│    → Firestore 업데이트                     │
└─────────────────┬───────────────────────────┘
                  ↓
┌─────────────────────────────────────────────┐
│ 5. 고객앱: 운행 완료 감지                   │
│    → CallService가 COMPLETED 감지           │
│    → 포인트 적립/사용 팝업 표시             │
└─────────────────────────────────────────────┘
```

```kotlin
            .collection("regions").document(regionId)
            .collection("offices").document(officeId)
            .collection("customerPoints")

    }
```

##### 2) 포인트 처리 함수 추가
```kotlin
/**
 * 포인트 사용 + 적립 통합 처리
 */
private suspend fun processCustomerPoints(
    phoneNumber: String,
    callId: String,
    fare: Int,
    pointsUsed: Int
): Boolean {
    return try {
        // 중복 체크
        val existingTransactions = firestore
            .collection("regions").document(regionId)
            .collection("offices").document(officeId)
            .collection("pointTransactions")
            .whereEqualTo("callId", callId)
            .get()
            .await()

        if (!existingTransactions.isEmpty) {
            android.util.Log.w("DriverViewModel", "이미 처리된 포인트: $callId")
            return true  // 이미 처리됨
        }

        // 포인트 정보 조회
        val pointsDoc = firestore
            .collection("regions").document(regionId)
            .collection("offices").document(officeId)
            .collection("customerPoints")
            .document(phoneNumber)
            .get()
            .await()

        // 신규 고객이면 초기 포인트 생성
        if (!pointsDoc.exists()) {
            val initialPoints = mapOf(
                "customerId" to phoneNumber,
                "phoneNumber" to phoneNumber,
                "currentPoints" to 0,
                "totalEarned" to 0,
                "totalUsed" to 0,
                "grade" to "BRONZE",
                "totalCalls" to 0,
                "lastUpdated" to FieldValue.serverTimestamp(),
                "createdAt" to FieldValue.serverTimestamp()
            )

            firestore
                .collection("regions").document(regionId)
                .collection("offices").document(officeId)
                .collection("customerPoints")
                .document(phoneNumber)
                .set(initialPoints)
                .await()
        }

        // 재조회
        val refreshedDoc = firestore
            .collection("regions").document(regionId)
            .collection("offices").document(officeId)
            .collection("customerPoints")
            .document(phoneNumber)
            .get()
            .await()

        val currentPoints = refreshedDoc.getLong("currentPoints")?.toInt() ?: 0
        val totalCalls = refreshedDoc.getLong("totalCalls")?.toInt() ?: 0
        val totalEarned = refreshedDoc.getLong("totalEarned")?.toInt() ?: 0
        val totalUsed = refreshedDoc.getLong("totalUsed")?.toInt() ?: 0
        val grade = refreshedDoc.getString("grade") ?: "BRONZE"

        // 적립률 계산
        val earnRate = when(grade) {
            "BRONZE" -> 0.01   // 1%
            "SILVER" -> 0.02   // 2%
            "GOLD" -> 0.03     // 3%
            "PLATINUM" -> 0.04 // 4%
            "DIAMOND" -> 0.05  // 5%
            else -> 0.01
        }

        val earnAmount = (fare * earnRate).toInt()
        val newBalance = currentPoints - pointsUsed + earnAmount
        val newTotalCalls = totalCalls + 1

        // 등급 업데이트
        val newGrade = when {
            newTotalCalls >= 100 -> "DIAMOND"
            newTotalCalls >= 50 -> "PLATINUM"
            newTotalCalls >= 20 -> "GOLD"
            newTotalCalls >= 10 -> "SILVER"
            else -> "BRONZE"
        }

        // Firestore 트랜잭션
        firestore.runTransaction { transaction ->
            val pointsRef = firestore
                .collection("regions").document(regionId)
                .collection("offices").document(officeId)
                .collection("customerPoints")
                .document(phoneNumber)

            // 포인트 정보 업데이트
            transaction.update(pointsRef, mapOf(
                "currentPoints" to newBalance,
                "totalEarned" to (totalEarned + earnAmount),
                "totalUsed" to (totalUsed + pointsUsed),
                "totalCalls" to newTotalCalls,
                "grade" to newGrade,
                "lastUpdated" to FieldValue.serverTimestamp()
            ))

            // 포인트 사용 내역 추가 (사용한 경우만)
            if (pointsUsed > 0) {
                val useTransactionRef = firestore
                    .collection("regions").document(regionId)
                    .collection("offices").document(officeId)
                    .collection("pointTransactions")
                    .document()

                transaction.set(useTransactionRef, mapOf(
                    "id" to useTransactionRef.id,
                    "customerId" to phoneNumber,
                    "type" to "USE",
                    "amount" to -pointsUsed,
                    "balance" to (currentPoints - pointsUsed),
                    "description" to "대리운전 요금 포인트 사용",
                    "callId" to callId,
                    "timestamp" to FieldValue.serverTimestamp()
                ))
            }

            // 포인트 적립 내역 추가
            val earnTransactionRef = firestore
                .collection("regions").document(regionId)
                .collection("offices").document(officeId)
                .collection("pointTransactions")
                .document()

            transaction.set(earnTransactionRef, mapOf(
                "id" to earnTransactionRef.id,
                "customerId" to phoneNumber,
                "type" to "EARN",
                "amount" to earnAmount,
                "balance" to newBalance,
                "description" to "대리운전 이용 포인트 적립",
                "callId" to callId,
                "fare" to fare,
                "grade" to newGrade,
                "timestamp" to FieldValue.serverTimestamp()
            ))
        }.await()

        android.util.Log.d("DriverViewModel", "포인트 처리 완료: 사용=$pointsUsed, 적립=$earnAmount, 잔액=$newBalance")
        true
    } catch (e: Exception) {
        android.util.Log.e("DriverViewModel", "포인트 처리 실패", e)
        false
    }
}
```

##### 3) 기존 정산 함수 수정
```kotlin
fun confirmAndFinalizeTrip(
    callId: String,
    paymentMethod: String,
    cashAmount: Int?,
    fareToSet: Int,
    tripSummaryToSet: String,
    pointsToUse: Int = 0  // ✅ 추가: 포인트 사용액
) {
    viewModelScope.launch {
        try {
            // 콜 정보 조회
            val callDoc = firestore
                .collection("regions").document(regionId)
                .collection("offices").document(officeId)
                .collection("calls")
                .document(callId)
                .get()
                .await()

            val isAppCustomer = callDoc.getBoolean("isAppCustomer") ?: false
            val phoneNumber = callDoc.getString("phoneNumber")

            // ✅ 추가: 앱 회원이면 포인트 처리
            if (isAppCustomer && phoneNumber != null) {
                val success = processCustomerPoints(
                    phoneNumber = phoneNumber,
                    callId = callId,
                    fare = fareToSet,
                    pointsUsed = pointsToUse
                )

                if (!success) {
                    android.util.Log.e("DriverViewModel", "포인트 처리 실패했지만 정산은 계속 진행")
                }
            }

            // 기존 정산 처리
            val tripData = hashMapOf<String, Any>(
                Constants.FIELD_PAYMENT_METHOD to paymentMethod,
                Constants.FIELD_STATUS to CallStatus.COMPLETED.firestoreValue,
                Constants.FIELD_FARE_FINAL to fareToSet,
                "fare_set" to fareToSet,
                Constants.FIELD_TRIP_SUMMARY_FINAL to tripSummaryToSet,
                "pointsUsed" to pointsToUse,  // ✅ 추가
                "finalFare" to (fareToSet - pointsToUse),  // ✅ 추가
                Constants.FIELD_COMPLETED_AT to FieldValue.serverTimestamp()
            )

            if (paymentMethod == Constants.PAYMENT_METHOD_CASH && cashAmount != null) {
                tripData[Constants.FIELD_CASH_AMOUNT] = cashAmount
            }

            firestore
                .collection("regions").document(regionId)
                .collection("offices").document(officeId)
                .collection("calls")
                .document(callId)
                .update(tripData)
                .await()

            // ... 기존 후속 처리

        } catch (e: Exception) {
            android.util.Log.e("DriverViewModel", "정산 실패", e)
            // 에러 처리
        }
    }
}
```

```kotlin
// 정산 화면에 포인트 정보 표시 섹션 추가

@Composable
fun SettlementScreen(
    viewModel: DriverViewModel,
    callId: String,
    phoneNumber: String,
    isAppCustomer: Boolean
) {
    var fare by remember { mutableStateOf("") }
    var pointsToUse by remember { mutableStateOf(0) }
    var customerPoints by remember { mutableStateOf<Map<String, Any>?>(null) }

    // 앱 회원이면 포인트 정보 로드
    LaunchedEffect(isAppCustomer, phoneNumber) {
        if (isAppCustomer) {
            customerPoints = viewModel.getCustomerPointInfo(phoneNumber)
        }
    }

    Column {
        // 요금 입력
        TextField(
            value = fare,
            onValueChange = { fare = it },
            label = { Text("요금") }
        )

        // 앱 회원인 경우 포인트 정보 표시
        if (isAppCustomer && customerPoints != null) {
            Spacer(modifier = Modifier.height(16.dp))

            Card(
                modifier = Modifier.fillMaxWidth(),
                colors = CardDefaults.cardColors(
                    containerColor = MaterialTheme.colorScheme.primaryContainer
                )
            ) {
                Column(modifier = Modifier.padding(16.dp)) {
                    Text(
                        text = "💎 고객 포인트",
                        style = MaterialTheme.typography.titleMedium,
                        fontWeight = FontWeight.Bold
                    )

                    Spacer(modifier = Modifier.height(8.dp))

                    val availablePoints = customerPoints!!["currentPoints"] as Int
                    val grade = customerPoints!!["grade"] as String

                    Text("보유: ${availablePoints}P")
                    Text("등급: $grade")

                    Spacer(modifier = Modifier.height(12.dp))

                    // 포인트 사용 입력
                    Row(verticalAlignment = Alignment.CenterVertically) {
                        Text("사용: ")
                        Spacer(modifier = Modifier.width(8.dp))
                        TextField(
                            value = pointsToUse.toString(),
                            onValueChange = {
                                val value = it.toIntOrNull() ?: 0
                                pointsToUse = minOf(value, availablePoints)
                            },
                            modifier = Modifier.width(120.dp),
                            keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Number),
                            suffix = { Text("P") }
                        )
                    }

                    if (pointsToUse > 0) {
                        Spacer(modifier = Modifier.height(8.dp))
                        Text(
                            text = "결제 금액: ${fare.toIntOrNull()?.minus(pointsToUse) ?: 0}원",
                            style = MaterialTheme.typography.titleMedium,
                            color = MaterialTheme.colorScheme.primary,
                            fontWeight = FontWeight.Bold
                        )
                    }
                }
            }
        }

        Spacer(modifier = Modifier.height(24.dp))

        // 정산 완료 버튼
        Button(
            onClick = {
                viewModel.confirmAndFinalizeTrip(
                    callId = callId,
                    paymentMethod = "CARD",
                    cashAmount = null,
                    fareToSet = fare.toIntOrNull() ?: 0,
                    tripSummaryToSet = "",
                    pointsToUse = pointsToUse
                )
            },
            modifier = Modifier.fillMaxWidth()
        ) {
            Text("정산 완료")
        }
    }
}
```

```kotlin
private fun awardPointsForCompletedRide() {
    viewModelScope.launch {
        try {
            val callId = uiState.callStatus?.callId ?: return@launch

            // Firestore에서 콜 정보 가져오기
            val callDoc = firestore
                .collection("regions").document(regionId)
                .collection("offices").document(officeId)
                .collection("calls")
                .document(callId)
                .get()
                .await()

            // ✅ 수정: 기사앱에서 이미 처리했는지 확인
            val pointsUsed = callDoc.getLong("pointsUsed")?.toInt() ?: 0

            // 중복 적립 방지: 이미 거래 내역이 있으면 스킵
            val existingTransactions = firestore
                .collection("regions").document(regionId)
                .collection("offices").document(officeId)
                .collection("pointTransactions")
                .whereEqualTo("callId", callId)
                .get()
                .await()

            if (!existingTransactions.isEmpty) {
                android.util.Log.d("MainViewModel", "이미 포인트 처리됨 - 팝업만 표시")

                // 적립 포인트 계산 (팝업용)
                val fare = callDoc.getLong("fare_set")?.toInt()
                    ?: callDoc.getLong("finalFare")?.toInt()
                    ?: 0

                val points = uiState.customerPoints
                val earnAmount = points?.calculateEarnPoints(fare) ?: 0

                // 팝업만 표시
                uiState = uiState.copy(
                    showPointsEarnedDialog = true,
                    earnedPoints = earnAmount,
                    usedPoints = pointsUsed,  // ✅ 추가
                    rideCompletedFare = fare
                )

                // 포인트 정보 다시 로드
                loadCustomerPoints()

                return@launch
            }

            // 거래 내역 없으면 기존 적립 로직 실행 (백업)
            val fare = callDoc.getLong("fare")?.toInt()
                ?: callDoc.getLong("finalFare")?.toInt()
                ?: callDoc.getLong("fare_set")?.toInt()

            if (fare != null && fare > 0) {
                val success = pointService.earnPoints(
                    phoneNumber = phoneNumber,
                    callId = callId,
                    fare = fare,
                    description = "대리운전 이용 완료"
                )

                if (success) {
                    loadCustomerPoints()

                    val points = uiState.customerPoints
                    val earnedPoints = points?.calculateEarnPoints(fare) ?: 0

                    // 알림음 재생
                    try {
                        val notification = RingtoneManager.getDefaultUri(RingtoneManager.TYPE_NOTIFICATION)
                        val ringtone = RingtoneManager.getRingtone(context, notification)
                        ringtone?.play()
                    } catch (e: Exception) {
                        android.util.Log.e("MainViewModel", "알림음 재생 실패", e)
                    }

                    uiState = uiState.copy(
                        showPointsEarnedDialog = true,
                        earnedPoints = earnedPoints,
                        usedPoints = pointsUsed,  // ✅ 추가
                        rideCompletedFare = fare
                    )
                }
            }
        } catch (e: Exception) {
            android.util.Log.e("MainViewModel", "포인트 적립 중 오류", e)
        }
    }
}
```

## 🔄 일반콜 vs 고객앱 콜 구분

### 결론: **구분 불필요**

### 이유

#### 1. 통일된 판별 기준
```
isAppCustomer 필드만으로 모든 경우 처리 가능

- isAppCustomer == true  → 포인트 처리
- isAppCustomer == false → 일반 정산만
```

#### 2. 동일한 처리 흐름
```
앱호출:
  콜 생성 → isAppCustomer=true → 기사앱 정산 → 포인트 처리

전화호출 (앱 회원):
  콜 생성 → isAppCustomer=true → 기사앱 정산 → 포인트 처리

전화호출 (비회원):
  콜 생성 → isAppCustomer=false → 기사앱 정산 → 일반 정산만
```

#### 3. 로직 단순화
- 기사앱: `if (isAppCustomer) { 포인트 처리 }`
- 콜매니저: `if (isAppCustomer) { 아이콘 표시 }`
- 고객앱: phoneNumber 기준 감시

### 기존 필드 활용

```kotlin
// 이미 CallInfo.kt에 존재하는 필드들
@PropertyName("isAppCustomer") var isAppCustomer: Boolean? = false
@PropertyName("customerId") var customerId: String? = null
@PropertyName("createdFrom") var createdFrom: String? = "phone"  // phone/customer_app

// 추가 구분 필드 불필요!
```
