# FCM 로컬 DB 업데이트 작업 내역 (2026-01-05)

## 📌 작업 개요

**목표**: FCM 메시지를 받았을 때 콜매니저의 로컬 DB를 업데이트하여 UI가 실시간으로 갱신되도록 수정

**작업 일시**: 2026-01-05

## 🔍 초기 문제 상황

### 증상
1. ✅ **이전**: 기사 카드 실시간 업데이트 작동
2. ❌ **현재**: 기사 카드 업데이트 안 됨 (악화!)
3. ❌ **계속**: 내부 콜 목록 업데이트 안 됨

### 사용자 피드백
> "배차 후 업데이트가 안되니 기사는 온라인에서 사라지고 배차 삭제하고 콜매니저 로그아웃 후 로그인, 기사앱 로그아웃 후 로그인해도 기사는 계속 온라인 상태로만 유지돼서 더 이상 테스트가 불가해"

## 📊 문제 분석

### 시스템 구조 분석 결과

#### 콜매니저 아키텍처
- **로컬 DB**: Room Database (SQLite)
- **동기화 방식**: FCM 전용 (Firestore 리스너 제거됨 - 비용 절감)
- **초기 데이터**: 앱 시작 시 Firestore에서 전체 데이터 1회 로드
- **이후 업데이트**: FCM 메시지로만 업데이트 (리스너 없음)

#### 문제의 근본 원인
```
1. Firestore 리스너 제거됨 (비용 절감을 위해 FCM 전용 모드로 전환)
   ↓
2. FCM 핸들러가 미완성
   - DRIVER_STATUS_UPDATE 받음 → 알림만 표시, 로컬 DB 업데이트 없음
   - CALL_STATUS_UPDATE 받음 → 브로드캐스트만 전송, 로컬 DB 업데이트 없음
   ↓
3. UI가 로컬 DB를 구독 (Room Flow)
   ↓
4. DB가 업데이트 안 되니 UI도 갱신 안 됨
```
