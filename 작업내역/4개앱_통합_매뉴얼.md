# 대리운전 통합 플랫폼 매뉴얼

## 시스템 개요

이 시스템은 4개의 앱이 Firebase Firestore를 중심으로 유기적으로 연결되어 작동합니다.

---

## 1️⃣ 콜디텍터 (Call Detector)

### 주요 역할
사무실 전화기에 설치되어 **걸려오는 전화를 자동으로 감지하고 Firebase에 저장**하는 앱입니다.

### 핵심 기능

#### 1. 전화 감지 시스템
- **RINGING 상태**: 전화벨이 울림 → 마감 상태면 공유콜 생성 준비
- **OFFHOOK 상태**: 전화를 받음 → 통화 세션 기록
- **IDLE 상태**: 전화가 끊김 → Firebase에 콜 데이터 업로드

#### 2. 자동 정보 수집
- 전화번호 자동 추출
- 연락처에서 이름/주소 자동 조회
- 앱 회원 여부 확인 (customers 컬렉션 조회)

#### 3. 스마트 콜 생성
```
사무실 상태가 "운영중" → calls 컬렉션에 일반 콜 생성
사무실 상태가 "마감" → shared_calls 컬렉션에 공유콜 생성
```

#### 4. 개인번호 필터링
- 제외 설정된 번호는 Firebase 업로드 건너뜀
- 연락처에서 개인번호 일괄 추가 가능

#### 5. 배차 팝업
- 콜 생성 즉시 DispatchActivity 팝업 표시
- SYSTEM_ALERT_WINDOW 권한 사용

## 2️⃣ 콜매니저 (Call Manager)

### 주요 역할
사무실 관리자용 앱으로 **전화 호출을 관리하고 기사에게 배차**하는 통제 센터입니다.

### 핵심 기능

#### 1. 대시보드 화면 구성
```
┌─────────────────────────────────┐
│  [사무실명] 🟢 운영중           │
├─────────────────────────────────┤
│  내부 호출 목록                  │
│  - 대기, 배차완료, 운행중 등     │
├─────────────────────────────────┤
│  공유 콜 목록                    │
│  - 다른 사무실 마감콜            │
├─────────────────────────────────┤
│  기사 상태                       │
│  - 대기중, 운행중, 오프라인      │
└─────────────────────────────────┘
```

#### 2. 콜 관리 기능

**내부 호출**:
- 전화 호출: 📞 일반 전화 아이콘
- 앱 호출: 📱 스마트폰 아이콘 + 앱 회원은 초록색
- 고객 등급 표시: 🥉브론즈 🥈실버 🥇골드 ⭐VIP
- 매칭점수 표시 (Attribution 시스템)

**공유 콜**:
- 마감콜: 다른 사무실이 마감 후 받은 전화
- 일반 공유콜: 출발지→도착지 표시
- 수락 → 출발지/도착지/요금 입력 → 기사 배정

#### 3. 새 콜 처리 프로세스
```
1. 새 콜 팝업 표시 (알림음 + 진동)
2. 관리자 선택:
   - "대기 중인 기사 선택" → 즉시 배차
   - "공유" → 출발지/도착지/요금 입력 후 공유
   - "삭제" → 콜 제거
   - "나중에" → 팝업 닫기 (콜은 대기 목록에 유지)
```

#### 4. 음성입력 & 주소검색
- 🎤 마이크 버튼: 음성으로 주소 입력
- 🔍 자동 주소검색: Kakao API로 주소 제안
- ❌ 삭제 버튼: 입력 내용 초기화

#### 5. 기사 상태 모니터링
- 🟢 대기중 (WAITING): 배차 가능
- 🔵 온라인 (ONLINE): 출근했으나 아직 대기
- 🟡 운행준비 (PREPARING): 콜 수락 후 준비 중
- 🔴 운행중 (ON_TRIP): 고객 태움
- ⚫ 오프라인 (OFFLINE): 퇴근

#### 6. 푸시 알림 수신
- 기사 로그인/로그아웃
- 운행 시작/완료
- 콜 취소
- 공유콜 수락/거절

#### 7. QR 코드 생성
- 고객 관리 화면에서 QR 생성
- QR 스캔 → 랜딩페이지 → 앱 다운로드 → 자동 회원가입

## 3️⃣ 기사앱 (Driver App)

### 주요 역할
대리기사용 앱으로 **배차받은 콜을 처리하고 운행을 관리**합니다.

### 핵심 기능

#### 1. 배차 알림
```
FCM 푸시 알림 → 배차 팝업
┌─────────────────────────┐
│  새로운 배차             │
│  고객: 홍길동            │
│  연락처: 010-xxxx-xxxx   │
│  주소: 서울시...         │
│  [수락] [거절]          │
└─────────────────────────┘
```

#### 2. 운행 프로세스
```
배차 수락
  ↓
운행 준비
  - 출발지 입력 (음성입력 가능)
  - 도착지 입력 (음성입력 가능)
  - 경유지 입력 (선택)
  - 요금 입력 (숫자만)
  ↓
운행 시작
  - 기사 상태: ON_TRIP
  - 콜 상태: IN_PROGRESS
  ↓
운행 완료
  - 콜 상태: AWAITING_SETTLEMENT
  ↓
정산 처리
  - 결제 방법 선택
  - 포인트 사용 처리 (앱 회원)
  - 콜 상태: COMPLETED
```

#### 3. 결제 방법
- **현금**: 받은 현금 금액 입력
- **외상**: 나중에 정산
- **이체**: 계좌 이체
- **포인트**: 고객 포인트로 결제
- **현금+포인트**: 혼합 결제

#### 4. 포인트 시스템
```
앱 회원인 경우:
- 콜 정보에 isAppCustomer: true 표시
- 정산 시 포인트 적립 자동 처리
- 등급별 적립률:
  🥉 브론즈: 1%
  🥈 실버: 2%
  🥇 골드: 3%
  💎 플래티넘: 4%
  💠 다이아: 5%
```

#### 5. 운행 취소
- **내부콜**: 콜 상태 HOLD로 변경 (다른 기사 재배정 가능)
- **공유콜**: 원본 shared_calls를 OPEN으로 복구

## 4️⃣ 손님앱 (Customer App)

### 주요 역할
고객용 앱으로 **직접 대리운전을 요청하고 포인트를 적립**합니다.

### 핵심 기능

#### 1. QR 스캔 회원가입
```
콜매니저 QR 생성 → 손님 스캔
  ↓
랜딩페이지 (사무실 정보 표시)
  ↓
앱 다운로드 링크
  ↓
앱 설치 → 자동 회원가입
  - regionId, officeId 자동 설정
  - 익명 인증 (Firebase Anonymous Auth)
  - customers 컬렉션에 고객 정보 저장
```

#### 2. 호출 요청
```
┌─────────────────────────┐
│  🏠 집 아이콘            │  ← 저장된 집주소 불러오기
│  📍 출발지 입력          │  ← 🎤 음성입력 가능
│  📍 도착지 입력          │  ← 🎤 음성입력 가능
│                         │
│  💰 포인트 사용          │  ← 보유 포인트로 할인
│     사용할 포인트 입력   │
│                         │
│  [대리운전 부르기]       │
└─────────────────────────┘
```

#### 3. 실시간 상태 확인
```
호출 요청 → FCM 알림 → 기사 배정
┌─────────────────────────┐
│  기사 배정 완료!         │
│  기사: 김철수            │
│  차량번호: 12가3456      │
│  전화: 010-xxxx-xxxx     │
│  [전화하기]             │
└─────────────────────────┘

운행 완료 → FCM 알림 → 포인트 적립
┌─────────────────────────┐
│  운행이 완료되었습니다!   │
│  요금: 30,000원          │
│  적립: +900포인트 (3%)   │
│  현재 포인트: 5,400P     │
└─────────────────────────┘
```

#### 4. 만보기 기능
- 실시간 걸음수 측정
- 일일/주간/월간 통계
- 세션 기능 (리셋 가능한 임시 카운터)

#### 5. 포인트 내역
- 적립 내역: 운행 완료 시 자동 적립
- 사용 내역: 호출 시 또는 운행 시 차감
- 잔액 실시간 표시

## 🔄 유기적 동작 흐름

### 시나리오 1: 전화 호출 → 배차 → 운행

```
1. 고객이 사무실 전화로 전화
   📞 → 콜디텍터

2. 콜디텍터가 전화 감지
   - 전화번호: 010-1234-5678
   - 이름: 홍길동 (연락처에서 조회)
   - 주소: 서울시 강남구... (연락처에서 조회)
   - Firebase에 콜 생성 (status: WAITING)

3. 콜매니저에 새 콜 팝업 표시
   [알림음 + 진동]
   관리자: "김기사님에게 배정"
   → Firebase 업데이트 (status: ASSIGNED)
   → FCM으로 기사에게 알림 전송

4. 기사앱에 배차 알림 도착
   [진동 + 알림음]
   기사: "수락" 버튼 클릭
   → Firebase 업데이트 (status: ACCEPTED)

5. 기사가 운행 준비
   - 출발지: 서울역 (음성입력)
   - 도착지: 강남역 (음성입력)
   - 요금: 30000원
   → "운행 시작" 클릭
   → Firebase 업데이트 (status: IN_PROGRESS)

6. 기사가 운행 완료
   → "운행 완료" 클릭
   → Firebase 업데이트 (status: AWAITING_SETTLEMENT)

7. 정산 처리
   - 결제 방법: 현금
   - 포인트 적립 (앱 회원인 경우)
   → Firebase 업데이트 (status: COMPLETED)
```

### 시나리오 2: 앱 호출 → 배차 → 운행

```
1. 손님앱에서 호출 요청
   - 출발지: 현재 위치 (GPS)
   - 도착지: 집주소
   - 포인트 사용: 1000P
   → Firebase에 콜 생성
     (status: WAITING, createdFrom: customer_app)

2. 콜매니저에 앱 호출 표시
   📱 아이콘 + 앱 회원 초록색 아이콘
   관리자: 기사 배정
   → FCM으로 손님에게 알림

3. 손님앱에 기사 정보 표시
   [진동 + 알림음]
   "김기사님이 배정되었습니다"
   전화번호 / 차량번호 표시

4. 운행 진행 (시나리오 1과 동일)

5. 운행 완료 후 손님에게 FCM 알림
   [진동 + 알림음]
   "포인트 적립 완료!"
   요금: 30,000원
   사용: -1,000P
   적립: +900P (3%)
   잔액: 5,400P
```

### 시나리오 3: 마감 시간 전화 호출 → 공유 콜

```
1. 밤 11시, 사무실 마감 후 전화 도착
   콜디텍터: 사무실 상태 확인 (CLOSED)
   → shared_calls 컬렉션에 공유콜 생성

2. Cloud Functions 트리거
   → 같은 지역 다른 사무실들에게 FCM 알림 전송

3. 다른 사무실 콜매니저에 알림
   [알림음 + 진동]
   "마감콜이 도착했습니다"
   - 사무실명: 홍천대리운전
   - 전화번호: 010-1234-5678
   [수락] 버튼

4. 수락 후 정보 입력
   - 출발지: 홍천군청
   - 도착지: 명랑운동회
   - 요금: 50000원
   - 기사: 박기사 선택
   → calls 컬렉션에 일반 콜 생성
     (callType: SHARED)

5. 이후 일반 콜과 동일하게 진행
```

## 📊 데이터베이스 구조

```
Firestore
├─ regions/{regionId}/
│  └─ offices/{officeId}/
│     ├─ calls/ (콜 목록)
│     │  ├─ status (상태)
│     │  ├─ assignedDriverId (배정된 기사)
│     │  ├─ isAppCustomer (앱 회원 여부)
│     │  ├─ customerGrade (고객 등급)
│     │  ├─ attributionScore (매칭점수)
│     │  └─ createdFrom (phone/customer_app/landing)
│     │
│     ├─ drivers/ (기사 목록)
│     │  ├─ status (WAITING/ON_TRIP/...)
│     │  └─ fcmToken (푸시 알림용)
│     │
│     ├─ customers/ (앱 회원 정보)
│     │  ├─ phoneNumber
│     │  ├─ homeAddress (집주소)
│     │  └─ officePhone (사무실 연락처)
│     │
│     ├─ customerPoints/ (포인트 정보)
│     │  ├─ currentPoints (현재 포인트)
│     │  ├─ totalEarned (총 적립)
│     │  ├─ totalUsed (총 사용)
│     │  ├─ grade (등급)
│     │  └─ totalCalls (총 이용 횟수)
│     │
│     └─ pointTransactions/ (포인트 거래 내역)
│        ├─ type (EARN/USE)
│        ├─ amount (금액)
│        ├─ balance (잔액)
│        └─ callId (연결된 콜)
│
├─ shared_calls/ (공유콜 - 지역 전체)
│  ├─ status (OPEN/CLAIMED/...)
│  ├─ sourceOfficeId (보낸 사무실)
│  ├─ callType (AFTER_HOURS/...)
│  └─ departure/destination/fare
│
└─ admins/ (관리자 정보)
   └─ associatedOfficeId
```

## 🔔 FCM 알림 체계

```
콜매니저 → 기사앱
├─ CALL_ASSIGNED: 콜 배정
├─ CALL_CANCELLED: 콜 취소
└─ SHARED_CALL_AVAILABLE: 공유콜 알림

기사앱 → 콜매니저
├─ DRIVER_LOGIN: 기사 로그인
├─ DRIVER_LOGOUT: 기사 로그아웃
├─ TRIP_STARTED: 운행 시작
├─ TRIP_COMPLETED: 운행 완료
└─ DRIVER_APPROVAL_REQUEST: 가입 승인 요청

기사앱 → 손님앱
├─ DRIVER_ASSIGNED: 기사 배정
└─ RIDE_COMPLETED: 운행 완료 (포인트 적립)

Cloud Functions → 콜매니저들
└─ shared_calls 생성 시 자동 알림
```

## ⚙️ 핵심 설정

### 콜디텍터
- regionId, officeId, deviceName 설정 필수
- READ_PHONE_STATE, READ_CONTACTS 권한 필요
- SYSTEM_ALERT_WINDOW 권한 (팝업용)
- 배터리 최적화 예외 설정

### 콜매니저
- Firebase 인증 (관리자 계정)
- admins 컬렉션에 associatedOfficeId 설정
- FCM 토큰 자동 등록
- 콜 감지 기능 ON/OFF 설정 가능

### 기사앱
- Firebase 인증 (기사 계정)
- regionId, officeId 자동 설정
- FCM 토큰 자동 등록
- 위치 권한 (운행 중)

### 손님앱
- 익명 인증 (자동)
- QR 스캔으로 regionId, officeId 자동 설정
- 위치 권한 (현재 위치 조회)
- 활동 인식 권한 (만보기)

## 🔧 문제 해결 가이드

### 콜디텍터가 전화를 감지하지 못할 때
1. 권한 확인: READ_PHONE_STATE, READ_CONTACTS
2. 배터리 최적화 예외 설정 확인
3. 포그라운드 서비스 실행 중인지 확인
4. regionId, officeId, deviceName 설정 확인

### 콜매니저에 콜이 안 뜰 때
1. Firebase 인증 상태 확인
2. admins 컬렉션에 associatedOfficeId 설정 확인
3. 네트워크 연결 확인
4. Firestore 보안 규칙 확인

### 기사앱에 배차 알림이 안 올 때
1. FCM 토큰 등록 확인 (drivers/{driverId}/fcmToken)
2. 기사 상태가 WAITING 또는 ONLINE인지 확인
3. 알림 권한 확인 (POST_NOTIFICATIONS)
4. 백그라운드 앱 실행 제한 확인

### 손님앱에서 호출이 안 될 때
1. 익명 인증 상태 확인
2. regionId, officeId 설정 확인
3. customers 컬렉션에 고객 정보 존재 확인
4. 네트워크 연결 확인
5. 위치 권한 확인 (현재 위치 조회 시)

```
  ↓
```

```
  ↓
WAITING (대기중)
```
