# 홈페이지 컨텐츠 이식 명세서

> **목적**: `홈페이지최종.html`의 디자인 틀을 그대로 유지하면서, 현재 운영 중인 `index.html`의 실제 컨텐츠(텍스트·이미지·링크·기능)를 이식합니다.
>
> **핵심 원칙**: 디자인(레이아웃, 색상, 간격, 효과)은 홈페이지최종을 100% 따르고, 안에 들어가는 내용물만 교체합니다.

---

## 1. 네비게이션 바

### 현재 (홈페이지최종)
```
CallMadang | 서비스 소개 | 주요 기능 | 비교 분석 | 요금 안내 | [무료 신청하기]
```

### 교체할 내용
| 항목 | 변경 내용 |
|------|----------|
| 로고 텍스트 | `CallMadang` → `콜마당` |
| 로고 옆 서브텍스트 | (추가) `지역대리운전 관리 플랫폼` (연한 회색, 작은 글씨) |
| 메뉴 항목 | `서비스 소개` / `관리자 로그인` / `무료 신청하기` (3개로 축소) |
| 관리자 로그인 링크 | `https://head-manager-web.web.app/owner/login` (새 탭) |
| 무료 신청하기 링크 | `signup.html` (같은 사이트 내 별도 페이지) |
| 모바일 햄버거 메뉴 | 동일한 3개 메뉴 항목 포함 |

> **디자인 유지**: 글래스모피즘 스타일, 블러 효과 그대로 유지

### 2-2. 오른쪽 시연 데모 영역

> **중요**: 이 영역은 단순 이미지가 아니라 **인터랙티브 애니메이션**입니다.
> 아래 "부록 A: 시연 데모 전체 코드"를 참고하여 통째로 이식해 주세요.

**데모 개요:**
- 재생 버튼을 누르면 자동으로 진행되는 시연 애니메이션
- 폰 3대(고객폰, 콜매니저폰, 일반방식폰)가 등장
- 커서가 자동으로 움직이며 클릭하는 효과
- 콜마당: 원클릭 배차 vs 일반방식: 8번 클릭을 시각적으로 비교
- BGM 재생 (Seamless_Flow.mp3)
- 화면 밖으로 스크롤하면 자동 정지 및 리셋

**교체할 이미지 (현재 홈페이지최종은 Google placeholder 사용 중):**

| 데모 내 요소 | 이미지 파일 경로 |
|-------------|-----------------|
| 고객 전화 화면 | `sourc/일반콜.jpg` |
| 콜매니저 수신 화면 | `sourc/콜매니저1.jpg` |
| 콜매니저 통화 화면 | `sourc/콜매니저2.jpg` |
| 콜매니저 배차완료 | `sourc/콜매니저3.jpg` |
| 일반방식 클릭 1~7 | `sourc/일반클릭/일반1.jpg` ~ `sourc/일반클릭/일반7.jpg` |
| 콜마당 아이콘 | `sourc/손님앱.png` |
| 일반전화 아이콘 | SVG (초록색 전화기, 코드 내 포함) |

**교체할 데모 JS:** index.html 하단의 `Showcase Compare` 스크립트 전체를 이식해야 합니다.
- 홈페이지최종에 이미 절반 정도 들어가 있으나 **불완전(잘려 있음)**합니다.
- index.html의 완성된 JS로 통째 교체해 주세요.
- BGM 관련 코드 포함: `<audio id="demoBgm" preload="auto" src="sourc/Seamless_Flow.mp3"></audio>`

| `요금 안내` 네비 메뉴 | 별도 요금 페이지 없음, 제거 |
