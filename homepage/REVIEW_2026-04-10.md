# 콜마당 홈페이지 종합 검토 (2026-04-10)

> 검토 팀: homepage-tech (기술), homepage-design (디자인+벤치마킹), 리드 (종합 평가)

---

## 검토 당시 상황
- 첫 파일럿 준비 단계, 미출시
- 양평군 10개 사무실 대상 방문 영업 시 어필용
- 상세 기능/포지션은 의도적 생략 (경쟁사 노출 방지)
- 타겟: 40~50대 대리운전 사무실 사장님
- 페인포인트: 운전 중 배차 8번 클릭, 이리저리 옮겨다니는 손님

---

## 강점

| 항목 | 평가 |
|------|------|
| 핵심 카피 | "8번 클릭 vs 1번", "QR 하나로 손님 각인" — 즉시 이해 가능한 구체적 수치 |
| 인터랙티브 데모 | 커서 애니메이션으로 기존 vs 콜마당 비교 — 업계에서 보기 드문 창의적 접근 |
| 색상 체계 | 골드(#FFAB00) + 네이비(#1a2640) 일관 적용, CSS 변수 관리 |
| 타이포그래피 | KakaoBigSans + Noto Sans KR 조합 양호 |
| 비교표 | 기존 플랫폼 vs 콜마당 대조 직관적 |
| 경쟁사 대비 | 로지콜/콜마너 대비 디자인 품질 압도적 |
